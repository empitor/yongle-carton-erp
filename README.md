# 宁波甬勒包装制品有限公司 · 管理系统

面向外购瓦楞纸板、厂内加工纸箱的本地 ERP。当前版本 **0.6.1**（Git 标签 `v0.6.1`）。

> 本机开发测试版本。正式投产前，请完成数据备份恢复、网络部署和真实业务流程验收。

## 主要功能

- 客户、供应商、产品、客户订单、采购订货与业务工作台（保留经营统计）。
- 分批到货、原材料/成品库存、库存流水（业务操作只追加；管理员直接编辑时保留修订记录）、生产任务与登记、客户送货、订单履约。
- 仓库送货/到货日期台账、每日批次汇总及计划；采购订货单与本批送货单Word/Excel导出，采购完整下载交付后可联动已订货状态。
- 采购/送货列表及详情直接预览和导出；AI设置→单据模板支持多模板、默认选择、字段显隐与顺序、A4字体排版及虚构测试样张。销售订单内可快捷新建客户/产品，生产支持整批领料完工，订单工作区支持批量核对导入。
- AI 订单/到货单识别、原件预览、可编辑草稿、人工核对后正式导入。
- 全局 AI 助手、附件阅读、业务工具、插件与页面控制、本地语音输入。
- 登录、账号管理（管理员/业务人员/只读）、归档、物理删除、审计及本机数据管理。

## Windows 本地启动

安装 **Node.js 24.15 或更高 24.x 版本**和 Git，进入项目目录执行：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd start
```

浏览器访问 `http://127.0.0.1:3001`。

- 首次使用在登录页创建管理员账号，系统不会生成默认密码或示例业务数据。登录后才能查看业务数据；其他账号在右上角账号菜单建立。
- 日常使用可双击“启动系统.cmd”；“停止系统.cmd”会在核验进程后停止服务。
- 源码开发执行 `npm.cmd run dev`：前端 5173，后端 3001；`npm.cmd stop`同时正常关闭前后端。后台源码修改会自动重启接口。
- PowerShell 7可作为Windows原生日常终端，5.1继续保留供既有兼容调用使用。不要将所有`powershell.exe`直接替换为`pwsh.exe`。
- 可通过`$env:PORT='3019'`配置后台及开发代理；`$env:WEB_PORT='5180'`配置开发前端。端口冲突会报错，不会结束其他实例。

## 数据与备份

业务数据、AI 原件/草稿/聊天记录、导入归档、提示词和工具设置均保存在项目下的 `data/`；AI 服务地址、模型和加密密钥保存在本机的 `%LOCALAPPDATA%\ZhixuERP\ai\settings.sqlite`。这些数据不进入 Git。

```powershell
npm.cmd run backup
npm.cmd run restore -- "备份目录绝对路径"
npm.cmd run reset-password -- "用户名"
```

- **完整备份：** `backup` 在 `backups/full-时间/` 生成完整备份，包含业务库、账号、AI 工作区与原件、正式归档、提示词和本机 AI 配置，并带校验清单。运行中也可以执行。
- **自动备份：** 服务运行时每天自动做一次（`backups/auto-时间/`），保留最近 14 份。失败时今日页会提示，详情在服务日志，请定期确认。
- **删除前快照：** 物理删除和数据初始化前自动保存业务库快照到 `data/snapshots/`，保留最近 20 份，5 分钟内不重复。快照只含业务库，不含 AI 工作区原件。
- **恢复：** 须先停止服务。恢复前的 `data/` 另存为同级的 `data.before-restore-时间`。本机 AI 配置不会自动覆盖。旧的单文件备份仍可用 `restore` 恢复；只备份业务库用 `tsx server/maintenance.ts backup-db`。
- **忘记密码：** `reset-password` 生成一次性临时密码，旧登录立即失效。

建议把备份另存到其他磁盘。更新现有副本前先备份并在原服务窗口按Ctrl+C停止旧版，再执行 `git pull --ff-only`、`npm.cmd ci`、`npm.cmd run build`。0.5.x实例没有新版正常关闭通道，升级前请使用原窗口停止。Git 只保存程序代码，不能代替业务数据备份。

## AI 与语音

在“AI 设置 → API 配置”填写服务地址、密钥并选择模型；密钥只保存在后端，由 Windows DPAPI 保护。识别和聊天会把相关单据或消息发送给已配置的 AI 服务，请在使用前确认外发范围。

全局助手默认显示右下角纸箱精灵，顶部“AI助手”也打开同一窗口。窗口右上角可切换收起后的顶栏/悬浮入口，保留本浏览器已保存的明确选择。精灵拖到左右边缘附近会半隐藏并扒边探头，拖回中间恢复完整形象；位置与停靠状态自动保存，展开的聊天窗口始终完整显示。

智能订单识别后，唯一同名客户会自动预选；产品匹配候选直接列在各条明细下方，确认后点击核对区域顶部固定的“保存客户与产品选择”。保存只更新导入草稿，正式订单仍需完整预览和确认。修改匹配关键字段会提示对应选择失效；档案缺材质/楞型会单独提示资料不完整。

本地语音模型不随 Git 上传。需要语音输入时，将完整的 `vendor/models/sensevoice` 目录放回项目；没有模型不影响文字聊天和 ERP 功能。
