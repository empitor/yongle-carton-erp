# 甬勒纸箱厂 ERP

宁波甬勒包装制品有限公司自用的纸箱厂管理系统：从收到客户文件，到下单、采购、生产、送货，再到每月算账，都在一个系统里完成，并由 AI 帮忙识别文件和处理日常操作。

当前版本 **0.8.2**，面向 Windows 和 Ubuntu 24.04 LTS x64，数据都保存在你自己的电脑或服务器里。

## 下载安装

两个安装包各自内置 Node.js 24 和原生依赖；Linux 另需中文字体。

1. 到 [Releases](https://github.com/empitor/yongle-carton-erp/releases/latest) 下载 `yongle-carton-erp-v0.8.2-win-x64.zip`。
2. 解压到一个固定的文件夹，比如 `D:\纸箱厂ERP`。**不要放在压缩包里直接运行。**
3. 双击 `启动系统.cmd`，浏览器会自动打开 `http://127.0.0.1:3001`。
4. 第一次打开时，在页面上建立管理员账号。系统没有默认密码，也没有示例数据。

用完双击 `停止系统.cmd`，或在启动窗口按 `Ctrl+C`。

**Linux：** 同一 Release 提供 `yongle-carton-erp-v0.8.2-linux-x64.tar.gz`，两个包各附 sha256。按[部署与运维](docs/部署与运维.md)配置中文字体、专用账号、systemd 与 Caddy。

**Windows 系统要求：** Windows 10、11 或 Windows Server，64 位。AI 助手操作独立浏览器窗口时，电脑上要有 Chrome 或 Edge。

**启动不了时：**

- **Windows 提示“已保护你的电脑”：** 点“更多信息”再点“仍要运行”。
- **提示缺少 DLL：** 安装微软的 [VC++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
- **端口被占用：** 另一个程序占了 3001，先关掉它。

## 功能一览

### 业务主线

```mermaid
flowchart LR
  A[客户发来文件] --> B[收件箱]
  B --> C[AI 识别，人工核对]
  C --> D[订单]
  D --> E[采购纸板]
  E --> F[到货入库]
  F --> G[生产完工]
  G --> H[送货]
  H --> I[财务]
```

### 日常业务

| 模块 | 能做什么 |
|---|---|
| **今日** | 打开就知道今天要做什么：逾期未发、未排产、待下单、到货待登记、货款到期 |
| **收件箱** | 把手动上传、粘贴和企业微信机器人收到的文字、图片、文件集中到一处，一键转订单、到货或唛头 |
| **AI 导入** | 识别客户订单、到货单、唛头文件，对照原件核对后才入账。上传不会自动发给模型 |
| **订单** | 客户、产品、订单管理。生产中、待发货、部分发货、已发货由实际单据自动判断，不用手工改 |
| **产品唛头** | 唛头和样稿文件按款对应到产品，下单和生产时直接查看 |
| **采购和到货** | 采购单、到货计划、验收入库、数量更正 |
| **生产** | 看板排产、生产任务、整批领料和完工登记 |
| **仓储和送货** | 原料和成品库存、日期台账、送货单。库存只由流水算出，不会变成负数 |
| **单据** | 采购单、送货单导出 Word 和 Excel，模板可调 |

### 财务

**业务不等财务：** 没有税率照样送货、到货、收付款，理论金额先进账，月底再补。只有出正式报表和结账时，才要求补完。

| 模块 | 能做什么 |
|---|---|
| **财务概览** | 每月对照两种盈亏，点金额看每一笔。还能看出这个月收到的钱是几月份的货款 |
| **月度台账** | 当月每一条接单、送货、到货、收付；单张或按单位批量补税率 |
| **应收应付** | 往来单、压货款、收付计划、到期提醒、账龄、对账单 |
| **账期和优惠** | 按单位设压几个月、每月几号付、现结优惠、分期、保证金、压款利息，比例都由你填 |
| **资金发票** | 收付款和核销、资金账户、银行流水导入和匹配、承兑票据、发票、税务底稿 |
| **费用资产工资** | 费用报销、固定资产折旧、工资导入、库存成本、毛利 |
| **凭证账簿** | 凭证制单、审核、记账；已记账只能红字冲销；总账、明细账、余额表 |
| **报表结账** | 资产负债表、利润表、现金流量表、试算平衡、结账清单、归档下载 |

两种盈亏互不影响：

| | 收入 | 支出 |
|---|---|---|
| **理论** | 本月送货单金额 | 本月到货单金额 |
| **实际** | 本月收到的钱 | 本月付出的钱 |

导出的都是可以直接看的 Excel：中文表头，金额按元，能继续求和。

> 科目、报表行项目和税率还没有请专业会计复核，正式报表目前只作内部参考。

### AI 助手和其他

- **全局 AI 助手：** 点右下角的小甬和小勒或按 `Ctrl+J`。可以读附件、查业务、帮忙录入、操作页面、查看系统状态和备份，还能语音输入。写入都走正常的权限和确认流程，AI 不能直接改数据库，也不能写财务；删聊天记录、移除唛头要你本人明确说。
- **企业微信机器人：** 员工把文件转发给机器人，内容自动进收件箱。在“设置 → 消息接入”填写凭据。
- **账号权限：** 管理员、业务人员、只读、财务、出纳五种。可以在登录页申请账号、提交忘记密码，由管理员处理；登录页和右上角都能切换账号。
- **数据安全：** 每天自动备份，删除前自动保存快照，升级前自动保存快照，修改留审计记录。
- **服务器部署：** 支持 Windows Server 加反向代理和 HTTPS，见[部署与运维](docs/部署与运维.md)。

详细操作见[使用手册](docs/使用手册.md)。

## 接入 AI

不接 AI 也能用全部业务功能，只是不能识别文件，也没有助手。

1. 用管理员账号打开“设置 → API 配置”（只有管理员能改）。
2. 填写服务地址和 API Key，比如 OpenAI 兼容接口或 DeepSeek。
3. 选择模型，点测试，保存。

密钥只保存在本机后端，用 Windows 账号加密，换电脑或换 Windows 账号要重新填写。使用时文件会发给你选的模型服务商，并由对方计费。

## 接入语音模型

语音输入是可选的，模型文件较大，不随安装包提供。没有模型时其他功能不受影响。

1. 下载 [sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17.tar.bz2](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17.tar.bz2)，约 1 GB。也可以到 [Hugging Face](https://huggingface.co/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17/tree/main) 只下载下面两个文件。
2. 解压后，把这两个文件放到安装目录的 `vendor\models\sensevoice\`：
   - `model.int8.onnx`
   - `tokens.txt`
3. 重启系统，在 AI 助手里点麦克风。

模型的使用条款以上游项目为准。

## 日常维护和升级

**备份和恢复：** 双击 `维护命令行.cmd`（源码运行时直接用终端），然后执行：

```bash
npm.cmd run backup
```

```bash
npm.cmd run restore -- "备份目录的完整路径"
```

```bash
npm.cmd run reset-password -- "用户名"
```

系统每天还会自动备份到 `backups\`，保留最近 14 份。请定期把备份复制到另一块硬盘。

**数据放在哪里：**

| 位置 | 内容 |
|---|---|
| 安装目录的 `data\` | 业务数据、账号、AI 导入记录、提示词 |
| 安装目录的 `backups\` | 备份 |
| `%LOCALAPPDATA%\ZhixuERP\` | 模型 API 和机器人的加密凭据 |

**升级：**

1. 先备份，然后停止系统。
2. 把新版本解压到一个新文件夹。
3. 把旧文件夹的 `data\` 和 `backups\` 复制到新文件夹，语音模型也一并复制。
4. 启动新版本。数据库会自动升级，升级前会自动保存一份快照。每个版本的升级注意事项见对应的[发布说明](docs/releases/)。

## 已知限制

- 支持 Windows x64 和 Linux x64（Ubuntu 24.04），界面和文档只有中文，金额只有人民币。
- 财务的科目和报表没有经过专业会计复核。
- 启用财务时要把存货金额填进期初，第一次算成本时填同样的金额，系统目前不校验两边是否一致。
- 部署到服务器的流程已写好，但真实的 HTTPS、开机自启和多人同时使用还没有实测。

完整清单见[路线图](docs/路线图.md)。

## 从源码开发

需要 Node.js 24.15 或更高的 24.x，以及 Git。

```bash
npm.cmd ci
```

```bash
npm.cmd run dev
```

前端在 5173 端口，后端在 3001 端口。

| 命令 | 作用 |
|---|---|
| `npm.cmd run typecheck` | 类型检查 |
| `npm.cmd test` | 全部自动测试，只用虚构数据和临时目录 |
| `npm.cmd run test:ui` | 用隔离实例和虚构数据，在无头 Chrome 里走财务、账号、手机和小甬小勒的主要流程 |
| `npm.cmd run build` | 构建页面 |
| `npm.cmd run package` | 生成发布用的 zip |
