# 安卓外壳文档

甬勒ERP 的安卓外壳：原生 Java WebView，包名 `cn.nbyongle.erp`（测试版 `cn.nbyongle.erp.test`）。打开就是整屏的 ERP 网页，没有地址栏；登录、权限、业务都由网页处理。和 ERP 的接点只有两处：构建时写进去的网址，和一条消息通道。

- 本目录自成一体：不引用 ERP 项目和 `apps/desktop/` 的文件，单独复制出去也能构建测试。
- 检查：ERP 项目根目录 `npm run check:apps -- android`。
- AI 真机实测只装、只操作测试版，连虚构数据的预览实例；不碰手机上别的应用和设置，系统弹出的权限、安装确认不替人点。
