# 安卓外壳文档

这里讲安卓外壳自己的结构、构建、测试和打包。不讲和网页之间的消息约定（只写在 ERP 项目 `docs/架构说明.md`“安卓 App 通道”），不讲服务器上放更新包的目录和 Caddy 配置（ERP 项目 `docs/部署与运维.md`“客户端更新包”），也不记待办（ERP 项目 `docs/路线图.md`“应用外壳”：还没做的、待真机测的、已知的限制）。

甬勒ERP 的安卓外壳（原生 Java WebView，包名 `cn.nbyongle.erp`，测试版 `cn.nbyongle.erp.test`）：安装后有自己的图标，打开就是整屏的 ERP 网页，没有浏览器地址栏和标签页。外壳和 ERP 的接点只有两处：构建时配置的网址，和上面那条消息通道；登录、权限、业务都由网页自己处理。

| 文档 | 管什么 |
|---|---|
| [架构说明](架构说明.md) | 目录、分层和登记表、两个版本、权限、每个行为怎么实现、安全边界、依赖 |
| [构建与测试](构建与测试.md) | 工具链、构建命令、代码检查和单元测试、装到手机、真机验证脚本、应用内更新和正式发布、看真实 ERP 界面的办法 |

- 本目录自成一体：不引用 ERP 项目和 `apps/desktop/` 的任何文件，单独复制出去也能构建和测试。代码标准（文件 500 行、函数 80 行、一个文件一件事、不写兜底）和 ERP 项目的 `AGENTS.md` 一致。
- 检查在 ERP 项目根目录用 `npm run check:apps -- android` 跑（不带 `-- android` 连 Windows 外壳一起查）。
- 安装包和签名密钥不进仓库；私钥和密码由用户本人保管，文档、代码、聊天里都不写。
- AI 真机实测只装、只操作测试版，连电脑上虚构数据的预览实例；不碰手机上别的应用和设置，系统弹出的权限、安装确认不替人点。
