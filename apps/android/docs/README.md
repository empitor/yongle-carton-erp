# 安卓外壳文档

甬勒ERP 的安卓外壳：安装后有自己的图标，打开就是整屏的 ERP 网页，没有浏览器地址栏和标签页。外壳和 ERP 唯一的接点是构建时配置的网址；登录、权限、业务都由网页自己处理。

| 文档 | 管什么 |
|---|---|
| [架构说明](架构说明.md) | 目录、分层和登记表、每个行为怎么实现、安全边界、依赖 |
| [构建与测试](构建与测试.md) | 工具链、构建命令、代码检查和单元测试、真机验证脚本、应用内更新、看真实 ERP 界面的办法 |

还没做的、待真机测的、已知的限制记在 ERP 项目的 `docs/路线图.md`“应用外壳”；和网页之间的消息约定只写在 ERP 项目的 `docs/架构说明.md`“安卓 App 通道”。检查在 ERP 项目根目录用 `npm run check:apps` 一次跑完两个外壳。

本目录自成一体：不引用 ERP 项目和 `apps/desktop/` 的任何文件，单独复制出去也能构建和测试。
