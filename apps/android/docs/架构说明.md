# 架构说明

安卓外壳的代码怎么分、每个行为怎么做、安全边界和依赖。消息约定（有哪几条、字段、谁回什么）只写在 [外壳和网页](../../../docs/架构/外壳和网页.md)“安卓 App 通道”，这里只写外壳这头；构建、测试、打包见[构建与测试](构建与测试.md)。

## 目录

Java 源码都在 `app/src/main/java/cn/nbyongle/erp/`：

| 文件 | 管什么 |
|---|---|
| `MainActivity.java` | 入口：生命周期、装配各件、网页设置、加载各时机（`ShellClient`）、站外交给系统、下载、重试、渲染进程没了换新 WebView，把通道上的消息分给各件 |
| `WebRules.java` | 纯规则：网址分流；哪些加载失败算连不上；ERP 来源；User-Agent 的 App 标记 |
| `BackKey.java` | 纯规则加状态：返回键先问网页、后退还是按首页；回执编号；首页连按两次才退出 |
| `SystemBars.java` | 系统栏让位、上下色带取网页颜色、图标深浅 |
| `BridgeChannel.java` | 通道：建端口、发接通消息、解析消息交给入口、页面重载时关掉；发送函数绑在当时的端口上 |
| `ShareInbox.java` | 收“分享”“用其他应用打开”的文件：判忙、复制进缓存、提示，把分享消息转给 `ShareRelay`，收尾 |
| `ShareBatches.java` | 缓存里待交的一批：目录、清单 `batch.json`、冷启动清理 |
| `ShareRelay.java` | 纯 Java：一批分享怎么逐份交给网页，和这几条消息的拼法 |
| `FileSaver.java` | 收 `save-file`，存进系统“下载”，回 `save-result` |
| `FileChooser.java` | 网页文件框：文件管理器，收图片时另给相册、拍照 |
| `AppUpdater.java` | 应用内更新：读清单、下载、核对、交给系统安装器；待装版本记在 SharedPreferences |
| `InstallStatusReceiver.java` | 系统安装器的结果：只打开系统的安装确认页，没装上就提示 |
| `LaunchScreen.java` | 冷启动的启动画面 |
| `Shell.java` | 共用小件：日志标签、`MIB`、提示、后台线程和回主线程、读内容提供者、限长复制、建删目录、文件名清洗 |

其余：

| 位置 | 放什么 |
|---|---|
| `app/src/main/AndroidManifest.xml` | 权限、入口、接收器、备份和网络配置（见“清单和权限”） |
| `app/src/main/res/` | 布局（页面层 `page` = 网页加离线层，另有上下色带和启动画面）、文字、颜色、主题、图标、启动动画 `drawable/splash_logo.xml`（12 起的主题在 `values-v31/`）、网络配置（正式版只许 HTTPS、只信系统证书）、备份规则（12 起 `data_extraction_rules.xml`，10–11 `full_backup_content.xml`） |
| `app/src/debug/res/xml/network_security_config.xml` | 只给测试版：127.0.0.1、localhost 可走明文 HTTP |
| `app/src/test/java/…` | JVM 单元测试和边界检查 `ShellBoundaryTest`（清单见[构建与测试](构建与测试.md)） |
| `app/build.gradle.kts` | 网址、更新清单地址、包名、版本、SDK、Java 17、Lint、javac、Checkstyle、运行时无库检查 |
| `config/checkstyle.xml` | 代码规模和写法上限（口径见[构建与测试](构建与测试.md)） |
| `gradle.properties` | 版本号、测试网址、更新清单地址、中文路径放行、不带 Kotlin 标准库 |
| `scripts/` | `env.ps1` 设环境变量；`verify-device.ps1` 真机验证；`update-test.ps1` 应用内更新的本机测试 |
| `test-site/` | 虚构测试页 |

## 分层和登记表

只往下引，没有循环：

```
MainActivity（入口）
 ├─→ WebRules、BackKey          纯规则
 ├─→ SystemBars、BridgeChannel、FileSaver、FileChooser、LaunchScreen
 ├─→ ShareInbox ─→ ShareBatches ─→ ShareRelay（纯）
 │              └→ ShareRelay
 ├─→ AppUpdater ─→ InstallStatusReceiver
 └─→ Shell（底层，谁都能引，它不引产品文件）
```

`ShellBoundaryTest` 守着这张登记表：产品源码（`src` 下各非测试源码集）正好是表里的文件、只引登记的（去掉注释和字符串再找）、没有循环；`WebRules`、`BackKey`、`ShareRelay` 只引 JDK（`WebRules` 另许 `WebViewClient` 的错误码），所以能在 JVM 里测。

## 两个版本

| | 正式版（release） | 测试版（debug） |
|---|---|---|
| 网址 | `https://erp.nbyongle.cn/`（`app/build.gradle.kts`） | `gradle.properties` 的 `erpTestUrl`，或 `-PerpTestUrl=…` |
| 更新清单 | `releaseUpdateUrl`（已填正式地址；空 = 不检查） | `testUpdateUrl`（`http://127.0.0.1:8787/update/manifest.json`） |
| 包名、名字 | `cn.nbyongle.erp`，甬勒ERP | `cn.nbyongle.erp.test`，甬勒ERP测试（可和正式版同装） |
| 明文 HTTP | 不许 | 只许 127.0.0.1、localhost |

网址经 `BuildConfig.ERP_URL`、`BuildConfig.UPDATE_URL` 进代码，运行时不能切换。

## 清单和权限

- 权限只有 `INTERNET` 和 `REQUEST_INSTALL_PACKAGES`（更新交给系统安装器，用户仍要确认）；拍照、存文件不要权限。
- `MainActivity`：唯一导出的组件，`singleTask`、`adjustResize`。入口：桌面图标、分享（`SEND`、`SEND_MULTIPLE`）、用其他应用打开（`VIEW`，只收 `content:`）；后两种只收 PDF、JPG、PNG、XLS、XLSX、DOC、DOCX。
- `InstallStatusReceiver` 不导出；`allowBackup=false`；开 `enableOnBackInvokedCallback`（13 起的返回手势）。

## 行为和实现

**整屏网页：** 单个 `Activity` 加 `WebView`。User-Agent 末尾加 ` YongleErpAndroid/<版本>`，网页凭它认出 App（单元测试核对版本名合网页的正则）。

**网址分流**（`WebRules.routeOf`）：协议、主机、端口都和 ERP 相同的留在应用里；别的 http(s) 交给系统（`ACTION_VIEW`）；其余协议不打开。主框架跳转在 `shouldOverrideUrlLoading` 判，管不到的（如表单 POST）在 `onPageStarted` 再判：不是站内就停下、站外交给浏览器、回上一页。

**通道**（`BridgeChannel`）：ERP 页面加载完（`onPageFinished`，页内换 `#` 不重接）建一对端口，用 `postWebMessage` 把接通消息和一个端口发给 ERP 来源的主页面；网页回 `bridge-ready` 才算接通；`onPageStarted` 时关旧端口。

**返回键：** 13 起用 `OnBackInvokedCallback`，12 及以下 `onBackPressed`。`BackKey.stepOf`：
- 盖着离线页 → 按首页处理；
- 通道接通 → 发 `back` 问网页，只认正在等的编号、认一次作废，回 `home` 才按首页处理；
- 没接通（图片原件这类非 ERP 页、页面加载中、ERP 是没通道的旧版本）→ 能后退就后退，否则按首页处理。

按首页处理 = 提示“再按一次返回退出”，2 秒内再按才退出。

**文件选择**（`FileChooser`）：
- `accept` 换成 MIME 交给系统“文件”（`ACTION_OPEN_DOCUMENT`）；收图片时另给“相册”“拍照”。
- 拍照先用 `MediaStore` 建一条相册记录交给相机（不要相机权限），存进“Pictures/甬勒ERP”。每次打开前删上次没用的占位，没拍成、打不开选择器也删；删不掉（vivo 安卓 16 抛 SecurityException）只记日志，相册里可能留一张空图。
- 结果去掉空地址；相机回“成功”却一字节没写的不交（读第一个字节判断，不看相册“大小”列，它异步更新；读不了照常交）。取消也交回 null，网页能再点。

**分享接收**（`ShareInbox`、`ShareBatches`、`ShareRelay`）：
- 上一批正在传（网页回过 `share-ready`）→ 提示“还在传”，不收。
- 后台单线程复制进缓存：一次最多 20 份，单份上限 10MB（和 AI 导入一致，大于才拒）。没收下的分“格式不支持 / 超过 10MB / 读不到”提示；名字和类型都没给（多半没给读权限）算读不到。
- 外来的一律不可信：交来的地址逐个按类型筛，混进别的类型就跳过，解包和筛选都接住异常；名字清洗（只取最后一段、去控制字符、UTF-8 不超过 255 字节）后只给网页看，落盘只用“序号.扩展名”并核对在这一批目录里；对方抛任何异常都只算这一份读不到。
- 每批一个目录 `cache/share/编号/`，复制完写 `batch.json`。`onCreate`（新启动、进程恢复、重建）读清单接着交，清掉没清单的旧目录；从“最近任务”重开时重发的旧分享（`FLAG_ACTIVITY_LAUNCHED_FROM_HISTORY`）不收。
- `ShareRelay` 按通道约定逐份交：读文件和 base64 在后台做好再回主线程发；到头自己收尾（有没传上的就提示、删目录）；网页回绝就提示原因、收尾；被替换的一批删缓存。只上传，不自动识别。
- 哪些提示由外壳说、哪些由网页说，见通道约定的“提示分工”。

**保存文件**（`FileSaver`）：网页导出的订货单、送货单是内存里的 `blob:`，系统下载器取不到，网页经通道发 `save-file`。按通道约定核对（名字用同一个清洗函数，上限 20MB），后台存进“下载”（`MediaStore.Downloads`，不要存储权限；先占待定记录、写完再放开，放开失败也算失败，出错删记录），提示“已保存到‘下载’：文件名”（重名用系统改的名）。`save-result` 绑在收到请求的端口上，页面换了就不发。例外：保存中 Activity 重建（如切深色模式），文件照样存好但不回复不提示，网页按失败处理，再存一次会多一份改了名的。

**应用内更新**（`AppUpdater`）：
- 冷启动先清缓存里用不着的旧安装包，再后台读一次清单（`UPDATE_URL` 空就不查；最多 64KB；连接、读取各等 15 秒）。`versionCode` 更大、地址是 http(s)、带 64 位 sha256 才弹“发现新版本”。
- “下载并安装”：有进度、能取消，最多 100MB，边下边算 sha256；对不上、包名或版本号和清单不符都删掉不装；取消、失败删半截文件；刚下完点了取消也不装。
- 没允许“安装未知应用”：待装版本记进 SharedPreferences、带去系统设置（打不开就提示自己去开），回到前台（含进程被收回后）接着装。待装记录只在后台那一条线程上读写，冷启动时排在清旧包之后，不会被当旧包删。
- 交给 `PackageInstaller` 写会话，出错就放弃会话。结果由 `InstallStatusReceiver` 收：只打开 `android.content.pm.action.CONFIRM_INSTALL`，去掉一切授权标志再打开，打不开或没装上就提示（用户自己取消的不提示）。
- 查不到、出错只记日志或提示，不影响打开 ERP。

**启动动画**（`LaunchScreen`，layout 最上层的 `launch`）：等窗口打开动画放完（`onEnterAnimationComplete`，最晚 0.8 秒）才放 `splash_logo.xml`（Y、L 从两边靠拢 0.9 秒合成商标），网页同时在后面加载。至少放 1.3 秒、且 ERP 加载完（或盖上离线页，最多等 5 秒）后，0.2 秒淡出图标、再 0.2 秒淡出底色。系统启动画面只铺同色的底、不放图标（`values-v31/themes.xml`），因为 vivo 等系统上它和启动缩放叠在一起看不到。从后台切回、进程恢复不重播。

**滑到头的拉伸：** WebView 自带的拉伸会带着固定顶栏、底部导航变形，用 `setOverScrollMode(OVER_SCROLL_NEVER)` 关掉；网页自己只拉伸内容区。

**连不上和证书：** 主框架加载失败（“协议不支持”“网址写错”除外）、网关 502/503/504、ERP 自己的证书错误 → 盖“暂时无法连接 ERP”和“重试”。`onReceivedSslError` 一律 `cancel()`，站外资源的证书错误只取消、记日志。

**渲染进程没了**（`onRenderProcessGone`）：不处理整个应用会崩。销毁旧 WebView、换新的，接着由 `WebRules.afterRendererGone` 定：
- 窗口看不见时没了（多半是系统收回内存）→ 等 `onStart` 再开刚才的页，不算“自动重开”；
- 看得见时，刚自动重开的那一页（之后没去过别的页）又没了 → 多半是页面自己弄崩的，盖离线页，“重试”回 ERP 首页，不再自动重开；
- 否则重开刚才的站内页（没有就首页），记下“自动重开过这一页”。

**下载：** http(s) 交给 `DownloadManager` 存进“下载”（带 UA，只有站内网址带 Cookie）；它抛异常（目录建不出、被停用）只提示。`blob:`、`data:` 取不到，只提示（网页导出走“保存文件”）。

**系统栏颜色**（`SystemBars`）：11 起窗口画到系统栏后面，网页让位，上下各垫一条色带；每次重画后（最多每 250 毫秒）用 `PixelCopy` 取网页最上、最下一行的颜色，并切换图标深浅。窗口看不见（`onStop` 到 `onStart`）不取色；取色报错只跳过这次。

**转屏、登录保持、备份：** `configChanges` 含转屏、屏幕尺寸、键盘、字号、密度，这些不重建页面；**切深色模式（含定时切）、改语言、开关粗体字仍会重建、整页重载**，没保存的表单会丢（分享、待装更新已落盘，接着办）。`CookieManager.flush()`；`allowBackup=false` 加两份什么都不备份的规则。

## 安全边界

- 外壳不调 ERP 接口、不查页面元素、不注入脚本；只在把站内文件交给系统下载器时带上这个网址的 Cookie。
- 和网页只有一条通道：`postWebMessage` 目标来源限定为 ERP（系统只投给这个来源的主页面），端口上只认通道约定里的消息；没有 `addJavascriptInterface`、`addWebMessageListener`。
- 关掉文件访问、内容访问，禁止混合内容。
- 分享来的名字、内容、异常都不可信：名字不进路径，落盘位置核对在缓存目录里。
- 只有 `MainActivity` 导出；安装结果接收器不导出，打开确认页前核对 action、去掉授权标志。
- 系统只装同包名、同签名的更新，装不装由用户确认。sha256 和清单在同一处，只防传输损坏，不是安全边界；包名、版本号核对防清单写错。

## 依赖

- 运行时：**没有第三方库**，只用安卓 SDK 和 JDK。AGP 9 默认把 kotlin-stdlib 打进安装包，`gradle.properties` 用 `kotlin.stdlib.default.dependency=false` 关掉；`checkNoRuntimeLibraries`（挂在 `check` 上）断言两种构建的运行时依赖为空。
- 构建：AGP 9.5.1、Gradle 9.9.1（wrapper 带 sha256 校验）、JDK 21、compileSdk/targetSdk 36、minSdk 29（安卓 10）。
- 只用于检查和测试：Checkstyle 14.4.0、JUnit 4.13.2。
