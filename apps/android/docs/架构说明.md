# 架构说明

安卓外壳的代码怎么分、每个行为怎么做、安全边界和依赖。和网页之间的消息（有哪几条、字段、谁回什么）只写在 ERP 项目 `docs/架构说明.md`“安卓 App 通道”，这里只写外壳这头的实现；怎么构建、测试、打包见[构建与测试](构建与测试.md)。

## 分层和登记表

只往下引，没有循环：

```
MainActivity（入口）
 ├─→ WebRules、BackKey          纯规则
 ├─→ SystemBars、BridgeChannel、FileSaver、FileChooser、LaunchScreen
 ├─→ ShareInbox ─→ ShareBatches ─→ ShareRelay（纯）
 │              └→ ShareRelay
 ├─→ AppUpdater ─→ InstallStatusReceiver
 └─→ Shell（底层，谁都能引，它不引任何产品文件）
```

`ShellBoundaryTest` 守着：产品源码正好是登记表里的文件（`src` 下除测试以外的各源码集都算），每个文件只引登记的产品文件（去掉注释和字符串再找），登记表没有循环；`WebRules`、`BackKey`、`ShareRelay` 只引 JDK（`WebRules` 另许 `WebViewClient`，只用它的错误码常量），所以不靠 `Activity` 就能在 JVM 里测。

## 清单和权限

- 权限只有两个：`INTERNET`；`REQUEST_INSTALL_PACKAGES`（应用内更新把新版交给系统安装器，用户仍要在系统页面确认）。拍照、存文件都不要权限（见下面“文件选择”“保存文件”）。
- `MainActivity`：`singleTask`、`adjustResize`（键盘弹出时网页让位），唯一导出的组件；入口有桌面图标、“分享”（`SEND`、`SEND_MULTIPLE`）、“用其他应用打开”（`VIEW`，只收 `content:`），后两种只收 PDF、JPG、PNG、XLS、XLSX、DOC、DOCX。
- `InstallStatusReceiver` 不导出；`allowBackup=false`；安卓 13 起的返回手势开 `enableOnBackInvokedCallback`。

## 行为和实现

| 行为 | 怎么做的 |
|---|---|
| 整屏网页 | 单个 `Activity` 加 `WebView`，没有任何浏览器界面；User-Agent 末尾加 ` YongleErpAndroid/<版本>`，网页凭它知道在 App 里（单元测试核对版本名合网页那条正则） |
| 网址分流 | `WebRules.routeOf`：协议、主机、端口都和 ERP 网址相同的留在应用里；别的 http(s) 交给系统（`ACTION_VIEW`）；其余协议不打开。主框架跳转在 `shouldOverrideUrlLoading` 判；它管不到的（表单 POST 这类）在 `onPageStarted` 再判一次，不是站内就停下、站外交给浏览器、回到上一页 |
| 和网页的通道 | `BridgeChannel`：ERP 页面加载完（`onPageFinished`，页内换 # 不重接）建一对端口，`postWebMessage` 把接通消息和一个端口发给 ERP 来源的主页面；网页回 `bridge-ready` 才算接通，页面重新加载（`onPageStarted`）就关掉旧端口。消息约定（返回键、分享、保存文件各有哪几条、字段、谁回什么）只写在 ERP 项目的 `docs/架构说明.md`“安卓 App 通道”，这里只写外壳这头怎么做 |
| 返回键 | 安卓 13 起登记 `OnBackInvokedCallback`，12 及以下走 `onBackPressed`。`BackKey.stepOf`：盖着离线页时按首页处理；通道接通了就发 `back` 问网页，回执只认正在等的那个编号、认一次就作废，`home` 才按首页处理；**没接通**（点开了图片原件这类不是 ERP 的页面、页面还在加载、ERP 是没有通道的旧版本）时 WebView 能后退就后退，不能就按首页处理。按首页处理是提示“再按一次返回退出”，2 秒内再按才退出，不会误退 |
| 文件选择 | `FileChooser`：按 `accept` 换成 MIME 类型交给系统“文件”（`ACTION_OPEN_DOCUMENT`，只开文件管理器）；收图片时选择器里另给“相册”“拍照”，拍照先用 `MediaStore` 建一条相册记录交给相机（不要相机权限），存进“Pictures/甬勒ERP”。每次打开前先删上一次没用掉的占位；没拍成、打不开选择器也删掉——有的系统不让删（vivo 安卓 16 实测抛 SecurityException），删不掉只记日志，可能在相册里留一张空图。选择结果去掉空地址；相机回了“成功”却一个字节都没写的照片不交（打开读第一个字节判断，不看相册的“大小”一列——系统异步更新，刚拍完可能还是 0；读不了就照常交回，不删可能拍成的照片）。取消也把 null 交回网页，网页能再点 |
| 分享接收 | 入口见上面“清单和权限”。`ShareInbox` 先看上一批是不是正在传（网页回过 `share-ready`），是就提示“还在传”不收；再在后台单线程复制进缓存（一次最多 20 份；单份上限 10MB，和 ERP 的 AI 导入一致，大于就拒、等于照收），没收下的按“格式不支持 / 超过 10MB / 读不到”分开提示（对方连名字、类型都没给——多半是没给读权限——算读不到，不说成格式不支持）。哪些提示由外壳说、哪些由网页说，见通道约定的“提示分工”。别的应用给的东西一律当不可信：交来的地址逐个按类型筛（混进 Intent、Bundle 这类别的东西就跳过），解包和筛选都接住异常；名字清洗后（只取最后一段、去掉控制字符、按 UTF-8 不超过 255 字节）只给网页看，落盘只用“序号.扩展名”并核对落在这一批的目录里，对方抛什么异常都只算这一份读不到。每批一个目录 `cache/share/编号/`，复制完写清单 `batch.json`（`ShareBatches`）；`onCreate`（新启动、进程恢复、Activity 重建）都读清单接着交，清掉没有清单的旧目录；从“最近任务”重开时系统重发的旧分享（带 `FLAG_ACTIVITY_LAUNCHED_FROM_HISTORY`）不收。交给网页由 `ShareRelay` 推进（一批怎么交、重连从头来、没开始的可替换，按通道约定）：读文件和 base64 在后台做好再回主线程发；到头由外壳自己收尾（有没传上的就提示、删整个目录）；网页回绝就提示网页给的原因、收尾；被替换的一批删旧缓存。只自动上传，不自动识别 |
| 保存文件 | ERP 导出的订货单、送货单是网页内存里的文件（`blob:`），系统下载器取不到，网页改经通道发 `save-file`。`FileSaver` 按通道约定核对请求（名字用和分享同一个清洗函数；上限 20MB），在后台存进系统“下载”（`MediaStore.Downloads`，安卓 10 起不要存储权限；先占一条待定记录，写完再放开，放开没成功也算失败，出错都删掉这条记录），提示“已保存到‘下载’：文件名”（重名时用系统改过的名字）。`save-result` 绑在收到请求的那个端口上，页面换了就不发。例外：正在保存时 Activity 重建（切深色模式这类），文件照样存好，但既不回复也不提示（页面已经重新加载，网页按失败处理），用户再存一次会多出一份系统改了名的 |
| 应用内更新 | `AppUpdater`：冷启动先清掉缓存里用不着的旧安装包，再后台读一次版本清单（`UPDATE_URL`，空就不查；清单最多 64KB；连接和读取各最多等 15 秒），`versionCode` 更大、地址是 http(s)、带 64 位 sha256 才弹“发现新版本”；点“下载并安装”在应用里下载（有进度、能取消，安装包最多 100MB），边下边算 sha256，对不上、包名或版本号和清单不符都删掉不装，取消和失败也删掉下了一半的文件，刚下完时点了取消也不装。没允许“安装未知应用”时先把待装的版本记进 SharedPreferences、带去系统设置（打不开设置就提示自己去开），回到前台（进程被收回过也一样）接着装；待装记录只在后台那一条线程上读和改，冷启动时一定排在清旧包后面，不会把待装的包当旧包删掉。交给 `PackageInstaller` 写会话，写的时候出错就放弃会话；结果由清单里登记、不导出的 `InstallStatusReceiver` 收：只打开系统的安装确认页（`android.content.pm.action.CONFIRM_INSTALL`），去掉一切授权标志再打开，打不开就提示没装上；没装上就提示（用户自己取消的不提示）。查不到、出错只记日志或提示，不影响打开 ERP |
| 启动动画 | App 自己的启动画面（layout 里盖在最上面的 `launch`，`LaunchScreen`）：等窗口打开动画放完（`onEnterAnimationComplete`，最晚 0.8 秒）才放 `splash_logo.xml`（Y、L 两个图形从两边靠拢 0.9 秒，合成 YL 商标），网页同时在后面加载；至少放 1.3 秒、且 ERP 页面加载完（或盖上离线页，最多等 5 秒）后，先 0.2 秒淡出图标（底色还盖着），再 0.2 秒淡出底色露出网页。不用系统启动画面放动画（vivo 等系统上它和启动缩放叠在一起看不到），系统那层只铺同色的底、不放图标（`values-v31/themes.xml`），看不出交接。从后台切回、进程恢复都不重播 |
| 滑到头的拉伸 | WebView 自带的拉伸是对整个视图做的，固定的顶栏、底部导航会跟着变形，所以 `setOverScrollMode(OVER_SCROLL_NEVER)` 关掉；ERP 网页在 App 里自己只拉伸中间的内容区 |
| 连不上 | 主框架加载失败（除“协议不支持”“网址写错”）、网关 502/503/504、ERP 自己的证书错误时，盖一层“暂时无法连接 ERP”和“重试” |
| 证书 | `onReceivedSslError` 一律 `cancel()`；只有 ERP 来源的证书错误才盖离线页，站外资源（比如网页里引用的外部图片）只取消、记日志 |
| 渲染进程没了 | `onRenderProcessGone`：渲染进程崩了或被系统收回时（不处理整个应用会跟着崩），移除、销毁旧 WebView，换一个新的。接着怎么办由 `WebRules.afterRendererGone` 定：应用在后台（窗口看不见）时没了，多半是系统收回内存、跟页面无关，等 `onStart` 再开刚才的页面，这次补开不算“自动重开”；窗口看得见时没了，如果是外壳刚自动重开的那一页（之后没去过别的页）又没了，多半是这一页自己把它弄崩的（不管它加载要多久），盖离线页让人点“重试”（回 ERP 首页），不再自动重开，否则重新打开刚才的站内页面（没有就 ERP 首页）并记下“自动重开过这一页” |
| 下载 | http(s) 交给系统 `DownloadManager` 存进“下载”（带 UA；只有站内网址带 Cookie）；系统下载器抛异常（“下载”目录建不出、下载管理器被停用）时只提示；`blob:`、`data:` 系统下载器取不到，只提示（网页导出走上面的“保存文件”） |
| 系统栏颜色 | `SystemBars`：安卓 11 起窗口画到系统栏后面，网页让出系统栏位置，上下各垫一条色带，每次重画后（最多每 250 毫秒一次）用 `PixelCopy` 读网页最上、最下一行的颜色给色带，并切换图标深浅；窗口看不见（`onStop` 到 `onStart`）时不取色，取色时系统报错只跳过这一次 |
| 转屏、登录保持、备份 | `configChanges` 包含转屏、屏幕尺寸、键盘、字号、密度这几种，这几种变化不重建页面；**切换系统深色模式（包括按时间自动切换）、改系统语言、开关粗体字仍会重建 Activity、整页重新加载**，表单里没保存的内容会丢（分享、待装的更新有落盘，接着办）。`CookieManager.flush()`；`allowBackup=false` 加两份不备份任何数据的规则 |

## 安全边界

- 外壳不调 ERP 的接口、不查页面元素，不注入脚本。只在交给系统下载器下载站内文件时读这个网址的 Cookie 放进请求头（站外网址不带）。
- 和网页只有一条通道：`postWebMessage` 的目标来源限定为 ERP 来源（系统只投给这个来源的主页面），端口上只认 ERP 项目文档里登记的几种消息；没有 `addJavascriptInterface`、`addWebMessageListener`。
- 关掉文件访问、内容访问，禁止混合内容。
- 别的应用分享来的文件名、内容、异常都当不可信：名字不进文件路径，落盘位置核对在缓存目录里。
- 只有 `MainActivity` 导出（桌面图标和分享要用）；安装结果接收器不导出，打开系统给的确认页前核对 action、去掉授权标志。
- 更新包要同一包名、同一签名系统才肯装，装不装由用户在系统页面确认。外壳核对的 sha256 和清单在同一处，只防传输损坏，不是安全边界；包名、版本号核对防清单写错。

## 依赖

- 运行时：**没有第三方库**，只用安卓平台 SDK 和 JDK。AGP 9 自带的 Kotlin 支持默认会把 kotlin-stdlib 加进运行时依赖、打进安装包，`gradle.properties` 用 `kotlin.stdlib.default.dependency=false` 关掉；`app/build.gradle.kts` 的 `checkNoRuntimeLibraries`（挂在 `check` 上）断言两种构建的运行时依赖解析出来是空的。
- 构建：Android Gradle Plugin 9.5.1、Gradle 9.9.1（wrapper，带 sha256 校验）、JDK 21、compileSdk/targetSdk 36、minSdk 29（安卓 10）。
- 只用于检查和测试：Checkstyle 14.4.0、JUnit 4.13.2。
