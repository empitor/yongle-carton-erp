# Windows 外壳文档

甬勒ERP 的 Windows 员工客户端（Tauri 2）：安装目录里只有一个程序 `甬勒ERP.exe`，它把同目录的客户端核心 `yongle_erp_core.dll` 加载进自己的进程运行，网址等设置在 `config\`、自带页面在 `pages\`；核心用独立窗口打开 ERP 网页，连不上时显示自带的离线页，点 × 收进托盘，托盘左键恢复，右键“显示”“重新载入”“检查更新”“开机自动启动”“退出”；再次启动只唤起已开的窗口。外壳和 ERP 唯一的接点是配置的网址。

它不是 ERP 的“Windows 本机安装包”：本机安装包带着 Node、服务端和数据，在本机跑 `http://127.0.0.1:3001`；这个客户端只是一个窗口，没有服务端、没有数据，只连正式域名。

本目录自成一体：不引用 ERP 项目和 `apps/android/` 的任何文件，单独复制出去也能构建和测试。
