# Windows 外壳文档

甬勒ERP 的 Windows 员工客户端（Rust + Tauri 2）：安装目录里只有一个程序 `甬勒ERP.exe`，它把同目录的核心 `yongle_erp_core.dll` 加载进自己的进程；网址等设置在 `config\`，自带页面在 `pages\`。

- 独立窗口打开 ERP，连不上显示自带的离线页；点 × 收进托盘，托盘左键恢复，右键“显示”“重新载入”“检查更新”“开机自动启动”“退出”；再次启动只唤起已开的窗口。
- 和 ERP 唯一的接点是配置的网址：没有消息通道（只有安卓 App 有），导出的文件走 WebView2 自己的下载。
- 它不是 ERP 的“Windows 本机安装包”（那个带 Node、服务端和数据，在本机跑 `http://127.0.0.1:3001`）；这里没有服务端和数据，只连正式域名。

- 本目录自成一体：不引用 ERP 项目和 `apps/android/` 的文件，单独复制出去也能构建测试。
- 检查：ERP 项目根目录 `npm run check:apps -- desktop`。
- AI 实测时不运行安装包、不动本机装的测试版（`%LOCALAPPDATA%\甬勒ERP测试`）、不改开机启动项：“安装验证”由人做；端到端测试会弹窗口、动鼠标，跑之前先问用户。
