# 功能链路：识别导入

什么时候读：加改收件箱、消息机器人、AI 识别导入、语音的页面、地址、助手工具时，查它走哪些页面、地址、工具。

表的写法（地址缩写、页面和工具列）相关的见 `.claude/skills/add-feature/SKILL.md`“功能链路表”。

| 功能 | 页面 | 后端地址 | 助手工具 |
|---|---|---|---|
| 收件箱 | `#inbox` | `/inbox`（带 `/:id`）、`POST /inbox/upload`、`/inbox/:id/file`、`POST /inbox/:id/convert`、`/inbox/:id/status` | `inbox.list`（传 `id` 读全文）、`inbox.add`、`inbox.set_status`、`order_import.from_inbox` |
| 消息机器人 | `#ai-settings?tab=channels`（管理员） | `/inbox/channels`、`/inbox/bots`、`POST /inbox/bots/:channel`（改要超级管理员模式） | 无 |
| 订单识别与正式导入 | `#ai-import` | `/ai/imports`（带 `/:id`、`/:id/file`）、`POST /ai/imports/upload`、`/ai/imports/:id/mode\|enqueue\|analyze\|edit\|undo\|mapping\|cancel`、`/ai/imports/:id/matches\|standard-order\|preview\|execute` | `order_import.list\|get\|start\|retry\|select\|edit\|match\|attach\|preview\|execute\|undo` |
| 到货单识别 | `#ai-import` 选到货单；到货页“AI 识别送货单” | `POST /ai/imports/:id/arrival/recognize`、`/ai/imports/:id/arrival/link`、`GET /flow/sources/:sourceId`、`/flow/sources/:sourceId/file`；挂订货单的存盘走 `POST /order-batches/:id/receive`（`pending:true`） | `arrival.recognize` |
| 识别工作区管理（归档、永久删除、错误档案、读不出的文件） | `#ai-import` 列表提示和“更多 → 历史与归档”；数据管理“AI识别工作区” | `POST /ai/imports/batch`、`/ai/imports/delete-many`（本机管理员）、`/ai/imports/diagnostics`（带 `/:failureId`）；`/management/workspaces`（`POST` 只有复制、打开） | `management.workspaces` |
| 语音输入、朗读 | 助手输入框 | `POST /assistant/transcribe`、`/assistant/speak` | 无 |

- **正式导入**带 `expectedRevision` 和预览的 `previewDigest`；回执只有 `ImportReceipt` 十项，不含服务器路径和操作人。
- **`order_import.start`** 识别本会话的附件或文件任务（含收件箱转来、关联进来的），识别过的复用原结果、不重复收费。**`execute`** 一份或几份一张卡片，写明客户和每行产品用已有档案还是新建，新建的列出相近的已有档案。

**进件路线：**

```text
企业微信、飞书、钉钉机器人 / 手动上传 / 粘贴 → 收件箱
收件箱 → 转订单 → AI 导入（客户订单）→ 人核对 → 正式订单
       → 转到货 → AI 导入（到货单）  → 人核对 → 待入库的到货单 → 核对入库
       → 新建订单（文字或不可识别格式的文件）→ 本页打开订单编辑窗 → 正式订单并由识别导入标收件已处理
安卓 App 分享 → src/app-bridge.ts → src/import/app-share.ts → useUploadQueue 的 upload → POST /api/ai/imports/upload → AI 导入（待识别）
唛头：产品详情里直接上传，整份文件挂到产品下，不识别
```

转单和分享都只把原件放进 AI 导入，不自动识别、不发给模型。分享的消息约定见[外壳和网页](../架构/外壳和网页.md)“安卓 App 通道”。
