# 功能链路：财务

什么时候读：加改财务的页面、地址、助手工具时，查财务各功能走哪些页面、地址、工具。

表的写法（地址缩写、页面和工具列）相关的见 `.claude/skills/add-feature/SKILL.md`“功能链路表”。

- 地址都在 `/api/finance` 下，要 `finance:view`，写入另按财务权限分；助手的财务工具全部只读。
- 路由：`server/finance/routes.ts`（设置、凭证账簿、业务单据、概览台账）、`routes-cash.ts`（应收应付、资金发票）、`routes-period.ts`（费用资产工资、报表结账）。导出 Excel、归档包、原件和三个上传用 express 注册。
- 每个财务请求和助手的财务查询之前，先补扫还没进财务的业务单据（`server/finance/events/catch-up.ts`）。
- 选客户、供应商的下拉读 `GET /parties`（`src/finance/fields.tsx`；收付款、凭证录入、账期、启用期初、补税率、对账单都用），出纳也能读。

| 功能 | 页面 | 后端地址（`/finance` 下） | 助手工具 |
|---|---|---|---|
| 财务概览、经营报表 | `#finance`；今日页“货款到期”；订单、送货、到货详情的“财务”段 | `/summary`、`/monthly-report`（`/detail`、`/trend`、`/export`）、`/due-soon`、`/related/:kind/:id`、`/reports/dashboard` | `finance.summary` |
| 月度台账、补税率 | `#finance-flow` | `/monthly-ledger`（`/export`）、`POST /tax-completion/batch`、`POST /events/:id/resolve` | `finance.monthly` |
| 应收应付、账期、对账单 | `#finance-ar` | `/obligations`（`/:id/bad-debt`、`/:id/due`、`/transfer-credit`）、`/held`、`/aging`、`/payment-plan`、`/due-recalculation`、`/discount-opportunities`、`/statements`（`/export`）、`/party-terms`（`/:kind/:id`） | `finance.receivables`、`finance.payables` |
| 保证金、压款利息 | `#finance-ar` | `/deposits`、`POST /deposits/:id/actions`、`/interest`、`POST /interest/confirm` | 无 |
| 收付款和核销 | `#finance-cash` | `/cash/accounts`、`/cash/daily`、`/cash/documents`（`/:id/confirm\|cancel\|allocate\|suggestions`）、`POST /allocations/:id/revoke` | `finance.cash` |
| 银行流水、票据 | `#finance-cash` | `POST /bank/upload`、`/bank/rows`（`/:id/suggestions`、`/:id/match`）、`/bank/reconcile`（`/export`）、`/notes`（`/:id/status`、`/:id/allocate`） | 无 |
| 发票、税务底稿 | `#finance-cash` | `/invoices`（`/:id/links`、`/:id/confirm`、`/:id/status`）、`/invoice-matching`、`/tax`（`/export`）、`POST /attachments/upload`、`/attachments/:id` | `finance.invoices` |
| 费用、资产、工资、成本 | `#finance-costs` | `/expenses`（`/:id/transition`）、`POST /employee-advances`、`/assets`（`/:id/dispose`）、`/depreciation`（`/export`）、`/payroll`（只读列表，及 `/upload`、`/confirm`、`/pay`、`/payment`）、`/costing`（`/requirements`）、`/margin` | 无 |
| 凭证、账簿、财务事件 | `#finance-ledger`；来源详情“更多”里撤回或红冲来源生成的凭证（`src/finance/source-voucher.tsx`） | `/vouchers`（`/:id/submit\|approve\|post\|void\|reverse`）、`POST /source-vouchers/:id/withdraw\|reverse`、`/books/:kind`（`/export`）、`/events`、`POST /events/:id/generate\|correct\|acknowledge`、`/audit` | `finance.ledger` |
| 报表、结账、预算、归档 | `#finance-reports` | `/reports/readiness`、`/reports/:kind`（`/export`）、`/closing`（`POST /tax\|profit\|close\|reopen`）、`/budgets`、`/archive/download` | `finance.reports` |
| 财务设置、科目、期初 | `#finance-settings` | `/settings`、`/accounts`、`/periods`、`/opening`、`POST /opening/enable`、`/templates` | 无 |

- 来源生成凭证的有票据、资产处置、费用、坏账、压款利息、保证金。
- `/reports/readiness` 和结账检查同一个口径，还没同步进财务的单据也拦，`unsyncedSources` 列出是哪几张；`src/finance/reports/unsynced.tsx` 读它提示，概览、月度台账、业务单据页也用。
