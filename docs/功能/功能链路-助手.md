# 功能链路：助手

什么时候读：加改助手的聊天、附件、确认卡片、记忆、看页面、联网、排查的入口、地址、工具时，查它走哪些入口、地址、工具。

表的写法（地址缩写、页面和工具列）相关的见 `.claude/skills/add-feature/SKILL.md`“功能链路表”。

| 功能 | 入口 | 后端地址 | 助手工具 |
|---|---|---|---|
| 聊天、会话 | 顶栏助手按钮（`Ctrl+J`；手机在底部导航） | `GET /assistant`、`POST /assistant/threads`、`/assistant/threads/:id`、`POST /assistant/threads/:id/chat\|cancel\|clear\|delete` | `chat.list`、`chat.delete` |
| 聊天附件 | 助手输入框 | `POST /assistant/threads/:id/attachments`（`/cancel-upload`）、`/assistant/attachments/:id/file`、`POST /assistant/attachments/:id/delete` | 无（附件随这一句发给模型） |
| 确认卡片 | 回复里的卡片（`src/assistant/AssistantReview.tsx`；内容由 `server/assistant/tools/card-summary.ts` 写） | `POST /assistant/previews/:id/execute`（只执行一次）、`/assistant/previews/:id/reject`、`/assistant/previews/:id/inventory-policy` | 所有写入命令 |
| 长期记忆 | 助手“更多 → 记忆”；回复下面已记住的每条后的“忘掉”（`src/assistant/AssistantExecuted.tsx`） | `/assistant/memory`（`GET` 列表、`POST` 新加）、`POST /assistant/memory/settings\|clear`、`POST /assistant/memory/:id`、`/assistant/memory/:id/delete` | `memory.search`、`memory.save`、`memory.update`、`memory.forget`、`memory.auto` |
| 看页面、打开页面 | 当前标签页 | `POST /assistant/page/results` | `page.observe`、`ui.open` |
| 联网查资料 | 回答下面的“来源 N 个” | 无（经 `server/ai/web.ts`） | `web.search`（一次 1 到 10 个词）、`web.read`（一次 2 万字，`offset` 接着读） |
| 排查问题（只读） | 助手 | 页面出错上报 `POST /diagnostics/page-problems`（出纳也能报） | `diagnostics.errors`、`history.records`、`jobs.status`、`ai.status`、`guide.read`；超级管理员另有 `logs.read`、`accounts.events`、`source.search`、`source.read` |

- 模型经三个通用工具 `find_command`、`command_usage`、`run_command` 查找、查用法、执行命令（`server/assistant/command-directory.ts`）。
- 确认或拒绝卡片后，前端带 `card: { id, decision }` 再发一次 `/threads/:id/chat`，助手接着办；回复下面一行写这一轮实际做了什么。
- `page.observe` 只看标题、正文、表格、弹窗、提示、选中的项、当前记录。
