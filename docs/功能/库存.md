# 库存

什么时候读：改库存流水和余额、库存品、采购单和采购明细，或改本机管理员改库存品、采购明细的连带时。

库存余额怎么来、谁写流水、两种视图、保存入口和“同一种货一个库存品”怎么守。库存的业务规则（只由流水派生、不能负库存、改写留修订）相关的见 `docs/业务规则.md`；采购已到货、登记到货相关的见 `docs/功能/单据流转.md`。

## 库存流水和余额

- **是什么：** 余额只由 `stock_movements` 派生。流水只追加，数量是千分单位整数；更正靠冲销和替代流水；数量为 0 的只有盘点能记。
- **谁写：** 流水、库存品和采购单的版本号、采购明细只由 `server/operations/ledger/ledger.ts` 写（别的模块经 `stockLedger` 调）；删除和初始化时由 `server/operations/deletion.ts` 写，删流水时给相关库存品加版本号，看过的预览随之作废。管理员改写、删除流水留 `stock_movement_revisions`。三种 JSON 列（库存品规格、订货单到货安排、修订记录）的结构在 `shared/business/operations/operations-stored.ts`，读写都按严格结构核对。
- **两种视图：** 基本视图（只有采购库存自己的数据，采购单已到货读缓存）在 `shared/business/operations/operations-views.ts`，`OperationsService` 读。完整视图（采购单现算已到货、带到货记录；库存品带已安排和可用；订货单带到货单；流水带来源单号）在 `shared/business/flow/stock-flow-views.ts`，由单据流转的 `FlowService.views` 拼。
- **保存只走一个入口：** 保存采购单、库存品，改采购单状态，手工出入库只走单据流转的 `server/flow/stock/stock-entries.ts`（`FlowService.stock`），页面、助手、数据管理、单据导出、脚本都用它。
- **同一种货一个库存品：** 撞上已有的回 409 `stock-exists`。完工按产品取成品库存（`finishedStockFor`，没有就建、归档的恢复）；到货没选库存品按查重键用已有原材料（`rawStockFor`）。查重和规格比对只用 `shared/business/operations/stock-identity.ts`。订单服务改产品时，在同一个保存点调用采购库存的 `syncFinishedStock` 更新关联成品库存。
- **用过的库存品：** 有流水或被单据、采购明细引用的，不能改种类，成品不能改关联产品，对所有账号生效；判断只在单据流转的 `StockViews.usages`。
- **成品批次不存表：** 每笔有效的完工入库算一批，剩余按流水推算（`shared/business/flow/stock-batches.ts`）；批次备注就是完工单的 `notes`，用说明编辑改。
