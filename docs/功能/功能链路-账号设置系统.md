# 功能链路：账号、设置、系统

什么时候读：加改登录、账号、超级管理员模式、数据管理、系统状态、AI 设置、提示词、工具开关、使用说明的页面、地址、助手工具时，查它走哪些页面、地址、工具。

表的写法（地址缩写、页面和工具列）相关的见 `.claude/skills/add-feature/SKILL.md`“功能链路表”。

`/auth` 下的接口归账号模块（`server/accounts/`），助手经装配传入的只读查询取登录记录。

账号管理、AI 设置、提示词、消息接入、工具启停的写入都要超级管理员模式（没进回 403 `super-mode`；本机管理员一直算在模式里）。没进模式时页面顶上 `src/ui/SuperModeNotice.tsx` 给入口，打开的是账号菜单里同一个“系统维护”窗口。

| 功能 | 页面 | 后端地址 | 助手工具 |
|---|---|---|---|
| 登录、申请账号、忘记密码、改密码 | 登录页；账号菜单 | `/auth/state`、`POST /auth/setup`（第一次建管理员）、`/auth/login`、`/auth/apply`、`/auth/forgot`、`/auth/password`、`/auth/logout` | 无 |
| 账号管理 | `#accounts`（管理员） | `/auth/users`（`/:id`、`/:id/password`）、`/auth/requests`（`/:id/approve\|reject`） | `accounts.list`、`accounts.events`（只读，超级管理员） |
| 超级管理员模式 | 账号菜单“系统维护” | `POST /auth/super-admin/:action` | 无 |
| 本机管理员数据管理、初始化 | 账号菜单“数据管理”（只在服务器本机） | `/management/records`、`POST /management/execute`、`/management/reset-preview`、`POST /management/reset` | `management.context`、`management.execute`、`management.delete_preview`、`management.reset_preview`、`management.reset`（只有本机最高管理员） |
| 系统状态、体检、备份 | 没有页面，本机问助手 | `/health` | `system.status`、`system.check`、`system.backup` |
| AI 设置 | `#ai-settings`“API 配置” | `/ai/settings`、`POST /ai/settings/key\|key/save\|key/delete\|test\|balance\|preferences`（`server/ai/settings-router.ts`） | `ai.status`、`settings.view`（只读） |
| 提示词 | `#ai-settings?tab=prompts` | `/ai/prompt-modules`、`/ai/prompt-modules/<模块>`（`/save\|copy\|activate\|delete\|restore`） | `prompts.get`、`prompts.propose`（只给超级管理员，卡片上是改前改后全文） |
| 工具分组和工具开关 | `#ai-settings?tab=tools`（“高级”页签“插件与工具”） | `/assistant/plugins`（`/settings` 整组启停）、`/assistant/tools`（`/settings`） | 无 |
| 使用说明 | `#guide` | `GET /guide`（`server/system/user-manual.ts` 读 `docs/使用手册.md`） | `guide.read` |

- **设置页谁看得到：** API 配置、提示词、高级只给超级管理员账号，读也一样（`/ai/settings`、`/ai/prompt-modules`、`/assistant/plugins`）；别的账号只有单据模板，只读和出纳没有设置。页签名单在 `src/app-shell.ts` 的 `settingsTabsOf`；助手 `ui.open` 打开这几个页签时别的账号被拒（`adminSettingsLink`）。
- **AI 设置：** 改密钥和识别设置要超级管理员模式；查余额、重新测试只要超级管理员账号。助手、AI 导入、收件箱要知道 AI 能不能用、用哪个模型，读 `GET /assistant` 的 `ai`，人人能读。两页的 AI 凭证关卡共用 `server/ai/page-guard.ts`。
- **`/assistant/tools`** 设置页不用，按账号列自己的工具，真实模型套件用。
- **数据管理：** 删除、已生效单据的说明和更正、库存品出入库打开的都是业务页面同一个窗口、走同一个地址。`/management/execute` 只办新建、修改、归档、恢复、确认、取消、撤销，删除走 `/deletions/execute`、助手走 `records.delete`；已生效单据改数量、日期会被拒；补丁里有录入结构不收的栏目，不管在第几层都拒收并说清哪一格，照读出来原样带回的放过（`docs/生成/模块表.md` 的数据管理）。
- **提示词模块**三个：客户订单识别 `sales-order`（AI 导入选客户订单）、供应商到货单识别 `supplier-delivery`（AI 导入选到货单、到货页 AI 识别送货单）、小甬小勒 `assistant`（全局助手）。定义在 `shared/ai/prompt-modules.ts`；存在哪个文件见 `docs/生成/表结构.md`“提示词库”，默认内容由谁提供见 `docs/生成/模块表.md` 的 AI接入。
