## 进行中

- **财务复核：** 请懂账的人核对科目名称、报表行项目、附加税率、小规模征收率优惠和相关法规条款。另有三个待定：启用期初和成本窗口的存货期初要手工保持一致，要不要系统校验；票据收取、背书、退票怎么对应到具体往来单（现在按往来单位记账，逐单余额要人工核对）；员工借还款沿用 `1221` 不分员工核算，要不要设专用科目。

2. **试真实模型的唛头识别：** 还没用真实文件试过，提示词效果未知。会把客户文件发给模型并产生费用，须用户同意。

## 上服务器前必须做

详情见[部署与运维](部署与运维.md)。

已定：Windows Server，只有用户本人通过限制 IP 的远程桌面维护，员工只用网页。

代码改造已完成，下面是到服务器上才能做的：

- 办域名和备案（如需要），装证书
- 在服务器上真实注册计划任务，验证开机自启和崩溃重启（脚本只做过预演）
- 用 Caddy 或 IIS 配好反向代理并实际跑通 HTTPS，确认防火墙只开 443
- 确认服务账号能读密钥，重新填写模型 API 密钥和机器人 Secret（DPAPI 绑定电脑和账号，不能直接搬）
- 切换机器人时先停本机连接，再开服务器连接，不要同时连同一个机器人
- 配置备份复制到服务器之外，并做一次完整的部署和备份恢复演练
- 用真实网络和多人同时使用试一次（压测只测过单请求）
- 确认反向代理的压缩生效（步骤见部署文档）
