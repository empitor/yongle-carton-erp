# 财务接口清单

所有路径相对 `/api/finance`。必须登录并持有 `finance:view`。写入带 `X-ERP-Auth-Token`、`requestId`，修改现有对象时附 `version`。版本冲突返回 409。同一操作者、同一请求号及相同参数回放原结果。除单价、税率和数量原文外，金额为人民币整数分。日期 `YYYY-MM-DD`，期间 `YYYY-MM`。

下表读接口默认使用 `finance:view`。写权限缩写 `edit`、`approve`、`cash`、`close` 分别为同名财务权限。列表一般返回 `rows`、`page`、`pageSize`、`filteredRecords`，默认每页 50，上限 200。新列表排序接受 `newest`、`recent`、`oldest`。用于设置选择的科目、模板、期间接口返回完整列表。JSON 字段及整数分口径沿用原接口。Excel 导出使用中文列，金额为数值元，缺价格时显示“缺价格”。导出附件名使用 UTF-8 并包含期间或起止日期。

## 财务概览、月度台账和经营报表

| 方法与路径 | 参数 | 返回 |
|---|---|---|
| GET `/summary` | 可选 `date` | `events`、`pendingApproval`、`overdue`、`accounts`、`period`、`current`、`latestClosed` |
| GET `/related/:kind/:id` | `orders\|delivery`，单据 ID | 财务事件状态、凭证 ID、往来单金额、到期日、已核销金额及收款链接 |
| GET `/flow`、`/flow/export` | `period`，可选 `missingTax=1\|0`、`metric`、`sourceMonth` | 台账列表、`summary`。明细 `detail` 带来源快照和数量、单价、财务税率信息 |
| GET `/monthly-report`、`/monthly-report/export` | `period` | 理论收入、支出、盈亏，实际收入、支出、盈亏，接单、缺价和缺税计数，实际来源月份、到期对照。优惠、利息、保证金另列 |
| GET `/monthly-report/detail`、`/monthly-report/detail/export` | `period`，可选 `metric`、`sourceMonth` | 分项记录和下钻快照。实际来源月份可为 `YYYY-MM`、`advance`、`unallocated` |
| GET `/monthly-report/trend` | 可选结束 `period`，`months` 默认 12 | 每期经营汇总 |
| GET `/due-soon` | 可选 `date`、`days`，默认 7 天 | 已逾期和即将到期单据或分期、剩余金额、`days_to_due` |

经营报表理论值取有效送货和实际入库到货的原始单据金额。实际值取已确认资金单及独立已记账资金分录。内部转账、保证金单独处理。补税只更新财务快照和往来记账金额。下钻 `metric` 可用 `ordered`、`theoreticalIncome`、`theoreticalExpense`、`actualIncome`、`actualExpense`、`discountIncome`、`discountExpense`、`interestIncome`、`interestExpense`、`depositIncome`、`depositExpense`。

## 设置、凭证和账簿

| 方法与路径 | 参数和权限 | 返回 |
|---|---|---|
| GET、PUT `/settings` | PUT `close`，可更新税务配置、税率基点、收入时点、账龄区间、成本分摊。审核分离开关仅管理员 | 配置、启用期、版本 |
| GET、PUT、DELETE `/accounts` | PUT `close`，`account` 包含编码、名称、类别、方向、启用、资金类型及辅助类型。DELETE `close`，`code`、`version` | 科目、是否末级、版本 |
| GET `/periods`、`/opening` | 期初读取需 `close` | 期间、状态、版本、期初分录 |
| POST `/opening/enable` | `close`，`period,taxpayer,rows,version`，每行 `accountCode,auxiliary,debit,credit,yearDebit,yearCredit` | 锁定后的期初设置 |
| GET `/vouchers`、`/vouchers/:id` | 列表可筛 `period,status` | 凭证头、明细和 `source` |
| POST `/vouchers`、PUT `/vouchers/:id`、DELETE `/vouchers/:id` | `edit`，`date,description,attachmentCount,entries`。分录 `accountCode,debit,credit,description,auxiliary,cashFlow`；科目要求辅助核算时 `auxiliary` 必填 `{kind,id,name}`。DELETE 不删除任何凭证，凭证编号要保留 | 凭证头和分录；DELETE 固定返回 405，提示改用作废 |
| POST `/vouchers/:id/{submit,approve,post,void,reverse}` | 提交、作废、红冲 `edit`，审核、记账 `approve`。红冲另传 `date,description` | 新状态或红冲凭证 |
| GET `/books/:kind`、`/books/:kind/export` | `kind=general\|detail\|journal\|balance\|auxiliary\|cash\|bank`，`period`，可选 `account,auxiliaryKind,auxiliaryId` | 账簿或 Excel。明细含 `voucher_id` |
| GET `/audit` | `close`，可选 `actorId,from,to,entity,recordId` | 修改前后、时间、操作者 |
| GET、PUT `/templates` | `close`。更新 `name,mapping,version` | 已配置映射及版本 |

已记账凭证及其分录只读。已联动模块的凭证由相应模块处理更正。现金流量项由制单录入或业务模板填入。辅助项为 `{kind,id,name}` 快照。

## 财务事件、应收应付、账期和核销

| 方法与路径 | 参数和权限 | 返回 |
|---|---|---|
| POST `/events/sync` | `view`，仅 `requestId` | `processed,remaining`。remaining 为 true 时可用新请求号继续 |
| GET `/events`、`/events/:id` | 可选 `status` | 来源、资料状态、`missing`、`taxSource`、数量提示、前后快照 |
| POST `/events/:id/generate` | `edit`、`version` | 来源凭证草稿关联，缺税的已有理论货款仍为待补 |
| POST `/events/:id/resolve` | `edit`、`version`，可选 `evidence`，逐行 `lines:[{exact,rate,mode}]` | 新事件和金额。已有待补税往来记录保留 ID、到期日和核销 |
| POST `/tax-completion/batch` | `edit`，`items:[{id,version}]` 或 `kind,partyId,period`，可用 `rate,mode,noTax,usePartyDefault,evidence` | 已补录事件，最多 200 张 |
| POST `/events/:id/correct` | `edit`，`version,date,reason` | 原单红冲与新单，或已处理状态。已核销须先撤销 |
| POST `/events/:id/acknowledge` | `edit`，`version,reason` | 仅核对管理员统计更正，保留原库存和凭证 |
| GET `/party-terms`、GET/PUT `/party-terms/:kind/:id` | `kind=customer\|supplier`。PUT `edit`，`termType,termDays\|termMonths/paymentDay/cutoffDay,taxRate,taxMode,creditLimit,options,version` | 规则、往来单位、税率、优惠档位、分期、保证金和利息配置 |
| GET、POST `/obligations` | 读 `kind=receivable\|payable,partyId`。POST `edit`，`kind,partyId,date,dueDate,amount,description,counterAccount` | 往来单、余额、已核销、开票金额、凭证、到期日、版本 |
| POST `/obligations/:id/bad-debt` | `edit`，`version,kind=writeoff\|provision,date,amount,reason,counterAccount` | 坏账记录、草稿凭证 |
| PUT `/obligations/:id/due`、`/installments/:id/due` | `edit`，`version,dueDate,reason` | 更新后的到期日 |
| GET、POST `/due-recalculation` | `edit`，`kind,partyId`。POST 另传预览 `digest` 和 `reason` | 预览变动或更新数量 |
| GET `/aging`、`/held`、`/payment-plan` | 账龄 `kind,date,basis,overdue`，压款 `kind,date`，计划 `date,months,dueMonth,partyId` | 账龄区间或按单位压款、分月收付及预测资金。无账期单独统计 |
| GET、PUT `/statements`、GET `/statements/export` | `kind,partyId,from,to`。PUT `edit`，`status=sent\|confirmed\|difference,discrepancy,version` | `opening,closing,items,state` |
| GET `/cash/documents/:id/suggestions` | 可选 `date` | 建议核销、可用资金、折扣档位 |
| POST `/cash/documents/:id/allocate`、`/cash/auto-allocate` | `edit`，前者 `version,date,allocations`，后者 `kind,partyId,date,documents`。核销项 `obligationId,version,amount,discount,reason` | 核销和凭证 |
| POST `/allocations/:id/revoke` | `edit`，`version,date,reason` | 作废或红冲记录，跨期留反向核销 |
| GET `/discount-opportunities` | `date,kind` 可选 | 优惠额、截止日、年化收益分子和分母 |
| GET、POST `/deposits`、POST `/deposits/:id/actions` | 新增 `cash`，`kind=paid\|received,partyKind,partyId,accountId,date,amount,description`。操作 `kind=refund\|apply,version,date,amount,reason,accountId\|obligationId`，退还需 `cash`，转抵需 `edit` | 保证金、余额、凭证、部分退回或转抵 |
| GET `/interest`、POST `/interest/confirm` | 读取 `period,kind`。确认 `edit`，`period,obligationId,version,amount,reason` | 建议、计算依据或确认凭证，零金额表示免除 |

## 资金、银行和发票

| 方法与路径 | 参数和权限 | 返回 |
|---|---|---|
| GET、PUT `/cash/accounts`、GET `/cash/daily` | 可按 `date,kind` 查询。PUT `close`，`id,version,name,kind,accountCode,lastFour,enabled` | 账户、余额或日报期初、收入、支出、期末 |
| GET、PUT `/cash/documents`、GET `/cash/documents/:id` | GET 可筛 `kind,accountId,partyId,from,to`。PUT `cash`，`id,version,kind,accountId,targetAccountId,partyId,date,amount,method,description,counterAccount,cashFlow` | 草稿或已确认资金单及未核销额 |
| POST `/cash/documents/:id/confirm` | `cash`，`version`，可选 `allocations` | 确认回执、凭证、余额不足提示 |
| POST `/cash/documents/:id/cancel` | `cash`，`version,date,reason,requestId`。先撤销核销并记账相关红冲，撤销日期须在开放期间 | 状态 `cancelled`，`voidedVoucherIds`、`reversalVoucherIds`。经营报表立即移除资金单，已记账金额在红冲记账后冲减账户余额。原已结期间保持不变 |
| GET、POST `/notes`、POST `/notes/:id/status` | 创建和变更 `cash`。创建 `kind,partyId,number,bank,date,dueDate,amount`，变更 `version,status,date,reason,accountId,counterPartyId,counterAccount,proceeds` | 票据和凭证，可筛 `kind,status,dueDays,date` |
| GET、PUT `/mapping-profiles` | PUT `edit`，`id,version,kind=bank\|invoice,name,mapping`，列号从 1 起 | 持久化列映射 |
| POST `/bank/import`、`/bank/upload` | `cash`，JSON `accountId,rows:[{date,amount,reference,party,description}]` 或字节上传。上传 query `requestId,accountId,format=csv\|xlsx,mapping\|profileId,skipHeader` | `imported,duplicates` |
| GET `/bank/rows`、`/bank/rows/:id/suggestions`、PUT `/bank/rows/:id/match` | 列表 `accountId,from,to,status`。匹配 `cash`，`version` 加 `voucherId,position` 或 `entries:[{voucherId,position}]`，voucherId 为空解绑 | 流水、单笔或合并分录建议及确认结果 |
| GET `/bank/reconcile`、`/bank/reconcile/export` | `accountId,from,to,bankBalance` | 两侧余额、调整数、差额、未达账 |
| GET、POST `/invoices`、GET `/invoices/:id` | 可筛 `direction,period,status`。POST `edit`，`direction,type,number,date,partyId,taxId,net,rate,tax,gross,originalId,attachmentId` | 发票和关联 |
| POST `/invoices/upload` | `edit`，xlsx 字节。query `requestId,direction,profileId,skipHeader` | 导入草稿 |
| PUT `/invoices/:id/links`、POST `/invoices/:id/confirm`、POST `/invoices/:id/status` | `edit`，`version`，依次另传 `links:[{obligationId,amount,estimateAmount,quantity,unit}]`，可选 `counterAccount`，或 `status,date,reason,counterAccount` | 关联、凭证、认证、不可抵扣或作废状态。部分到票明确填写对应暂估金额，数量和单位可选并同时填写。红字发票不关联往来单，确认时全额红冲原蓝票凭证；部分红冲且原票已有凭证时必须传 `counterAccount`。红冲掉的开票额度按蓝票各关联累计分摊释放 |
| GET `/invoice-matching`、`/tax`、`/tax/export` | 往来 `kind` 或 `period` | 往来开票余额、来源明细或税务底稿 |
| POST `/attachments/upload`、GET `/attachments/:id` | 上传 `edit`，query `requestId,filename`，原字节 | 去重附件 ID 或附件。PNG、JPEG、PDF 内联，其余下载 |

文件端点使用 `Content-Type: application/octet-stream`，表格上限 10 MB，附件 20 MB。CSV 使用 UTF-8，金额列为元，解析成分。发票网关为离线实现，税务底稿请以税局系统为准。

## 正式报表和关账

| 方法与路径 | 参数和权限 | 返回 |
|---|---|---|
| GET `/reports/readiness` | `period` | `ready,count,amount,unsynced,rows` |
| GET `/reports/:kind`、`/reports/:kind/export` | `period`，`kind=balance\|profit\|cashflow\|trial` | 报表和下钻参数。正式三表及导出缺资料返回 409，`code=FINANCE_INFO_PENDING`，`details` 含待补清单 |
| GET `/reports/dashboard` | `period` | 管理数据、估算标记、12 月趋势 |
| GET、PUT `/budgets` | `period`。PUT `close`，`accountCode,amount,version` | 预算及实际。已结账期间可读取，修改返回 409 |
| GET `/closing` | `period` | 顺序、状态、逐项检查、是否可结。12 月的 `profit` 项带 `annualNext`：月末损益已结转、年度利润还没结转时为真 |
| POST `/closing/{tax,profit,close,reopen}` | `close`，`period`。损益可传 `annual`（仅 12 月，须先完成并记账月末损益结转），结账、反结账传 `version`，反结账传 `reason`。年度反结账另需管理员 | 计提或结转、期间状态、快照 |
| GET `/archive` | `close`，`period` | Excel 文件的 Base64、大小、SHA-256 及快照版本 |
| GET `/archive/download` | `close`，`period=YYYY-MM`，该期间须已结账 | ZIP 附件 `财务归档-YYYY-MM.zip`，含 `vouchers.xlsx`、`journal.xlsx`、`reports.xlsx` 和 `manifest.json`，清单含期间、快照版本、文件字节数及 SHA-256 |

ZIP 的 `reports.xlsx` 分工作表保存资产负债表、利润表和现金流量表快照。普通报表及 ZIP 使用同一排版。反结账后的历史快照仍可通过原 `/archive` 读取，重新结账后可下载当前 ZIP。

## 开发初始化与助手

`GET /api/management/reset-preview?scope=business&clearClosedFinance=1` 返回财务影响和摘要，已结账时由本机最高管理员在人工预览明确选择。提交 `POST /api/management/reset` 时带 `clearClosedFinance:true,financeDigest`。该操作保留科目、模板、设置和审计。AI 的业务初始化工具保留财务数据。

财务助手仅登记 `finance.summary`、`finance.receivables`、`finance.payables`、`finance.ledger`、`finance.reports`、`finance.invoices`、`finance.cash`，均要求 `finance:view`，`limit` 最大 50。工资明细通过独立人工鉴权接口读取。
