# 0.7.0 发布说明

发布日期：2026-11-06

这是 0.6.1 之后最大的一次更新：新增完整的财务模块、收件箱和企业微信机器人、产品唛头，支持部署到服务器，并提供解压即用的安装包。

## 下载

`yongle-carton-erp-v0.7.0-win-x64.zip`：解压后双击 `启动系统.cmd` 就能用，已内置 Node.js 和全部依赖。

不包含任何业务数据、账号和密钥，也不包含语音模型。接入 AI 和语音模型的步骤见 [README](../../README.md)。

## 新功能

### 财务模块

业务不等财务。没有税率照样送货、到货、收付款，只有出正式报表和结账时才要求补完。

- **两种盈亏：** 理论盈亏看送货单和到货单，实际盈亏看实际收付，互不影响。点金额能看到每一笔，还能看出这个月收到的钱是几月份的货款。
- **月度台账：** 当月每一条接单、送货、到货、收付；单张或按单位批量补税率，不改原单。
- **压货款和优惠：** 按单位设压几个月、每月几号付、现结优惠、分期、保证金、压款利息。
- **收付款：** 录入、确认、核销、撤销；到期提醒和未来几个月的收付计划。
- **账务：** 凭证、账簿、银行流水、承兑票据、发票、费用、固定资产、工资导入、库存成本。
- **报表和结账：** 三张正式报表、试算平衡、结账清单、反结账、打包归档。
- **导出：** 全部是可以直接看的 Excel，中文表头，金额按元。

### 收文件

- **收件箱：** 手动上传、粘贴和企业微信机器人收到的内容集中处理，一键转订单、到货或唛头。
- **企业微信机器人：** 员工把文件转发给机器人就进收件箱。
- **产品唛头：** AI 识别唛头文件，按款对应产品，存入档案。

### 部署

- 支持 Windows Server 加反向代理和 HTTPS，公网和本机维护分开。
- 登录状态重启不丢，提供开机自启脚本、日志轮转和备份异地复制。不配置时，本机使用方式不变。

### 界面和可靠性

- 全部列表页统一，订单和采购详情顶部显示下一步。
- 重新设计纸箱精灵；大页面按需加载，主脚本从 873 KB 降到 526 KB。
- 升级前自动保存业务库快照，快照失败就不升级；财务和今日页在大数据量下明显提速。

## 从 0.6.1 升级

1. **先备份：** 在旧版本执行 `npm.cmd run backup`，再停止系统。
2. 解压新版本到新文件夹，把旧的 `data\`、`backups\` 复制过去，语音模型也一并复制。
3. 启动新版本。数据库会自动升级到迁移 17，并增加财务表，旧业务数据不变。
4. 模型 API 和机器人凭据保存在 `%LOCALAPPDATA%\ZhixuERP\`。同一台电脑、同一个 Windows 账号不用重填。

账号权限新增“财务”和“出纳”两级，原有账号不变。管理员默认拥有财务权限。

启用财务前请注意：已有库存的金额要填进期初，**启用后期初不能再改**。

## 已知限制和未验证项

请先了解这些再使用：

- **财务未经会计复核：** 科目、报表行项目和税率还没有请专业会计核对，正式报表只作内部参考。
- **未经真实业务长期试跑：** 自动测试和浏览器实测用的都是虚构数据，还没有用真实业务长期使用过。旧库升级用虚构的旧版数据库验证过。
- **服务器部署未实测：** 真实的 HTTPS 证书、开机自启、崩溃重启、压缩和多人同时使用，都还没有在服务器上跑过。
- **企业微信：** 从客户聊天转发文件、群聊 @ 机器人、断网重连没有真实测过。
- **唛头识别：** 还没有用真实文件和真实模型试过。
- **票据：** 目前按往来单位记账，不对应到具体单据。
