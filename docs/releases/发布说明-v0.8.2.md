# 0.8.2 发布说明

发布日期：2026-11-08

这是 0.8.1 之后的修复版本，修掉第二轮代码审查里确认属实的问题。数据库结构不变，可以直接覆盖升级。

## 下载

- `yongle-carton-erp-v0.8.2-win-x64.zip`：Windows 版，解压后双击 `启动系统.cmd`。
- `yongle-carton-erp-v0.8.2-linux-x64.tar.gz`：Linux 版（Ubuntu 24.04 LTS x64），安装步骤见 [部署与运维](../部署与运维.md)。

两个包都内置 Node.js 和全部依赖，各附 sha256 校验文件。不包含任何业务数据、账号、密钥和语音模型。

## 修复

- **发票：** 发票已有带数量和单位的关联时，再加一条关联不再报错，原来的数量和单位保持不变。
- **生产任务维护：** 管理员在数据维护里修改已确认的生产任务，不再丢掉产品名、确认人和确认时间。
- **排产提醒：** 多产品订单里，已经做好且库存够发的产品不再提醒排产，今日页“未排产”也按产品判断。
- **AI 导入：** 业务人员在工作区点“删除文件”会移进回收站，可以在归档里恢复，不再提示没有权限；已在归档、回收站里的才永久删除，仍只限本机管理员。
- **单据模板：** 签名栏末尾多打一个逗号不再保存失败。

## 从 0.8.1 升级

1. 先做一次完整备份。
2. Windows：停止系统，解压新版本到新文件夹，把 `data\`、`backups\` 复制过去，再启动。
3. Linux：按[部署与运维](../部署与运维.md)替换 `/opt/yongle-carton-erp` 下的程序文件，数据目录不动，然后重启服务。
