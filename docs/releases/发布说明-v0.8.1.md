# 0.8.1 发布说明

一套代码支持 Windows x64 和 Ubuntu 24.04 LTS x64，分别提供内置 Node.js 24 与原生依赖的安装包：

- `yongle-carton-erp-v0.8.1-win-x64.zip`
- `yongle-carton-erp-v0.8.1-linux-x64.tar.gz`

两个包各附 sha256。双平台全部验收通过后才发布。

Linux 新增 AES-256-GCM 凭据保护、严格权限检查、独立目录、systemd 与 Caddy 示例。安装 `fonts-noto-cjk`，使用专用服务账号；维护端口通过 SSH 隧道访问。Windows 默认配置路径与 DPAPI 保护保持兼容，旧密文照常读取。

订货单和送货单采用固定版式：补空行、完整续张、末张合计，支持纸型、联次、商标和明细列恢复默认。默认每张为 6/11/11/24/14 行。信息区和备注固定，长文字缩至最小 7 磅仍放不下时明确拒绝导出，不截断、不减行、不撑出半张单据。大写合计独占整行；Excel 明细金额仍为数字，合计整行为展示文本。

升级前完整备份并离机保存。Windows 迁 Linux 后，在新平台重新填写 AI 密钥和机器人 Secret；Linux 主密钥 `credentials/master.key` 不进入业务备份，务必单独安全保管。先停旧机器人连接再启新连接。可选语音模型缺失不影响其他功能。

详细步骤：[部署与运维](../部署与运维.md)、[使用手册](../使用手册.md)、[变更日志](../CHANGELOG.md)。真实针式打印机、Microsoft Office 和正式公网环境需部署时另行验收。
