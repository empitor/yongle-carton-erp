# 0.8.3 发布说明

发布日期：2026-11-08

修复 0.8.2 部署到 Linux 服务器后发现的问题，并新增补丁升级。数据库结构不变。

这一版只发补丁，不提供新的完整安装包：全新安装先装 0.8.2 安装包，再打这个补丁。完整安装包留到 0.9.0。

## 下载

- `yongle-carton-erp-v0.8.2-to-v0.8.3-linux-x64.patch.json.gz`：Linux 补丁，把 0.8.2 Linux 安装包升级到 0.8.3。
- `apply-patch.mjs`：在服务器上应用补丁的脚本。

两个文件各附 sha256 校验文件。补丁只含程序文件，不含任何业务数据、账号、密钥和语音模型。

## 修复

- **AI 正式导入：** 服务器上 AI 识别后点“正式导入”会失败。原件归档原来固定写在程序目录，服务器的程序目录是只读的；现在改为写在业务数据目录，也会进入完整备份。
- **数据初始化：** 初始化清空业务记录时，正式导入留下的原件归档一并删除，不再把客户文件留在磁盘上。只清 AI 识别工作区时归档保留。
- **服务器语音输入：** 部署模式不再连带关闭语音输入，服务器装了语音模型就显示按钮。识别改为异步，识别期间不再卡住其他人的请求。
- **维护隧道：** SSH 隧道映射到任意本机端口都能建立管理员和登录，不再提示“请求来源不允许”。
- **健康检查：** 服务器上显示“服务器部署版”。

## 新增

- **补丁升级：** `npm run patch-server` 只把有变化的程序文件传到服务器，自动备份数据、保存回滚副本、重启并检查健康，失败自动回滚，最后核对服务器和本机文件完全一致。用法见[部署与运维](../部署与运维.md)。

## 从 0.8.2 升级（Linux）

1. 把两个文件传到服务器，核对 sha256。
2. 运行：

```sh
sudo /opt/yongle-carton-erp/runtime/node/bin/node apply-patch.mjs yongle-carton-erp-v0.8.2-to-v0.8.3-linux-x64.patch.json.gz
```

脚本会先核对服务器上的文件确实是原版 0.8.2，再备份业务数据、替换文件、重启服务。启动失败会自动换回旧文件。

Windows 本机版直接更新源码到 0.8.3 即可。

## 已知限制

- 补丁不能更新依赖，依赖有变化时要用完整安装包。
- 语音输入还没在服务器页面上实际录音试过；手机上用语音要等 HTTPS 域名开通。
- 第二轮审查里还没核实的财务和数据维护条目仍在[路线图](../路线图.md)。
