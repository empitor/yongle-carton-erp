# 0.8.0 发布说明

发布日期：2026-11-07

这一版主要是“用真实单据跑一遍，把测出来的问题修掉”：真实订单文件把识别、导入、送货、导出、财务口径和唛头整条链路走了一遍；助手换成小甬和小勒两个角色；做了两轮代码审查，修了权限、订单状态、财务和库存的几处缺陷；清理了旧样式，页面外观统一。

## 下载

`yongle-carton-erp-v0.8.0-win-x64.zip`：解压后双击 `启动系统.cmd` 就能用，已内置 Node.js 和全部依赖。

不包含任何业务数据、账号和密钥，也不包含语音模型。接入 AI 和语音模型的步骤见 [README](../../README.md)。

## 主要变化

### 订单状态更准

- **做够才算待发货：** 订单每个产品的已完工数量够订单数量，才显示“待发货”。只做了一部分仍是“生产中”。
- **部分发货：** 发了一部分显示“部分发货”，全部发完才是“已发货”。比如一万个今天做五千发五千，今天是部分发货，今日页会提醒还差五千没排产。
- **不换算单位：** 生产任务按箱、订单按只时，不算这张单的生产量，订单详情里会提示。
- **今日页：** 做好一批就能安排送货；还没做够又没在生产的，提醒接着排产。

### 识别和导入更省心

- 模型偶尔返回格式不对时自动清理或重试，不再莫名失败；疑点只列真正要看的。
- 客户只差“有限公司”这类字样的直接并入已有档案；产品同名同尺寸直接对应。名字相近但不确定的列为候选，不会静默建重复档案。
- 唛头识别后自动挂到对应产品，产品详情里能预览原件。

### 助手：小甬和小勒

- 两个角色分工回答：小甬管导入、客户、产品、唛头、订单、送货，小勒管采购、到货、库存、生产、财务。
- 新增系统维护（状态、体检、备份）、收件箱添加、唛头挂接和移除、到货单识别、聊天记录管理。
- 删聊天记录、移除唛头必须是你本人明确说要做，否定、问怎么做都不算。
- 读财务数据时金额统一按元，不会再把七千多说成七十多万。

### 财务

- 红字发票可以确认了，红冲后释放开票额度。
- 12 月可以先结转月末损益，再结转年度利润。
- 手工凭证能选客户、供应商等辅助项。

### 界面

- 新商标（YL 折痕），手机有底部导航和卡片列表。
- 页面外观不再取决于先打开哪个页面；字号和圆角统一，部分页面更紧凑。
- 手机上 AI 导入页的原件不再压住草稿。

## 从 0.7.0 升级

1. **先备份：** 在旧版本执行 `npm.cmd run backup`，再停止系统。
2. 解压新版本到新文件夹，把旧的 `data\`、`backups\` 复制过去，语音模型也一并复制。
3. 启动新版本。**数据库结构没有变化**（仍是迁移 17），不需要升级数据库。
4. 模型 API 和机器人凭据保存在 `%LOCALAPPDATA%\ZhixuERP\`。同一台电脑、同一个 Windows 账号不用重填。

升级后请注意：

- **AI 设置只有管理员能改。** 业务人员、只读、财务、出纳账号打开设置页的 API 配置，只看到提示。导入工作区和提示词仍然是有业务编辑权限的账号都能改。
- **第一次启动会重算老订单的状态。** 系统按新规则把全部订单核对一遍，只改状态不对的（比如只做了一半却显示“待发货”的，会改回“生产中”），改了哪些记在审计里，启动窗口也会显示改了几张。只跑这一次，以后启动不再跑。
- **提示词：** 没改过的默认提示词会自动升级到新版本；改过的不覆盖，只补上缺少的条目。
- **外观：** 设置页、AI 导入页和几个新建窗口更紧凑，小字统一为 12 像素。

## 已知限制和未验证项

- **财务未经会计复核：** 科目、报表行项目和税率还没有请专业会计核对，正式报表只作内部参考。原票已有凭证时的红字发票、在页面上走完 12 月结账，都只在后端测试里验证过。
- **真实单据：** 客户订单用真实文件测过；真实供应商送货单还没有试过。唛头和真实产品档案的对应率还要用真实档案看。
- **最后几处修改没有用真实模型复测：** 删聊天授权的分句判断、识别绑定确认过的模型，只用自动测试和模型替身验证过。
- **未经真实业务长期试跑：** 浏览器实测用的都是虚构数据。
- **服务器部署未实测：** 真实 HTTPS 证书、开机自启、崩溃重启、多人同时使用还没有在服务器上跑过。备份恢复的自动退回只在测试里模拟过故障。
- **企业微信：** 从客户聊天转发文件、群聊 @ 机器人、断网重连、新的固定地址下载都没有用真实机器人测过。
- **手机：** 只在浏览器的手机尺寸里看过，没有在真机上试。
