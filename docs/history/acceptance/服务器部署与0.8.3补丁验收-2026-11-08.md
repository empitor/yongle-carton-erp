# 服务器部署与 0.8.3 补丁验收（2026-11-08）

## 范围

0.8.2 Linux 安装包装到腾讯云 Ubuntu 24.04 服务器后，对照本机逐项排查功能差异，修复后以补丁方式升级服务器，并发布 0.8.3 补丁。

## 排查结论

- 部署模式把语音输入和服务器浏览器绑在同一个开关上一起关闭；语音录音只上传到本服务器识别，已拆开。服务器浏览器仍关闭。
- AI 正式导入的原件归档按程序目录定位，服务器程序目录只读且 systemd 只允许写数据目录，正式导入会失败；已改为数据目录。
- 数据初始化清空导入台账却不清原件归档，客户文件会残留；已改为一并删除。
- 维护隧道只接受 3001/5173 两个本机端口来源；已改为来源与回环 Host 一致即放行。
- 本机最高管理员能力只在服务器回环入口（SSH 隧道）提供，公网域名入口不提供，属有意设计，未改。
- Windows 图片 OCR 代码没有被调用，两平台图片都交给视觉模型，无功能差异。其余存储路径都跟随 `DB_PATH`。

## 验证

- 类型检查通过；全量测试 729 项加串行 9 项通过，4 项仅 Linux 的测试在 Windows 上跳过。全量并行时 `raw-stream-import` 和 `assistant-plugin-management` 各偶发失败一次，单独运行与重跑均通过，原因未查。
- 服务器语音：SenseVoice 模型从 hf-mirror 下载，sha256 与本机一致；2 核 4G 实测加载约 1 秒、常驻约 400MB、5.6 秒中文约 0.4 秒。本机真模型验证异步识别期间事件循环不阻塞。补丁后服务器页面出现语音按钮；实际录音未在服务器页面试。
- 原件归档：按正式服务相同的 systemd 沙箱验证旧位置写入失败、新位置可写；用户在服务器用真实订单完成正式导入，归档生成 1 份原件。
- 初始化清理：新增回归测试覆盖清业务删归档、只清工作区保留、未配置归档目录不删。用户初始化后残留的 1 份原件已按用户同意删除。初始化前快照保留在服务器 `data/snapshots/`。
- 补丁升级：两次补丁分别 680KB、628KB，服务器自动备份、留回滚副本、重启、健康检查通过，补丁后 279 个程序文件与本机逐个一致。
