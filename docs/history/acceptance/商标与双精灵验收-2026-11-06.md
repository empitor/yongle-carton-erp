# 商标与双精灵验收

2026-11-06。全程用隔离实例和虚构数据，没有碰 `data/`、`backups/` 和正式实例。

## 做了什么

| 需求 | 结果 | 位置 |
|---|---|---|
| 商标 | YL 折痕，用在左上角、登录页、标签页图标。原图是 SVG 和 1024 像素 PNG | `src/ui/BrandLogo.tsx`、`public/favicon.svg`、`docs/brand/` |
| 双精灵 | 小甬（Y）和小勒（L），站在一起就是商标，小勒的脚托小纸箱。替换了原来的纸箱精灵 | `src/YlSpirits.tsx`、`src/yl-spirits.css` |
| 同一个入口 | 两个精灵是一个按钮，点小甬、小勒、纸箱都打开同一个助手 | `src/GlobalAssistant.tsx` |
| 两人互动 | 传箱子、悄悄话、击掌、互相顶、够小星、轮流蹦，空闲时隔 9 到 20 秒随机演一段 | `src/YlSpirits.tsx` |
| 状态反应 | 处理中、做完击掌、眼睛跟随、悬停、拖动、贴边半隐藏、出场 | `src/yl-spirits.css` |
| 手机 | 手机上仍不显示悬浮精灵，底部“助手”图标换成不动的小图 | `src/mobile/MobileNav.tsx` |

入口按钮从 88×98 改为 104×108，页面底部和操作条的避让跟着调大。

## 没有验证

- 动画顺不顺滑。无头 Chrome 能确认动作和位置，看不出实际流畅度，要在真屏幕上看。
- 低配电脑上长时间运行的占用。动画只用 transform 和 opacity，没有实测 CPU。
- 真手机上的底部图标。
- 标签页图标的实际显示。只确认了文件能加载。

## 已知取舍

- 聊天窗口开着时精灵不显示，所以“做完击掌”只有收起窗口时才看得到。
- 贴边时按钮有一半在屏幕外，第二个精灵只露半张脸，这时不演小剧场。
