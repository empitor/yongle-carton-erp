## 部署配置

| 配置 | 含义 | 默认值 |
|---|---|---|
| `ERP_DEPLOYMENT` | 用 `1` 启用部署，`0` 或省略走本机模式 | 本机模式 |
| `PORT` | 本机维护回环端口 | `3001` |
| `ERP_PROXY_PORT` | 同机代理的上游回环端口 | `3002` |
| `ERP_ALLOWED_HOSTS` | 逗号分隔的公网 Host | 部署时必填 |
| `ERP_ALLOWED_ORIGINS` | 逗号分隔的 HTTPS 写请求来源 | 由允许域名派生 |
| `ERP_BACKUP_COPY_DIR` | 完整自动备份复制目录，支持 UNC | 关闭复制 |
| `ERP_BACKUP_COPY_KEEP` | 复制目标的自动备份保留份数 | 保留全部 |

计划任务还需指定项目外的配置文件和日志目录，`TaskName` 默认为 `CartonWorkshopERP`，`Node` 默认为 `node.exe`，服务账号在注册时输入。启动器设置 `NODE_ENV=production`。公网代理必须使用独立代理端口并覆盖 `X-ERP-Client-IP`。如果运维把公网转发到了维护端口，又把 Host 改成本机并去掉所有代理头，该请求与本机直连无法区分。配置与操作参见[部署与运维](../../部署与运维.md)。
