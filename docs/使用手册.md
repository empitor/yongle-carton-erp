# 使用手册

这份手册教你一步一步用这个系统，分三部分。业务员（接单、采购、仓库、生产、送货的同事）看前面从“登录和账号”到“常见问题”这几章。财务和出纳看“财务”这一章。管理员看“财务”后面那几章，标题都以“管理员”开头。不知道自己是哪种账号，问管理员。

## 登录和账号

### 登录

**什么时候用：** 每天开始用系统时。

1. 在手机或电脑上打开上网的软件（比如手机自带的浏览器），打开管理员给你的系统网址。装了“甬勒ERP”的手机，直接点开它。
2. 这台手机或电脑以前登录过，会列出用过的名字，点你的名字；你的名字不在里面，点名字下面的“使用其他账号”，在“用户名”里填你的名字。这台手机或电脑从没登录过，页面直接是“用户名”框，填你的名字。
3. 在密码框里填密码，点“登录”。

**做完以后：** 进到“今日”页。

- 这台手机或电脑只记名字，不记密码，每次自己填密码。
- 提示“尝试次数过多”：密码输错太多次了。照提示等几分钟再试。
- 提示“服务器正忙，请稍后再试。”：同时登录的人多。等一会儿再点“登录”，不算输错。
- 单机版重启后需要重新登录。服务器部署版正常重启后，原来的登录会话在到期前仍可用。恢复完整备份后需要重新登录。

### 没有账号

1. 在登录页下方点“申请账号”。
2. 填用户名（建议用真实姓名）、密码，再写上你的部门和岗位。
3. 点“提交申请”，等管理员通过。通过以后用刚才填的名字和密码登录。

### 忘记密码

1. 在登录页下方点“忘记密码”，填你的用户名，点“提交申请”。
2. 当面或打电话告诉管理员。管理员会给你一个临时密码，24 小时内有效。
3. 回到登录页，在密码框里填临时密码，点“登录”。
4. 这时会出来一个改密码的页面：在“临时密码”里再填一次临时密码，在“新密码”里填你自己的新密码，点“保存并进入系统”。

管理员给临时密码之前，你原来的密码照样能用。

### 改密码、换颜色、退出

1. 点右上角你的名字（手机上只显示名字的第一个字），打开账号菜单。
2. **改密码：** 点“修改密码”，填“当前密码”和“新密码”，点“保存新密码”。新密码至少 8 位，里面要有大写字母（比如 A）和小写字母（比如 a）。手机键盘上先按向上的箭头，再按字母，就是大写。改完以后，别的手机、电脑要重新登录。
3. **换颜色：** 在“外观”里选“浅色模式”“深色模式”（黑底），或“跟随系统”（跟着手机或电脑的设置走）。只对这台手机或电脑有效。
4. **退出：** 下班或借别人的电脑用完，点“退出登录”。

## 认识页面

### 常用的词

| 词 | 意思 |
|---|---|
| 列表 | 一页上一行一行的记录 |
| 详情 | 点列表里一行后，右边（手机上是整屏）出来的这条记录的全部内容和按钮 |
| 筛选 | 只看符合条件的，比如只看某个客户的 |
| 归档 | 把办完、不用的收起来，不显示在平常的列表里，随时能找回 |
| 订料 | 向供应商订纸板，会生成采购单 |
| 排产 | 安排生产，会生成生产任务 |
| 入库、出库 | 东西进仓库、出仓库，库存跟着加减 |
| 原材料、成品 | 原材料是纸板（按“张”）；成品是做好的纸箱（按“只”） |
| 流水 | 库存每进一笔、出一笔的记录 |
| 待××、已×× | 单子现在的状态，比如“待送货”是排好了还没出库 |

### 电脑上

左边一排是页面，从上到下就是干活的顺序：

- 今日、收件箱、AI 导入
- 销售：订单、客户、产品
- 采购：采购单、供应商
- 生产：生产任务、完工记录
- 仓储：库存、到货、送货、流水
- 最下面：设置、归档、使用说明

用法：

- **打开一条：** 在列表里点一行，右边打开详情；点详情右上角的 × 关掉。
- **详情上面的按钮：** 实心的那个就是下一步该做的事。不常用的收在“更多”里，点“更多”会展开一串。
- **列表上面一排：** 搜索框，打几个字就能找。旁边“待处理”“全部”“已归档”三个页签，点哪个看哪些。点“筛选”能按日期、客户等挑；挑过以后“筛选”上有个数字，点“清除筛选”全部去掉。
- **到货、送货的列表：** 只列还要处理的和最近 90 天的。要看更早的，在列表最下面点“显示更早的记录”。

### 手机上

- **最上面一排：** 左边三条横线是菜单，中间是搜索框，再右边“+”是新建，最右边是你名字的第一个字（点开是账号菜单）。
- **最下面五个按钮：** 今日、订单、助手、生产、仓库。
- 手册里写“点左边‘××’”的，手机上这样找：

| 电脑上左边的 | 手机上 |
|---|---|
| 今日、订单 | 底部的“今日”“订单” |
| 库存、到货、送货、流水 | 点底部“仓库”，再点页面上方的“库存”“到货”“送货”“流水” |
| 生产任务、完工记录 | 点底部“生产”，再点页面上方的“生产任务”“完工记录” |
| 收件箱、AI 导入、客户、产品、采购单、供应商、设置、归档、使用说明 | 点左上角三条横线，在菜单里点 |

- 列表变成一张张卡片，点卡片打开详情。
- 从下面升起来的小窗口，点窗口外面灰色的地方就关掉，和点右上角的 × 一样。正在保存时不会关。
- 排产板要拖着改日期，在电脑上做方便。

### 在安卓“甬勒ERP”里

- 按手机的返回键，先关最上面的窗口、详情、筛选或“更多”；什么都没开时回到“今日”；在“今日”连按两次返回才退出。
- 看图片原件时按返回，回到系统。
- 把微信里的文件传进来：在微信里点开这个文件，点右上角的三个点，选“用其他应用打开”，再选“甬勒ERP”。相册、文件管理里点“分享”，选“甬勒ERP”。文件会自动进“AI 导入”，显示“待识别”。超过 10MB、格式不对、读不出来的传不进去，会告诉你原因。
- 导出的订货单、送货单存在手机的“下载”文件夹里。存好了单子的状态才变；没存成，窗口里写原因，状态不变。

### 处处一样的规矩

- **数量单位：** 纸箱、成品只用“只”（客户写“个”也写“只”）；纸板只用“张”。别的单位要先自己换算好，系统不换算。
- **单价：** 最多四位小数。2.7600 显示成 2.76，2.5 显示成 2.50。按面积算的写“元/m²”。金额都是两位小数。
- **时间：** 都是北京时间。
- **没填好的会标红：** 点保存时，窗口自动滚到第一个没填对的地方，按钮上方写着还差哪几项。
- **几个人一起用：** 别人改了东西，你不用刷新。左边的数字十几秒内会变；从别的窗口切回来，列表马上更新。
- **提示“预览以后数据已变化，请重新预览。”：** 你看的时候别人改了数据。把窗口里新的内容看一遍，再点一次确认。
- **看一条记录的来龙去脉：** 在详情的“更多”里点“关联记录与修改历史”，能看到它连着哪些单子、谁什么时候改了什么。

## 今日

**什么时候用：** 每天一上班先看这里。

页面左边是“今日待办”，按要做的事分组。每一行右边有一个按钮，就是这一步要做的事。点它打开对应的窗口，办完回到这里。

| 组 | 意思 | 行上的按钮 |
|---|---|---|
| 待确认 | 订单录好了，还没确认 | 确认订单 |
| 待订货 | 采购单建好了，还没把订货单发给供应商 | 导出订货单 |
| 待到货 | 订了纸板，还没到齐 | 登记到货 |
| 待排产 | 订单要的货，库存不够，要安排生产 | 安排生产 |
| 待完工 | 正在生产，做完了要登记 | 登记完工 |
| 要核对订单 | 订单上的规格和产品对不上，送不了货 | 打开订单 |
| 可发货 | 库存够了，可以安排送货；排好的送货单也在这里 | 安排送货、导出送货单 |
| 收件箱 | 新进来的文件和消息 | 查看 |

右边是今天的安排：今天要到的货（过期没到的标红）、要生产的、要送的，还有库存是零的纸板。

- 几张订单要同一种货、库存不够时：交期早的先用库存，放在“可发货”。交期晚的放进“待排产”。
- 顶上的“本月接单”“本月发货”把已归档的也算进去。

### 经营概况

**什么时候用：** 想看一段时间接了多少单、送了多少货。

1. 在“今日”页最上面，点“今日待办”旁边的“经营概况”。
2. 在“统计日期”里选从哪天到哪天，默认是最近两个月。点“清除筛选”回到最近两个月。

**看到什么：** 这段时间的订单数和金额、送货金额、到货金额、采购、库存进出。

- 送货金额按送货单上的单价算，不另加税。只送了一部分的只算送了的。撤销的、被更正换掉的不算。
- 到货金额按入库数量和单据上的单价算，不另加税。
- 缺单价、数量或尺寸的单子算不出金额，不算进去，另写“N 张算不出金额”。
- “预估毛利”是大概赚的钱，只算录了预估成本的订单，不是真正的利润。

## 收件箱

**什么时候用：** 客户发来的文字、图片、文件，都先放进这里，再一条条处理。

### 东西怎么进收件箱

- **上传文件：** 点右上角“上传文件”，选电脑或手机里的文件。
- **粘贴文字：** 点右上角“粘贴文字”，把微信里复制的话粘进去，点“加入收件箱”。
- **发给公司的机器人：** 管理员会告诉你机器人叫什么、在企业微信、飞书还是钉钉里。单独发消息给它就行；在群里发要先打 @，再选机器人的名字。钉钉群里只收文字和图片。机器人会回“已收到”，或者说为什么没收下。客户发给你的文件，要你自己转发给机器人。
- 超过 20MB 的文件收不了。
- 没处理的、忽略了的，放 180 天（大约半年）后自动清掉。已处理的一直留着。

### 处理一条

1. 点左边“收件箱”。页面标题下面有“待处理”“已处理”“已忽略”三个页签，点“待处理”。
2. 点一条，右边打开详情。
3. 按情况选一个：

| 这一条是 | 点 | 会怎样 |
|---|---|---|
| 客户的订单文件 | 转订单 | 文件进“AI 导入”，照“接单”一章“用文件建订单”做 |
| 供应商的送货单文件 | 转到货 | 文件进“AI 导入”，按到货单识别 |
| 一段文字，或 PDF/Word/Excel/JPG/PNG 以外的文件 | 新建订单 | 本页直接打开新建订单窗口，上方显示原文或原文件下载链接，对照着填；保存后自动把这条标为已处理、人留在收件箱页（若标记失败，订单已建立，页面会提示失败原因） |
| 自己处理完了 | 标为已处理 | 挪到“已处理” |
| 没用的 | 忽略 | 挪到“已忽略” |

文件的“标为已处理”“忽略”在“更多”里。只有 PDF、Word、Excel、JPG、PNG 文件能转订单、转到货。

**点错了怎么办：** 在“已处理”或“已忽略”里点这一条，点“恢复待处理”。

## 接单（客户订单）

### 用文件建订单（AI 导入）

“AI 导入”就是让电脑读客户的订单文件，自动把客户、产品、数量、单价填好，你核对后变成订单。

1. 点左边“AI 导入”，点右上角“上传文件”，选客户的订单文件。从收件箱点“转订单”来的，文件已经在这里。
2. 在左边的文件列表里点这份文件。右边最上面一排有“客户订单”“到货单”两个按钮，点“客户订单”。
3. 点右上角“开始识别”。等一会儿，结果会填到页面上。
4. 对照原件一格一格看。点右上角“原件”能打开或收起原件。带黄色提示的地方要细看。
5. 看客户和产品选对没有。没选上的，从它给出的几个名字里点一个，或者导入时新建。
6. 都对了，点页面下方的“导入订单”。这时只是打开一个“导入为正式订单”的窗口给你最后核对，还没导入。
7. 窗口里每个产品后面写着“已有”还是“新建”。有“同名产品要确认”的，看清是不是另一个产品，是就勾“是另一个产品”。
8. 勾上“我已核对明细、客户和产品（含要新建的）、金额和税费，确认按上面导入。”，点窗口下面的“导入订单”。这一下才真的导入。

**做完以后：** 页面上写“已导入订单 ……”，点底部的“查看订单”能打开它。

- 客户名字只差“有限公司”这类后缀的，系统会自动选上。
- 产品名称和尺寸都对上的，也自动选上。这位客户以前订过、名称和规格都一样的，也直接选上。
- 名字差不多的（比如“纸箱1”和“纸箱10”），系统不替你猜，会列出来让你选。
- 原件没写下单日期，会标“下单日期缺失”，补上才能导入。
- “含税口径”就是价格含不含税，只有“含税”“未税”“未明确”三种。原件没写就是“未明确”。原件写了别的说法（比如“不含税”），要你自己改选一种。
- 原件没写整张订单的交期、每行各写了交期：整单交期先填最晚的那一行，请核对。

**改错了怎么办：** 点“撤回修改”，退回上一次改动。它只退识别结果，不会撤销已经导入的订单。识别得全不对，点右上角“更多”里的“重新识别”。

### 手工新建订单

**什么时候用：** 客户打电话、发文字下单，或者你想直接录。

1. 点左边“订单”，点右上角“新建订单”。
2. 在“客户”那一格打几个字，从下面跳出来的名单里点中这一家。名单里没有，点这一块右上角的“新建客户”。
3. “下单日期”已经填好今天，不对就改。选“交货日期”。客户有自己的采购单号，填在“客户采购单号”。
4. 在“订单明细”里，“产品”那一格打几个字，点中这个产品。没有这个产品，点这一格右边的“+”新建。
5. 填“数量”和“单价（元）”。还有别的产品，点这一块右上角的“添加明细”再加一行。
6. 都核对好了，点“保存并确认”。还要等客户再确认的，点“保存”，订单是“待确认”，以后再确认。

**做完以后：** 订单出现在列表里。“待确认”的订单不能安排生产和送货。

- 从客户详情点“新建订单”，客户已经填好。在产品列表勾选几种点“新建订单”，产品已经加好。
- 产品的参考单价空着，就是还没定价，单价要自己填；填 0 就是 0 元。单价不能超过 1000000 元。
- 有一行没填单价，合计显示“—”。
- **预估成本：** 想看这单大概能赚多少，点窗口下方的“更多信息”，勾“录入预估成本”，填这张订单的材料、加工等各项花费。不填也不影响下单。

### 确认订单

平常用第一种：

- 打开“待确认”的订单，点“确认订单”，订单马上变成“已确认”。
- 在“今日”的“待确认”里点“确认订单”，会先弹出窗口写着客户、交货日期、产品，核对后再点窗口里的“确认订单”。

**改错了怎么办：** 在订单详情的“更多”里点“退回待确认”。客户不要了，点“取消订单”，写原因；以后还能在“更多”里点“恢复为待确认”。

### 看订单做到哪一步

- 打开订单，“下一步”那一句写着接下来要做什么，比如“先安排订料”。要点的按钮在详情最上面一排，实心的那个就是下一步；不在外面的在“更多”里。
- 下面列着每个产品订了多少、已发和待发多少、库存可用多少、排没排产。
- 订单列表上的“进度”有四个圈，依次是订（下单）、料（订纸板）、产（生产）、送（送货），走到哪一步就亮到哪一个。
- “待确认”“已确认”“已取消”是人改的；“生产中”“待发货”“部分发货”“已发货”跟着生产和送货自动变。
- 每个产品都做够订单数量，才算“待发货”。做好的那部分可以先送，送了一部分是“部分发货”。

### 几张订单一起办

1. 在订单列表勾选几张订单，屏幕下方出现一条操作栏。
2. 选一个：
   - **安排送货：** 按交期先后用现有库存排，一个客户一张送货单。
   - **安排生产：** 同一种产品合成一张生产任务。要做的数量先按“还没发的减去库存里有的”算好，可以改。
   - **安排订料**（在操作栏的“更多”里）：向供应商订纸板。窗口上方选这几张订单“合成一张采购单”，还是“每张订单一张”。一张采购单只能是一家供应商。

已经在生产的、还没确认的订单不会排，窗口里写原因。

## 客户和产品

### 新建客户

1. 点左边“客户”，点右上角“新建客户”。
2. 填“客户名称”。联系人、联系方式、地址、备注可以以后补。
3. 点“保存客户”。

### 新建产品

1. 点左边“产品”，点右上角“新建产品”。
2. 填“产品名称”，点“保存产品”。别的可以以后补：打开产品点“编辑”再填。

几个栏目的意思：

| 栏目 | 填什么 |
|---|---|
| 长、宽、高，尺寸单位 | 纸箱的尺寸，单位选毫米或厘米 |
| 材质 / 配纸 | 用什么纸，比如 K=A |
| 楞型 | 瓦楞的种类，比如 BC、E |
| 参考单价（元） | 平常卖多少钱一只，不知道就空着 |
| 加工要求 | 印刷、钉箱这类要求 |
| 附属于 | 小箱套在大箱里，就在小箱这里选大箱；只是列表里挂在一起，价格、库存各算各的 |

资料没填全的产品，产品页上方会写“资料不全”，点它只看这些。尽早补全，不然订单里规格可能对不上。

### 改资料、收起不用的

- 打开客户或产品，点“编辑”，改完保存。
- 不再用的，在“更多”里点“归档”。要找回来，见“归档和删除”。

### 唛头和样稿

唛头是印在纸箱上的图样、样稿是给客户看的样子。它们只是挂在产品下面的参考文件，系统不读里面的内容。

1. 打开产品，往下翻到“唛头”那一节，点“上传唛头”，选文件，可以写一句说明。
2. 以后在产品、订单、生产任务的详情里都能点开看。

也可以把文件发给助手，让它挂到产品下。

## 采购订货

采购订货就是向供应商订纸板。顺序是：建采购单 → 把订货单发给供应商 → 货到了登记到货。

### 建采购单

**什么时候用：** 订单确认后，纸板不够。

1. 打开订单，“下一步”会写“先安排订料”，点详情上面的“安排订料”。窗口里已经关联了这张订单，每个要生产的产品带出一行纸板，材质和楞型照产品填好。
2. 在“供应商”里打几个字，选中一家。
3. 每行纸板填“长”“宽”：纸板要裁成多大，就填多大，系统不替你算。以前订过的会带上次的长宽，标着“参考上次”。
4. 填“订货数量”，单位是张。
5. 选“计价方式”：供应商按面积报价的选“按平方米”，按一张多少钱报价的选“按张”。再照报价填单价，不知道可以先空着。
6. 库存里已经有这种纸板的，在“库存里已有的纸板”里选它，长宽就跟着它，不用填。
7. 最后看要不要把订货单发给供应商：
   - 要发：点“保存采购单”，接着照下面“发订货单”做。
   - 电话里已经订好、不用发：点“保存为待到货”。

**做完以后：** 采购单出现在“采购单”页。

- 还要订别的纸板，点“加一种纸板”。
- 不从订单来的，在“采购单”页点“新建采购单”，或在供应商详情点“新建采购单”，或在库存里纸板的详情点“安排订料”。

### 发订货单

1. 打开采购单，点“导出订货单”。同一家供应商的几张，也可以在列表里勾选后一起导出。
2. 想写清什么时候要货：每行写“多少张、在哪天前到”，分几批到就写几段。不写也行，以后再改。
3. 选“格式”：Word 或 Excel。想先看看，点“预览”。
4. 点“导出订货单”。

**做完以后：** 文件存到电脑或手机里，用微信等发给供应商。这几张采购单变成“待到货”。

- 两个人几乎同时导出，后一个会被提示号被占用，重新导出一次就好。
- 同一批采购单导出了两份时，系统会提示哪一份作废。作废的那份不要发给供应商。
- 只想再下载一份、不改状态：在导出窗口的“更多”里点“只导出文件，不改状态”。

### 改、取消采购单

- 改内容：打开采购单点“编辑”。
- 改什么时候到：采购单详情里点“编辑到货安排”。
- 不要了：在“更多”里点“取消采购单”。

## 到货

先记住：**实到 = 合格 + 拒收**。实到是这次送来多少张；拒收是不要、退回去的；合格的才加进库存。

### 登记到货（有采购单的）

**什么时候用：** 供应商把订的纸板送来了。

1. 点左边“到货”。页面最上面一块叫“待到货”，列着还没到齐的订货单。找到这一家，点这一行的“登记到货”。也可以在“今日”的“待到货”里点。
2. 选“到货日期”。供应商的送货单上有单号，填在“供应商送货单号”。
3. 每种纸板填“本次实到”。有不要的，填“其中拒收”。
4. 少见的情况：合格的没有全部放进仓库，点这一行的“合格的没全部入库？”，填真正入库多少。
5. 点“登记到货”。

**做完以后：** 合格的纸板马上加进库存。没到齐的继续留在“待到货”里，下次再登记。过期还没到的标红。

### 用照片识别送货单

1. 在“到货”页点右上角“AI 识别送货单”，上传供应商送货单的照片或文件，点“开始识别”。
2. 核对时选这批货是哪份订货单（对得上的自动选好）。多送的、样品选“不挂采购单”。
3. 识别完就登记成“待入库”，还没加库存。因为是电脑读的，要人再看一遍：在同一页右边点“核对入库”，没错再点“确认入库”。

### 没有采购单的货

**什么时候用：** 供应商多送的、送来的样品。

1. 在“到货”页点右上角“更多”，点“登记没有采购单的到货”。
2. 选供应商，填“供应商送货单号”“到货日期”。
3. 库存里已经有这种纸板的，在“入哪个库存”里选它，名称、材质、楞型、长、宽跟着带出来。新的纸板，填“纸板名称”，知道的材质、楞型、长、宽也填上。
4. 填“实到数量（张）”，在“差异原因”里写明为什么没有采购单。
5. 点“登记到货”。这时是“待入库”。
6. 打开这张到货单，点“核对入库”，没错再点“确认入库”，才加库存。

### 退货给供应商（采购退货）

1. 打开已经入库的到货单，点“采购退货”。
2. 在要退的那行填“本次退货”，填退货日期和原因，点“确认退货”。

**做完以后：** 库存扣掉，采购单上已到的数量也减掉，供应商补送时还能再登记到货。纸板只能整张退。

### 到货登记错了

照“改已生效的单据”那一章选改法。到货单特别要注意：

- 货是退给供应商的，用“采购退货”，不用更正。
- 有采购退货没撤销时，要先请管理员撤销退货，才能更正或撤销这张到货。
- 这批纸板已经领去用掉、库存不够扣的，撤销不了。

## 生产

### 安排生产

**什么时候用：** 订单要的货，库存不够。

1. 打开订单，点详情上面的“安排生产”（不在外面就在“更多”里）。
2. 窗口里每个产品一行。“本次生产”已经算好，可以改。选“计划日期”，默认今天。
3. 点窗口下面的“安排生产（N 张）”。N 是这次会生成几张生产任务。

**做完以后：** 生成生产任务，在“生产任务”页的排产板（按日期排的生产计划表）上显示待生产。

- 没有订单、先备货：在“生产任务”页点右上角“安排生产”，在窗口里点“加一种要生产的产品”。也可以在产品列表勾选几种后点“安排生产”。
- 还没登记完工的任务可以“编辑”。已经登记过完工的不能改：少做了就取消剩下的，多做了再安排一张。
- 取消任务：打开任务，在“更多”里点“取消这张任务”，写原因。已经做完的部分保留。

### 登记完工

**什么时候用：** 机台做完了，数清楚了，要把成品记进库存。还没数清楚的，看下面“还没清点完”。

1. 在“生产任务”页点右上角“登记完工”，或在任务详情里点“登记完工”。
2. 选“完工日期”，在“机台操作”里填是谁做的。
3. 在“做完了哪些任务”里勾上做完的任务（从任务详情点进来的，这张任务已经列在“做完多少”里，不用勾）。勾上以后“合格”才能改，里面已经填好还差的数量，照实际改；做坏的填在“报废”。
4. 在“领了哪些纸板”第一行点“选择纸板”，打几个字选中这种纸板，填“领用（张）”。没用完、退回仓库的填“退料（张）”。领了好几种，点“加一种纸板”。
5. 想记一句这批的情况（用的什么料、质量怎样），写在“批次备注”。
6. 点“登记完工”。

**做完以后：** 成品马上进库存，领的纸板从库存扣掉。

- 几张任务用的是同一批纸板：在同一个窗口里一起勾上、一起登记。
- **打样、补做，没有任务的：** 在“不挂任务的完工”里点“加一行”，选产品，填合格和报废。
- **还没清点完：** 不点“登记完工”，点窗口下面“更多”里的“先登记，稍后核对入库”。这时库存不动。数清楚以后，到“完工记录”打开它，点“核对入库”。
- 完工日期不能晚于今天。合格数不能超过还差的数量。

### 完工单弄错了

| 情况 | 怎么办 |
|---|---|
| 先登记了、还没核对入库，发现登记错了 | 在“完工记录”打开它，在“更多”里点“取消这次完工”，写原因。成品不入库，纸板不扣 |
| 已经入库，只是机台操作、批次备注写错 | 点“编辑” |
| 已经入库，合格、报废、领料数错了 | 找管理员用“更正完工单” |
| 已经入库，其实根本没做 | 找管理员用“撤销这次完工” |

## 送货

### 安排送货

**什么时候用：** 货做好了，要给客户送。

1. 打开订单，点详情上面的“安排送货”（不在外面就在“更多”里）。
2. 核对“计划送货日期”（默认今天），和“收货联系人”“联系方式”“收货地址”（照客户资料带出，可以改）。
3. 看“本次送货”的数量，可以改。有送不了的货，窗口下面会多出一块“这次送不了的”，写着为什么送不了；全部能送就没有这一块。
4. 点“安排送货（N 张）”，N 是会生成几张送货单。

**做完以后：** 送货单出现在“送货”页，状态是“待送货”。这时还没扣库存，但这批货已经留给这张单子，别的单子用不了。

上面是最常用的做法。也可以：

- 在“送货”页上方“可发货”里勾选几行，点“安排送货”。几张订单一起排时，按交期先后分库存。
- 在“送货”页点右上角“安排送货”，先选“送给哪个客户”，再排。
- 在库存的成品详情里点“安排送货”。

### 导出送货单，货出库

1. 打开“待送货”的送货单，点“导出送货单”。也可以在“今日”的“可发货”里点。
2. 选 Word 或 Excel。想先看看，点“预览送货单”；看完点窗口下面的“返回导出”。
3. 点“导出并出库”。

**做完以后：** 文件存好，成品库存扣掉，订单算已发，送货单变成“送货中”。在电脑上打开这个文件，点打印，随货送去。

- 送货单上印的日期是出库那天。联系人、地址空着的，印“未记录”。
- 不要文件、直接出库：在“更多”里点“不导出直接出库”。
- 已经出库的再下载一份：打开送货单点“送货单”，点“导出Word”或“导出Excel”，不会再扣库存。

### 确认送达

1. 客户收到货后，打开这张送货单，点“确认送达”。
2. 选“送达日期”，就是客户签收那天，点“确认送达”。

只是记一下，不动库存。送达日期不能早于出库那天，不能晚于今天。

### 送不了、送多了

- **窗口里说规格对不上：** 订单上写的规格和产品现在的不一样，提示里会并排写出哪一项不同。打开订单点“编辑”，把那一行的规格改成和产品一样，再排。
  - 空格、斜杠、逗号多一个少一个，不算不一样。
  - 横线、下划线算不一样，比如“A-11”和“A1-1”是两个规格。
- **要比订单多送：** 跟管理员说清哪张订单、多送多少、为什么，由管理员来排。
- 送货一定要对应一张订单。

### 送货单弄错了

照“改已生效的单据”那一章选改法。

## 改已生效的单据

“已生效”就是已经动了库存的单子：已入库的到货单、已出库的送货单、已入库的完工单。这样的单子填错了，不能直接改数量，按下面选：

| 遇到什么 | 用哪个 | 谁能做 |
|---|---|---|
| 数量没错，只是备注、时间、地址、联系人写错 | 编辑 | 自己 |
| 数量登记错了，或某一行其实没有 | 更正到货单、更正送货单 | 自己；完工单找管理员 |
| 整张单子根本没发生 | 撤销这次到货、撤销这次送货 | 自己；完工单找管理员 |

### 编辑（只改说明）

1. 打开单子，点“编辑”。
2. 改完点“保存”。库存和金额不变。

能改的：到货单的到货时间、备注；送货单的收货地址、联系人、联系方式、实际送货时间、备注；完工单的机台操作、批次备注。

### 更正（数量错了）

1. 打开单子，点“更多”，点“更正到货单”（或“更正送货单”）。
2. 在“正确数量”里填对的数。到货单后面还有“合格”“拒收”“入库”，这几个也错了就一起改，不动就跟着算。送货单有一行其实没送，点那一行后面的删除；至少留一行。
3. 在“更正原因”里写为什么改。窗口会自动算出改完以后库存、订单会怎么变，看一遍。
4. 点“提交更正”。

**做完以后：** 原来的单子标“已更正”，另外出一张新单号的单子，顶上写着“更正自 原单号”“已更正为 新单号”。不用重新给客户纸面单子。

- 客户已经签收的送货单也能更正。出库日期、送达记录和单价都照原来的。
- 数量改多了、超过订单剩下的，找管理员。
- 已归档的单子先恢复再更正。已经更正过的，打开最新那张再改。

### 撤销（整张没发生）

1. 打开单子，点“更多”，点“撤销这次到货”（或“撤销这次送货”）。
2. 在弹出的窗口里写原因，点窗口下面的“撤销这次到货”（或“撤销这次送货”）确定。

**做完以后：** 库存、订单已发、采购已到货都改回来。单子留着，标“已撤销”。库存已经被后面的单子用掉、不够扣的，撤销不了。

### 让助手改

也可以跟助手说，比如“送货单 SH-… 实际只发了 550 只”。它会出一张确认卡片，写清改哪张单、每行原来多少、改成多少、库存怎么变，你点“确认执行”才改。

## 单据导出和模板

订货单、送货单像印好的多联单：每张纸铺满，明细的行数是固定的，货少就只填前几行。

- 超过一张会自动接到下一张，合计金额只写在最后一张。
- 一格写不下会先缩小字，再加高。一整张纸都放不下，就不出文件，提示哪一行哪一格太长。
- **Word 还是 Excel：** 用老式的针式打印机（打多联单的那种）选 Word，纸张尺寸准；想在电脑上再改选 Excel。
- 导出的文件在系统里留 180 天，这期间在助手聊天里的文件卡片上能再下载。过期了重新导出一份就行。

### 改单据的样式

一般员工不用动，公司定好一次就行。要改时：

1. 点左下角“设置”（手机上在左上角三条横线的菜单里），点“单据模板”。
2. 选“采购订货单”或“送货单”。
3. 选纸张：送货单默认针式 241×93（一张纸分三份），还能选 241×140（分两份）、A5 横向、A4；订货单默认 A4 竖版。
4. 改公司资料、联次（一式几联）、签字栏、条款和明细的列。
5. 点“刷新预览”看一张纸放几行。明细的列弄乱了，点“恢复默认”。
6. 点“保存模板设置”，改的才生效。

想要好几套样式，在“更多”里点“复制为新模板”。导出时在导出窗口的“模板”里选用哪一套。

## 库存

**什么时候用：** 看还有多少纸板、多少成品。

1. 点左边“库存”。上方有“原材料”“成品”两个页签，点要看的。
2. 点一行看详情。

**几个数的意思：**

| 数 | 意思 |
|---|---|
| 在库 | 仓库里现在实际有的 |
| 已安排 | 已经排在待送货的单子上，还没出库 |
| 可用 | 在库减去已安排，还能拿去用的 |
| 在途 | 订了还没到的 |

库存不会变成负数。只想看哪些没货了，点右上角“更多”，点“只看零库存”。

### 手动出入库、盘点

**什么时候用：** 不是从单子来的进出；或者数了一遍，和系统里的数对不上。

1. 打开这种纸板或成品，点“出入库 / 盘点”。
2. 在“操作类型”里选“手动入库”“手动出库”或“盘点调整”（照你数出来的数改）。
3. 入库、出库填“本次数量”；盘点调整填“实盘数量”，就是你数出来的数。
4. “业务日期”选是哪天的事，在“用途”里写为什么。
5. 勾上“已核对实物和数量，确认登记这笔流水。”，点“确认库存变动”。

**做完以后：** 记一笔流水，库存跟着变。

**记错了怎么办：** 再做一笔反方向的，或者再做一次盘点调整。

### 新建库存品

1. 在“库存”页点右上角“更多”，点“新建原材料库存品”（成品页签那边是“新建成品库存品”）。
2. 原材料填名称、尺寸、材质 / 配纸、楞型；成品先选是哪个产品。
3. 点“保存库存品”。

- 同一种货只能有一个。名称、规格、尺寸、材质、楞型都一样的纸板就是同一种，保存时会提示你“打开它”。120cm 和 1200mm 算一样。
- 质量不同的纸板，在名称或规格里写清楚，分开建。
- 一个产品只有一个成品库存，名称、规格跟着产品走，自己只能改备注。
- 已经进出过的库存品，不能在原材料和成品之间改，成品也不能换产品。要改就新建一个。

### 流水

点左边“流水”，能看库存每一次进出。库存数就是这些流水加减出来的，流水不能删。

- 单子带出来的流水记错了，点“去更正原单据”，到原来的单子上改。
- 流水被改过的，详情下面有修订记录。

### 成品批次

打开一种成品，往下翻到“批次”。每次完工入库算一批，写着完工日期、入库多少、估计还剩多少、生产任务、订单、用料、批次备注。

- “估计还剩”是系统推算的：送货时先扣同一张订单做的那批，再扣最早做的。送货时不用自己选批次。
- 要补批次备注，点“写备注”或“编辑备注”，库存不变。
- 纸板没有批次。

## AI 助手

**打开：** 电脑上同时按键盘的 Ctrl 和 J，或者点屏幕右下角的两个小人（小甬、小勒，点哪个都一样）。手机上点底部“助手”。

### 能让它做什么

用平常说话的方式打字或说话，比如“这周要发哪些货”“给东海电器建一张订单”。它能查东西、帮你建单改单、看你发的文件和图片、读订单和送货单、上网查资料。你的账号办不了的事，它也办不了，会直说该找谁。

- 小甬先说结论和下一步，管收件箱、AI 导入、客户、产品、唛头、订单、送货。
- 小勒先说数字和依据，管采购、供应商、到货、库存、流水、生产。
- 想让谁答就点名，比如“小勒，查一下库存”。
- 它不会替你打电话、发微信。联系客户、供应商、同事要你自己去，它会提醒你找谁、问什么。

### 改东西都要你点确认

它要新建、修改、删除、导入、出库这类事，不会自己动手，而是先弹出一张确认卡片：

1. 看卡片：第一行写改的是哪一条，下面写每一项原来是什么、改成什么，库存从多少变成多少。
2. 对了点“确认执行”；不要就点“不执行”。

- 卡片 15 分钟不点就作废，一张卡片只能执行一次。
- 卡片出来后数据被别人改了，点确认会被拦下，助手会按最新的再出一张。
- 卡片上写“执行没有成功”或“已经发出去，结果不明”的：先查一下现在的情况，再让助手重新出一张。
- 只是查东西、开始识别文件、下载文件，不出卡片。

**拿不准它做没做：**

- 看每条回复最下面那一行：“只查询，没有改动”“待确认：……”“已执行：……”“没做成：……”。以这一行为准。
- 不要急着把同样的话再说一遍。再说一遍会再出一张卡片，确认了就会再做一次。

### 发文件和图片

1. 点输入框左边的“+”，选文件；也可以直接把文件拖进来，或粘贴图片。
2. 一条消息最多 6 份，每份不超过 10MB，加起来不超过 30MB。
3. 说“识别这张订单”，它就开始读。读好的结果到“AI 导入”里核对，导入时也出确认卡片。

读过的不会重复读、不重复收费。上次中断或失败的，说“重试”。

### 打字和说话

- 电脑上按回车发送；按住 Shift 再按回车是换行。用拼音选字时按的回车不会发出去。
- 手机上回车是换行，点发送按钮发出去。
- 点麦克风可以说话。回复下面点“读出来”，它会念给你听。
- 输入框旁的“思考”有关、低、高、最高四档：越高想得越久、答得越稳。平常不用动。

### 它会记住你的习惯

它会自己记住你的一些习惯，你也可以说“记住……”。记了什么，在那条回复下面写着“已记住：……”，点后面的“忘掉”就删了。

- 在助手窗口右上角“更多”里点“记忆”，能看、加、改、删全部记忆，也能关掉自动记。
- 每人一份，只有自己看得到。
- 带密码、验证码的话它不记，会说“这句话里像是有密码或密钥，没有记”。

### 别的

- **上网查：** 行情、政策这类系统里没有的，它会上网搜。回答下面有“来源”，点开能看是哪个网页。
- **帮你打开页面：** 它能看你眼前的页面，帮你打开某张单子，但不会替你点页面上的按钮、填表。
- **一句话要办的事太多：** 办到一半会停下，说清做到哪、还差什么。
- **断线：** 会自动重试，最多 5 次。还不行就说没办成。程序中途重启，会话里会写一句“程序中途重启了……”，接着说就行。
- **不乱填：** 你没说清的，它会先问你。
- **删聊天记录：** 跟它说“把聊天记录全部删掉”；或者点助手窗口右上角“更多”，点“清空会话”。删了找不回来。
- **点了没反应、保存不了：** 可以问它，它会查最近出了什么错。

## 归档和删除

- **归档就是收起来：** 办完的单子、不用的客户产品，打开后在“更多”里点“归档”。它不再出现在平常的列表里，随时能找回。
- **还没办完的归档不了：** 订单没发完货、采购单没到齐、单子还没核对、生产任务没做完、库存不是零，点“归档”会写着为什么不行，先办完再归档。
- **找回归档的：** 最方便的是在原来那一页的列表上方点“已归档”页签。也可以点左边“归档”，在“查看”里选是订单、客户还是别的。点开那一条，在“更多”里点“恢复”。
- **删还没核对的单子：** 待送货的送货单、待入库的到货单和完工单，还没动库存，打开后在“更多”里删。
- **已经出库、入库的单子错了：** 用撤销，见“改已生效的单据”。
- 删客户、产品、订单这类资料，找管理员。

| 遇到什么 | 怎么办 |
|---|---|
| 单子填错了 | 还没入库、出库的，打开点“编辑”；已经入库、出库的，看“改已生效的单据” |
| 不知道下一步做什么 | 打开订单看“下一步”那一句，或看“今日”页 |

| 识别失败 | 告诉管理员，多半是 AI 的设置要处理。原因在 AI 导入右上角“更多”的“历史与归档”里 |

## 财务

这一章给财务和出纳看。财务管账，出纳管钱，谁能做哪一步看下面“登录后看到什么”里的表，各节不再重复。

**送货、到货、收付款都不用等财务：** 单子上没写税率也照常做，财务事后补。只有出正式报表和结账时才要求补齐。科目、报表和税率还没请懂账的人复核，先当内部参考。

**几个常用词：**

- **核销：** 把收到、付出的一笔钱，对上是哪几张单子的货款。
- **账期：** 约定的多久付款。
- **凭证：** 记账用的单子，一笔账一张。
- **红字冲销：** 记错了不删，另记一笔负数把它抵掉。
- **计提：** 月底把这个月该算的工资、折旧、税费先记上账。

### 登录后看到什么

- **财务账号：** 登录后先到“今日”。侧栏和业务员一样，多一个“财务”，点它进财务页面。业务页面看前面业务员的各章。
- **出纳账号：** 登录后直接到“财务概览”。侧栏只有财务的几个页面和“使用说明”。
- **顶上一排页签** 切换财务各页，比如“月度台账”“资金发票”。下面一排是这一页里的小页签。
- **月份：** 大多数页面右上角有“月份”，换一个月，下面的数跟着换。
- **详情：** 点列表里的一行，右边打开详情。详情上方是能做的按钮，不常用的在“更多”里。
- **手机上：**
  - 出纳点屏幕最下面一排：“概览”“应收应付”“助手”“资金”“凭证”。
  - 财务账号点左上角三条横线的按钮，在打开的菜单里点“财务”。
  - 页面顶上那排页签显示不全，用手指按住往左滑，就能看到后面的。
  - 列表是一张张卡片，点卡片看详情。
  - 安卓 App 里，出纳按返回键回到“财务概览”。出纳用不了 AI 导入，分享文件进来会提示“当前账号不能使用 AI 导入”。

**财务和出纳谁做什么：**

| 事情 | 财务 | 出纳 |
|---|---|---|
| 看全部财务页面、导出 | 能 | 能 |
| 收款、付款、银行流水、承兑汇票、员工借还款、费用付款、发工资、保证金收和退 | 做不了，要出纳来做 | 能 |
| 录收款时当场核销 | 做不了 | 能 |
| 收款已经确认、以后再核销，或撤销核销 | 能 | 做不了 |
| 启用财务、建资金账户、补税率、账期、压款利息、发票、凭证、费用单、工资表、固定资产、算成本、结账、财务设置 | 能 | 做不了，只能看 |

### 第一次用：启用财务

**什么时候用：** 开始在系统里记账的第一个月做一次。只想看盈亏可以不启用。

1. 点“财务设置”页签，再点右上角“启用财务”。
2. “启用月份”选开始记账的那个月。比它早的单据不记账，也补不了税率。
3. “纳税人身份”选“一般纳税人”或“小规模纳税人”，不知道就问会计。
4. 期初余额是启用那天账上已有的钱、欠款和库存。有的，点“加一行”，按科目一行一行填。应收、预收每个客户一行，应付、预付每个供应商一行。没有就空着。
5. 点“确认启用”。

**做完以后：** 期初和纳税人身份不能再改。原材料、库存商品的期初金额，以后第一次算成本时要再填一样的数，系统不帮你核对。

**接着做三件事：**

- **建资金账户：** 点“资金发票”，再点“账户和流水”，点“新建资金账户”。“名称”写基本户、现金这类，“类型”选银行或现金，“对应科目”选一个，点“保存账户”。没有资金账户，出纳没法录收付款。
- **只有一个人做账：** 系统默认凭证要两个人经手，自己做的凭证自己审核不了。这个开关只有管理员能改，财务账号看不到。请管理员登录，点“财务设置”，点“编辑设置”，把“制单和审核必须不同人”前面的勾去掉，点“保存设置”。
- **填税率：** 结账前在“财务设置”点“编辑设置”，填“城建税率（%）”“教育费附加率（%）”“地方教育附加率（%）”“所得税率（%）”，不用缴的填 0，系统不给默认值。点“保存设置”。

### 每月看什么

**什么时候用：** 想知道这个月赚了多少、收了多少钱。

1. 点“财务概览”。
2. 右上角“月份”选要看的月。
3. 看最上面那张表，两种盈亏互不影响：

| | 收入 | 支出 |
|---|---|---|
| **理论** | 本月送货单金额 | 本月到货单金额 |
| **实际** | 本月收到的钱 | 本月付出的钱 |

- **蓝色的金额点一下，** 下面列出每一笔，可以点“导出”，看完点“收起”。点其中一行看这张单子。
- **“需要处理”** 列着要办的事，点它直接过去。
- **“本月实收来自哪个月的单子”** 看这个月收的钱是几月份的货款。
- 补税率、拿优惠、收利息都不改理论盈亏。房租、工资、水电录了付款就算进实际支出。
- “本月接单”不算待确认、已取消的订单，算已归档的，和今日页的“本月接单”“本月发货”同一口径；理论收入、理论支出和经营概况的“送货金额”“到货金额”是同一个数。
- 最下面“记账口径”是按凭证算的收入、成本、利润，和上面的理论、实际是两回事。
- 要存一份：右上角“更多”，点“导出本月经营报表”。

### 月度台账和补税率

**月度台账** 列着这个月每一笔接单、送货、到货、收付款。上方切“全部”或“待补税率”，点“筛选”只看某一类；右上角“更多”里有“导出台账”。点一行看明细，详情上的“打开订单”这类按钮跳到原单据。

**补税率**

**什么时候用：** 送货单、到货单没写税率，台账里标着“待补税率”。金额本来就是 0 的，比如赠品、整批拒收，不用补。

补一张：

1. 点“月度台账”，再点“待补税率”。
2. 点要补的那一行，右边详情里有“补税率”一节。
3. 每一行填“税率（%）”，“口径”选含税或未税。“依据”可以写合同约定或对方开的票。
4. 点“保存税率”。不开票的，直接点“填成无税 / 不开票”。

几张一起补：

1. 在“待补税率”里，勾上每行前面的小方框。表头那个方框是全选这一页。
2. 点页面底部的“补税率”。
3. “补法”选“填写税率”，再填税率和口径；或者选“无税、不开票”；或者选“用往来单位默认税率”，按账期里给这家设的默认税率补。
4. 点“保存税率”。

一个单位一整个月一起补：什么都不勾，点右上角“补税率”，选“客户（送货单）”或“供应商（到货单）”，再选是哪一家，照上面填好，点“保存税率”。

**做完以后：** 页面提示补了几张，这几行不再是“待补税率”。补税率只改财务记录，不动送货单、到货单原件，也不改理论盈亏。

### 账期和压货款

**什么时候用：** 和客户、供应商约好多久付款、有没有现结优惠时，先设好，系统按它算到期日。

1. 点“应收应付”，再点“账期”。
2. 右边选“应收（客户）”或“应付（供应商）”。
3. 点“新建客户账期”，应付那边是“新建供应商账期”。
4. 在“客户”那一格打几个字，从跳出来的名单里点中这一家。
5. “账期方式”三选一：
   - “没有账期（到期日留空）”：不算逾期。
   - “压几个月，每月固定日付款”：填“压几个月”“每月几号付”，要的话填“每月几号截止”，截止日之后的单子算到下个月。
   - “压若干天”：填“压多少天”。填 0 是当天到期。
6. 有现结优惠的，点“加一档优惠”填比例，比例自己定，系统不内置。默认税率、口径、授信额度、分期用到才填，授信超额只提醒。
7. 点“保存账期”。

- **改了账期：** 只管以后的新单子。已有的单子要按新账期重算，到“欠款明细”点右上角“更多”，再点“按新账期重算到期日”。
- **压款利息：** 账期里勾“这个单位要算利息”，填利率。“账期”页下面的“压款利息”一节按利率给建议，只算已经过去的逾期天数，确认了才入账。在那一行点“确认利息”，选“算到哪天”，核对金额后确认。一个月可以确认几次，下次接着上次算到的那天算。
- **保证金：** 账期里勾“这个单位有保证金往来”。收、付保证金要出纳在“账期”页“保证金”一节点“新建保证金”；退回也由出纳在保证金详情点“退回”；转抵货款由财务点“转抵货款”。保证金不算收入支出，经营报表里单独列。

### 收款和付款

**什么时候用：** 客户打款进来、给供应商付货款、付房租水电、两个账户之间转钱。**录收款、付款要用出纳账号，财务账号没有“新建收付款”。**

录一笔收款：

1. 点“资金发票”，再点“收付款”。
2. 点右上角“新建收付款”。
3. “类型”选“收客户款”。付货款选“付供应商款”，房租、水电选“其他支出”，账户之间转钱选“内部转账”。
4. 填“日期”“金额（元）”，“方式”选银行、现金、承兑汇票、微信、支付宝或其他。
5. 在“往来单位”里打几个字，从跳出来的名单里点中这一家。
6. “资金账户”选钱进了哪个账户，“说明”写一句，比如“10 月货款”。
7. 点“保存收付款”。这时是“待确认”，还没入账。
8. 右边详情点“确认”。窗口里按到期先后列出这家没结清的单子，勾上要核销的，金额可以改。
9. 点窗口右下角“确认”。

**做完以后：** 页面提示已确认，这家的欠款跟着减少。

- **现在不核销也行：** 什么都不勾也能确认。以后由财务在“收付款”列表点开这笔，点详情上的“核销”，窗口和上面一样。
- **客户让了价：** 核销金额要算上让的钱。例：单子 339 元，让 6.78 元，实收 332.22 元。“核销”格填 339，“优惠”格填 6.78。账期里约好了现结优惠的，点“用 x%，省 …”自动填好。自己填的优惠，要在“为什么让这笔”里写原因。
- 窗口里只列收款那天及以前的单子。
- **还没确认就发现填错了：** 点“编辑”改。
- **确认以后发现录错了：** 有核销的，先请财务撤销核销：财务点开这笔，在“核销”一节那一行点“撤销”。然后出纳在详情“更多”里点“撤销”，填“撤销日期”“原因”，点“确认撤销”。
- **承兑汇票，客户用银行汇票付款时：** 点“资金发票”，再点“票据”，点“新建票据”登记。系统按到期先后冲这家的欠款，冲不完的记成预收或预付。转给别人、提前换钱、到期兑现、被退回，在票据详情点“变更状态”，选“背书转让”“贴现”“到期承兑”或“退票”。
- **银行流水：** 在“账户和流水”点“导入银行流水”，选银行导出的文件，填日期、金额在第几列，点“导入流水”。点一笔流水，在详情里点“匹配”对上凭证，配错了点“解除匹配”。没匹配的不影响结账。“余额调节”填银行对账单余额，生成调节表。

### 欠款和对账单

**欠款明细：** 点“应收应付”，再点“欠款明细”，右边切“应收（客户）”或“应付（供应商）”。

- **“按单位”** 看每家欠多少：最早到期、已到期、没有账期、预收款、已送货未开票、还欠。“还欠”已扣掉没抵货款的预收款，和同一天对账单的期末一样。点一行，下面“逐笔”只列这一家。
- **“逐笔”** 是一张张单子。点开详情能“编辑到期日”，“更多”里有“坏账”。多付了的那笔有“多付转抵”。
- **“账龄”** 看欠了多久。账龄只算已记账的、不含预收款，和“按单位”可能暂时对不上，凭证记账后就对上了。
- **手工记一笔应收：** 右上角“更多”，点“新建应收”，填往来单位、金额、日期、到期日、对方科目、摘要，点“保存”。
- **“到期和计划”：** “到期提醒”看快到期和已逾期的，今日页也会提醒；“现结优惠”列现在结清能享受优惠的单子；“收付计划”估以后几个月收、付多少。

**对账单**

**什么时候用：** 月底和客户、供应商对账。

1. 点“应收应付”，再点“对账单”。
2. 在“选择客户”里选一家，填开始日期和结束日期。
3. 下面列出这段时间的每一笔和期初、期末。
4. 要发给对方：右上角“更多”，点“导出对账单”。
5. 发出去、对方回了话，点“标记对账状态”，选“已发给对方”“对方已确认”或“有差异”，点“保存”。

**冲销过的单子怎么看：**

- 原来那笔标“已冲销”，下面挨着一笔负数，标“红字冲销”。两笔加起来是 0。
- 这两笔不再出现在到期提醒和核销窗口里。
- 按新内容重新记的那笔标“重记”。
- 红字凭证还没记账时，账龄里还看得到原来那张，记账后才去掉。

### 发票

**什么时候用：** 给客户开了票、收到供应商的票，登记进来。

1. 点“资金发票”，再点“发票”，右边选“销项（开给客户）”或“进项（供应商开来）”。
2. 点“新建发票”。
3. 填“发票类型”“票号”“开票日期”“往来单位”，再填“不含税”“税率（%）”“税额”“价税合计”。“发票原件”可以传 PDF、图片、OFD 或 XML。
4. 点“保存发票”，这时是待确认。
5. 详情点“关联单据”，选这张票对应的送货单或到货单，点“保存”。
6. 点“确认”。

**做完以后：** “开票对比”里这张单子的已开票、未开票跟着变。

- **一批货分几张票：** 关联单据时填“对应暂估”。
- **红字发票：** 新建时金额填负数，“红票对应的蓝票编号”填原来那张蓝票。全额红冲自动冲原票的凭证；部分红冲、原票已有凭证时要填对方科目。开错了重开：先开整张红票冲完，再开正确的蓝票，关联同一笔往来；只冲一部分的折让红票不能用来重开。
- **采购红字发票，退货、折让用：** 按比例冲减应付和库存成本。已经付过款的这笔显示“多付”，在“欠款明细”点它，用“多付转抵”抵这家供应商的下一笔应付，或者让供应商退款。转错了，在付款单的核销记录里点“撤销转抵”。
- **采购退货的钱：** 还没到票的，退货时按这批到货的暂估单价冲减暂估，到票时只转回剩下的；已经到票的，请供应商开红字发票。
- 认证、作废这类，在发票详情点“变更状态”。
- **“税务底稿”** 看本月增值税和附加税费，“更多”里有“导出税务底稿”。只是内部底稿，申报以税局系统为准。

### 凭证

**什么时候用：** 每月把送货、到货记成凭证并记账。

1. 点顶上的“凭证账簿”。页面里有三个小页签：“凭证”“业务单据”“账簿”。点“业务单据”。送货、到货确认后会自动进到这里。
2. 点右上角“生成凭证”，按钮上写着有几张。确认窗里点“生成凭证”。
3. 点小页签“凭证”。右上角会出现“提交本页”“审核本页”“记账本页”，按这个顺序点。“本页”就是列表里现在显示的这些凭证。
4. 每点一个，确认窗里再点一下，再点下一个。

- 凭证要两个人经手时，“审核本页”“记账本页”要另一个财务账号或管理员来点。只有一个人做账，见“第一次用：启用财务”。
- 单张凭证也可以点开，用详情上的“提交审核”“审核”“记账”。
- **单据所在月份已经结账的：** 补录的、结账后才补税率的单据，凭证记在最早没结账月份的 1 号，摘要写明单据日期。到期日、分期、压款利息仍按单据日期算；按送货确认收入时，毛利也算在凭证那个月。
- **手工凭证：** 在“凭证”点“新建凭证”，填日期、摘要，每行选科目、填借方或贷方，点“保存凭证”。应收应付类科目要选单位。
- **记错了：** 已记账的凭证不能改、不能删，错了只能红字冲销：凭证详情“更多”里点“红字冲销”；没记账的在同一处点“作废”。业务单据生成的凭证要到“业务单据”里处理，见下一节。
- **费用、保证金、票据、资产处置、坏账、压款利息生成的凭证：** 不在凭证页作废或冲销，到各自详情里办：还没记账的点“撤回”，已记账的点“红字冲销”。保证金的退回、转抵在保证金详情里一笔一笔办。
- **别的：** “账簿”看各科目的余额，“更多”里有“导出余额表”。“更多”里的“记账模板”看各类单据记到哪些科目；“修改记录”看谁改了什么。

### 单据改了以后

送货单、到货单在业务那边被撤销、更正、删除以后，“业务单据”里会标出来。结账时“业务单据”那一步会拦着，点“去处理”看全部要处理的。

- **还没入过账的：** 自动变“已更正”，不用管。只改备注、地址、确认送达这类不影响金额的，不会出“有差异”。
- **盘点调整的差异：** 点“核对无误”，或者等月末算成本时一起处理，不卡结账。
- **入过账以后被撤销或更正：**
  1. 点开这张，详情里写着改前改后。
  2. 点“红字冲销并重做”。单据已撤销的，按钮只叫“红字冲销”。
  3. 填“更正日期”“原因”，确认。日期默认是撤销那天；那个月已结账的，默认是最早没结账那个月的 1 号。
  - 这张单子已经收过、付过钱的，先撤销核销。
  - 到货开过票的，先开红字发票，再冲销。所以这个月要等红票到了才能结账。
- **单据被删了：** 没入过账的，包括只挂了暂估往来的，自动变“已更正”；盘点流水、完工单被删直接“已更正”，库存数量和成本月末按流水算。入过账的标“单据已删”、拦结账，二选一：点“红字冲销”；或者原凭证记的收入、成本是真的，比如删单时保留了库存流水，在“更多”里点“核对无误，保留凭证”。挂着核销或发票的，先撤销核销或红冲发票再冲销。
- **启用前的单据后来又改了：** 结账清单的“启用前单据的变动已核对”一步一张张列出来，核对后点“核对无误”。这一步只提醒，不拦结账。
- **页面写“正在把业务单据记进财务，还剩 N 张”：** 单据多时分几次记，不是出错。
- **有单据读不出来：** 结账和出正式报表会被拦下，提示里写明是哪张，请联系维护人员。

### 费用、工资和固定资产

这些都是财务做，只有付钱那一步要出纳来做。

**费用报销：**

1. 财务点“费用资产工资”，再点“费用报销”，点“新建费用单”。
2. 填员工工号、姓名、部门、日期、金额、费用科目、说明，点“保存费用单”。
3. 详情点“提交审批”。再点开这张，由财务账号点“批准”，不同意就点“退回”。
4. 批准后生成一张待记账凭证，先到凭证页把它记账。
5. 出纳打开这张费用单点“付款”，填“付款日期”，选“资金账户”，点“确认付款”。

**员工借还款，出纳做：** 在“费用报销”右上角“更多”里点“新建员工借还款”，填好后点“保存借还款”。

**工资：**

1. 财务点“工资”，点“导入工资表”，选算好的工资表。系统只导入汇总，不算个税和社保。
2. 点“计提工资”。
3. 出纳点“发放工资”，填“本次发放”“发放日期”“资金账户”。可以先发一部分再补发，累计不超过实发合计，撤销的那笔不算。

- 计提后工资表要改：“更多”里点“重新导入工资表”，改完要重做计提。
- 没有工资的月份：“更多”里点“本月没有工资，直接计提”。

**固定资产：** 点“固定资产”，点“新建固定资产”，填编号、名称、类别、部门、原值、使用月数、折旧费用科目、付款科目，点“保存资产”。“残值率（%）”填百分数，填 5 就是 5%。换使用部门点“调部门或科目”；卖掉、报废在详情“更多”里点“处置”。每月折旧在结账时点“计提折旧”。

### 结账和报表

**什么时候用：** 每月月底，把这个月的账结掉。要按月份顺序结。

1. 点“报表结账”，再点“结账”，右上角选月份。
2. 照清单一项一项做，每项右边是去处理的按钮：
   - “业务单据都已生成凭证或处理完”：点“去处理”。
   - “凭证都已记账”：点“去记账”。
   - “折旧、工资、成本、税费都跑过”：依次点“计提折旧”“计提工资”“计算成本”“计提税费”。没有工资、固定资产的月份也要点一下。
   - “损益已结转”：点“结转损益”。
   - 计提和结转会生成待记账凭证，要去凭证页记账后才算完成。
3. 每一项都写“完成”后，点左下角“结账”，确认窗里再点“结账”。
4. 点“下载归档文件”存一份，里面有凭证、序时账和三张报表。

**做完以后：** 状态变成已结账，这个月的凭证不能再新建或修改。

- “银行流水都已匹配”不强制，没匹配也能结账。
- 12 月“结转损益”要点两次，第二次叫“结转年度利润”。
- **结错了：** 点“反结账”，写原因，点“确认反结账”。只能反结最近一个已结的月份。反结账后改了数，清单会写哪一步要重做：原凭证红字冲销，按现在的数重新生成。

**正式报表：** 点“报表结账”，再点“正式报表”，切“资产负债表”“利润表”“现金流量表”看，右上角“更多”里导出。它和结账同一个口径：还有没进财务的单据或没补完的资料时出不了正式报表，页面上写着还差几张。“更多”里还有“预算”。

财务页面导出的都是中文表头、能直接求和的 Excel。

### 算成本

**什么时候用：** 结账前，在结账清单点“计算成本”，或者在“费用资产工资”的“成本毛利”里点“计算 某月 成本”。

1. 打开“计算 某月 成本”窗口。第一次算时，“启用前已有的库存，期初值多少钱”一节每种库存品一行，填它启用那天值多少元。这些数加起来，要和启用时填的原材料、库存商品期初一样。
2. “要补金额或对方科目的出入库”一节列着手工出入库，每笔填金额。填 0 表示没有成本。
3. 点“计算”，再去凭证页记账。

- 冲销退回的库存按原成本自动冲回。补登到已算过成本那个月的流水，算进下一个还没算成本的月份。
- 已入过账的到货被撤销或更正：在撤销那个月按原来的暂估把这批冲出库存，不用填。冲完数量是 0 的，到过票、还等红票冲的金额先留着，其余转进主营业务成本。
- 没入过账就作废的到货不算成本。启用前的到货撤销后，仍要在“计算成本”窗口选对方科目。
- 算完以后数又变了：结账清单会写“要重做”，点“重做成本”。
- “成本毛利”页还能看每种库存品的进出金额和每张订单的毛利。

### 财务用助手能问什么

按 Ctrl+J，或点右下角的小甬小勒；手机上点底部“助手”。

**可以这样问：**

- “这个月赚了多少？”它会把理论和实际分开说。
- “某某客户还欠我们多少？哪些到期了？”
- “我们还欠某某供应商多少？”
- “11 月的资产负债表”“这个月的利润表”
- “这个月开了哪些发票？”“今天收了哪些钱？”
- “财务概览上有什么要处理的？”
- “打开月度台账”：它帮你打开页面。

**它只查、不记账：** 补税率、收付款、核销、凭证、结账，都要你自己在页面上点。出纳账号的助手只能查财务。

## 管理员：账号管理

只有管理员账号能做。账号有五种：管理员、业务人员、只读、财务、出纳。出纳只能看财务和使用说明，助手也只能帮他查财务。

### 处理账号申请

1. 点左边“账号管理”。上面“待处理”里是别人提交的申请。
2. 先当面或打电话确认对方是谁。
3. 有人申请账号：点“通过并选级别”，选级别，点“通过”。不同意就点“拒绝申请”。
4. 有人忘记密码：点“重置密码”，系统给出一个临时密码，把它告诉本人。临时密码 24 小时内有效，对方登录后要马上改掉。

### 新建、改级别、停用

- **新建：** 点“新建账号”，填“用户名”“初始密码”，选“级别”，点窗口下面的“新建账号”。
- **改级别：** 点一个账号，在详情的“级别”里改。
- **重置密码：** 点一个账号，点“重置密码”。
- **停用：** 点一个账号，在“更多”里点“停用”。账号不能删，停用的可以再点“启用”。

从公司域名打开系统时，这些操作要先进超级管理员模式（见“管理员：超级管理员模式”），只看列表不用。

管理员自己忘了密码，要维护人员在服务器上重置，见[部署与运维](部署与运维.md)。

## 管理员：设置

点左下角“设置”（手机上在左上角三条横线的菜单里）。管理员看到五个页签：API 配置、提示词、单据模板、消息接入、高级。

- 业务人员、财务账号只看得到“单据模板”，怎么改见“单据导出和模板”。
- 只读和出纳账号没有“设置”。
- 从公司域名打开系统时，改 API 配置、提示词、消息接入、高级之前，要先进超级管理员模式。没进模式时这几页只能看，保存的按钮不出现；查余额、重新测试照常能点。

各页：

- **API 配置：** 系统用的 AI 是 DeepSeek（识别文件、助手、语音都靠它），这里填它的密钥（一串字母数字，在 DeepSeek 网站上买了以后拿到），点测试，再启用。密钥加密存在服务器上，存好以后不再显示。没填也能用全部业务功能，只是没有识别和助手。余额不够时，这几样都会失败。
- **提示词：** 给 AI 的说明书，告诉它怎么读文件、怎么回答，全公司共用。识别规则只写各家客户原件的写法习惯，比如某家客户的规格怎么写；要识别哪些栏目是固定的。助手的提示词默认只有“小甬和小勒”“工厂和业务口径”两条。改小甬、小勒的性格和分工，在“小甬小勒提示词”里改。
- **消息接入：** 让员工在企业微信、飞书、钉钉里把消息发给公司机器人，自动进收件箱。三家各一张卡片，照各家后台填两项（Bot ID 和 Secret、App ID 和 App Secret、Client ID 和 Client Secret），点“保存并连接”。显示“已连接”才收得到消息，三家可以同时开。系统关着时收不到。各家后台怎么设，见[部署与运维](部署与运维.md)“消息机器人”。
- **高级：** “插件与工具”里列着助手能做的各种事，能整组或单个停用。

**机器人没回复：** 看“消息接入”里那一家是不是“已连接”。写着“正在重试”的等一会儿。写着“连接被拒绝”的，照卡片上的红字改凭据或重填 Secret，再点“保存并重新连接”。文件要单独发给机器人；飞书、钉钉要在后台发布版本、把发消息的人加进可用范围。

## 管理员：超级管理员模式

超级管理员模式是给管理员临时开的“保险锁”：容易出大事的操作，要先输一次自己的密码才能做。

- 平常从公司网址打开系统：账号菜单里有“系统维护”，要开这个模式。
- 在服务器那台电脑上直接登录：账号菜单里是“数据管理”，一直算在模式里，不用开（见“管理员：在服务器本机登录”）。

**开模式：**

1. 点页面顶上的“进入超级管理员模式”，或者点右上角你的名字，点“系统维护”。
2. 在“本人密码”里填你自己的密码，点“进入超级管理员模式”。

开一次管 15 分钟，这期间连着做不用再输密码。做完可以点“退出超级管理员模式”。

**开了模式才能做的事：**

- 管理账号；改 API 配置、提示词、消息接入、助手工具开关。
- 删除已经核对过的单子和客户、产品、订单、供应商、采购单、库存品（见“管理员：删除”）。
- 撤销生产任务、撤销完工、撤销采购退货。
- 更正完工单。
- 送货比订单多送（超订单数量发货）。

别的账号去做这些事，会直接提示“要用超级管理员账号”。

### 这些业务操作怎么做

- **撤销采购退货：** 在“到货”页打开那张到货单，在退货记录里点“撤销退货”，退回的数量加回库存。从采购单里点开的到货单窗口只能看，不能撤销。
- **更正完工单：** 打开完工单，在“更多”里点“更正完工单”，改合格、报废和领料（可以加减行、换纸板），写原因，点“提交更正”。发出去一部分的完工撤销不了，但能更正。
- **撤销完工：** 打开完工单，在“更多”里点“撤销这次完工”，写原因。
- **撤销生产任务：** 打开任务，在“更多”里点“撤销这张任务”，写原因。
- **比订单多送：** 安排送货时某一行超过订单还没发的数量，窗口里要填“超订单原因”，也不能超过库存。已经有的送货单，在编辑窗口里勾“超订单数量发货（特殊情况）”并写原因；没勾的，出库时会被拦下。更正送货单时数量改多、超过订单剩下的，也要写原因。

## 管理员：删除

日常用归档，能恢复。删除不能恢复，只有管理员能删已经核对过的单子和资料。

### 删一条或几条

1. 先进超级管理员模式。
2. 打开要删的那条，在“更多”里点“删除”。要删好几条，在列表里勾选，屏幕下方出现操作栏，在它的“更多”里点“批量删除”。
3. 窗口顶上一句话说清会删什么，下面分“会删除”和“保留，只解除关联”逐条列出。看清楚。
4. 单子动过库存时，选“库存怎么处理”：
   - “库存一起改回”：当这张单子没发生过，这是默认的。
   - “库存数量不动，只删单子”：留下的流水改成“系统维护”流水，适合已经盘点过、库存数是对的时候。
5. 输一次你自己的密码，点红色的“确认删除”。

在服务器本机登录的管理员直接就有“删除”，不用输密码。

- 删供应商会一起删它的采购单和到货单。删产品会一起删它的生产任务、完工记录、成品库存和用到它的送货单。
- 已经到货的采购单也能删，到货单和库存不动，只是不再挂这张采购单。
- 改回会让库存变成负数的，删不了。删还有库存的库存品，窗口开头会写明删掉后这些库存就没了。
- 删除窗口开着时别人改了数据，窗口会按最新的重新列一遍，请再核对。
- 每次删除前，系统会自动把当时的数据另存一份（快照），存不下来就不删。

### 让助手删

跟助手说要删哪几条，它出一张卡片，列出会删的、会保留的。也有“库存怎么处理”，改了选项清单马上重算。先进超级管理员模式，在卡片上输本人密码，点红色的“确认删除”。卡片出来后其中一条变了，整张卡片作废重来。

### AI 导入里的文件

- AI 导入里的文件点“更多”里的“归档”，能恢复。
- 永久删除：AI 导入页右上角“更多”里点“历史与归档”，在那里删。读不出来的识别文件也在这里看，用本机管理员账号永久删除。
- 已归档的识别文件不能导入，先在“历史与归档”里恢复。

## 管理员：在服务器本机登录

在服务器那台电脑上直接登录的管理员，账号菜单里是“数据管理”，不是“系统维护”。

- 能直接查看和修改全部业务数据。关联的那几格是能搜索的选择框。改过的记录，在“关联记录与修改历史”里标着“数据管理”。
- 最下面是“初始化业务数据”：把选定范围的业务数据全部清空，从头开始。做之前务必确认。
- 能直接改订单和已经开工的生产任务。开工后的任务在“更多”里点“编辑”能整张改；计划数不能改到比已经登记的完工数还少。
- 已经生效的到货单、送货单、完工单，在这里也只能“编辑”说明，或在“更多”里更正，和业务页面是同一个窗口；改数量、日期会被拒。已经撤销、取消、被更正的不能再改。
- 更正时还能改：送货的出库日期、挂哪条订单明细、加一行；完工的完工日期、产品、生产任务。到货单的计价方式和单价也在“更正到货单”里补。
- 库存品“更多”里的“出入库 / 盘点”和库存页是同一个窗口。
- 完工单不能在这里新建，用“登记完工”。
- 新建订单有“金额结算”一格。单价有不到一分的尾数时，要选“明确采用整单四舍五入到分”。以前没填过的订单显示“未填写”，不动它就不写。
- 保存的内容里有系统不收的栏目，会报错、写明是哪一格，什么都不存。系统算出来的栏目（已发数量、金额这类）改了也会被拦下。
- 在服务器本机登录时，还能跟助手说“看看系统状态”“检查一下数据库”“现在备份一次”。超级管理员还能让助手看登录记录和运行日志。

**打不开网页：** 本机上双击“启动系统”，窗口一直开着别关。服务器上的，联系维护人员。

## 备份

系统每天自动备份一次，留最近 14 份。但备份和系统在同一台机器上，**请定期把备份复制到别的硬盘。** 自动备份失败时，“今日”页会提示。

手动备份、恢复由维护人员做，见[部署与运维](部署与运维.md)。在服务器本机用管理员登录时，也可以让助手“现在备份一次”，它会出确认卡片，写明多出一份什么备份、放在哪、不会自动清理。
