# 使用手册

写给每天用系统的人：每个功能在哪、点什么、会发生什么、要注意什么。程序里的“使用说明”页显示的就是这份，助手回答“怎么操作”时读的也是它。

## 开始之前

- **打开：** 浏览器打开系统地址。装在自己电脑上是 `http://127.0.0.1:3001`；部署到服务器后用公司的域名，手机也能打开，不用装 App。
- **第一次用：** 管理员先到“设置 → API 配置”填 DeepSeek 密钥（不填也能用全部业务功能，只是没有识别和助手），再录常用的客户和产品（也可以建订单时顺手新建）。
- **侧栏顺序就是干活的顺序：** 今日、收件箱、AI 导入；销售（订单、客户、产品）；采购（采购单、供应商）；生产（生产任务、完工记录）；仓储（库存、到货、送货、流水）；财务；最下面是设置、归档、使用说明。
- **详情：** 点列表的一行，右边打开详情。右上角的实心按钮就是当前的下一步，不常用的操作在“更多”里。“更多 → 关联记录与修改历史”看这条记录连着哪些单据、谁什么时候改了什么、从哪改的（页面、助手、数据管理），能看记录的账号（包括只读账号）都能打开。
- **列表怎么找：** 上面一行是搜索、“待处理 / 全部 / 已归档”和“筛选”。有条件生效时“筛选”上显示个数，“清除筛选”一次清掉。日期都是“最近一个月 / 两个月 / 三个月 / 自定义”。到货、送货默认只列还要处理的和最近 90 天的，列表下面点“显示更早的记录”看全部。
- **几个人同时用：** 别人改的东西不用刷新页面：左侧导航上的数字最多十几秒就更新，从别的窗口切回来时眼前的列表马上重新取。
- **先看影响再确认的窗口**（核对入库、出库、更正、删除、登记完工、正式导入、初始化等）：看过以后数据被别人改了，确认时会提示“预览以后数据已变化，请重新预览。”（核对窗、更正窗、删除窗重查成功后会自动换成最新的），重新看一遍再点。
- **没填的会标红：** 保存时窗口滚到第一个没填对的地方，按钮上方写着还差哪几项。提示“连不上服务器，请检查网络后再试。”时等网络好了再点。
- **数量单位：** 产品和成品只有“只”（客户写“个”也是“只”），原材料只有“张”。别的单位要先自己换算，系统不换算。
- **单价：** 最多四位小数，显示至少两位、最多四位（2.7600 显示 2.76，2.5 显示 2.50），送货单上也一样；按面积计价写“元/m²”。金额两位小数。
- **时间：** 系统里显示的时间一律是北京时间，不跟着电脑所在的时区变。

**手机上：** 底部是今日、订单、助手、生产、仓库（出纳是概览、应收应付、助手、资金、凭证），其他页面点左上角菜单。列表变成卡片，点卡片看详情。排产板靠拖动改日期，建议在电脑上做。

**安卓 App 里：** 返回键先关最上面一层（窗口、详情、筛选、“更多”菜单，正在保存时不关），没有窗口时回首页（“今日”，出纳这类纯财务账号是财务概览），在首页再按两次退出；点开图片原件后按返回回到 ERP。在文件管理、相册或微信里用“分享”“用其他应用打开”选甬勒ERP，文件会自动传进 AI 导入、显示待识别，自己选好类型再点识别；开着窗口时先提示，关掉窗口后再进入 AI 导入；超过 10MB、格式不支持、读不到的文件不上传，会分开提示原因；纯财务账号用不了 AI 导入，会提示“当前账号不能使用 AI 导入”。在 App 里导出的订货单、送货单存进手机“下载”，存好了才改状态；没存成时窗口里说原因，状态不变。

## 今日

每天先看这里：待办按要做的事分组（可发货、待排产、到货待登记、货款到期等），每一行的按钮直接办这一步，和订单详情的“下一步”一致。

- 几张订单要同一种货、库存不够全发时，交期早的先分到库存（在“可发货”），晚的进“待排产”。
- 订单明细的规格和产品现在的对不上时，这一行送不了货、不分库存，订单列在“要核对订单”里（已经排在别的组里的，比如在生产、待完工，就留在原组）；点“打开订单”核对明细。

**经营概况：** 今日页上方切到“经营概况”，看一段时间的接单、送货、采购、库存和流水。“统计日期”默认最近两个月，“清除筛选”回到最近两个月。

- **送货金额：** 所选日期内有效送货单的金额，按送货日期、按单据上的单价算，不另加税，和财务月度台账的理论收入是同一个数（部分发货的按送了的算，撤销、被更正替代的不算）。
- **到货金额：** 所选日期内有效到货单的金额，按到货日期、实际入库数量、按单据上的单价算，不另加税，和理论支出是同一个数。
- 算不出金额（缺单价、数量或尺寸）的单子不计入，另写“N 张算不出金额”。
- 预估毛利只算录了预估成本的订单（见“接单”），不是净利润或会计收入。

## 收件箱

所有进来的文字、图片、文件都在这里，一条条处理。

- **从哪来：** 点“上传文件”“粘贴文字”；或在企业微信、飞书、钉钉里**单聊**机器人发给它（群里只收 @ 它的消息；钉钉群里只有文字和图片），机器人会回“已收到”或失败原因。客户发给员工的文件，要员工转发给机器人。超过 20MB 的文件不保存。
- **留多久：** 待处理、已忽略的消息收到 180 天后自动清掉，已处理的（包括转成单据的）留着。请告诉往机器人发消息的同事。
- **文件：** 点“转订单”或“转到货”，进入 AI 导入。只有 PDF、Word、Excel、JPG、PNG 能转。转过去不会自动发给 AI，要点“开始识别”（在助手里从收件箱转进 AI 导入的订单文件，也可以接着对助手说“识别一下”）。
- **文字：** 点“新建订单”，原文显示在表单上方对照，保存后自动标为已处理。
- **不需要的：** “更多”里“标为已处理”或“忽略”，都能恢复。

## 接单（客户订单）

**用文件建：** 在 AI 导入选客户订单文件，点“开始识别”，对照左边原件核对（黄色提示重点看），确认客户和产品后正式导入。名字只差公司后缀的客户、名称和尺寸都对上的产品自动选上；这位客户以前订过、名称和规格都一样的老产品也直接选上，并注明“本客户以前订过同名同规格”。相近的、只是包含关系的（“纸箱1”和“纸箱10”）列出候选让你选，没有就导入时新建，会新建哪些在导入前列出来让你确认（助手的导入卡片上还列出相近的已有档案）。系统不猜。助手改过的格子下边线是紫色，鼠标停上去写着“助手改的”，“已改 N 处”里也标着。“产品资料可以后补”只在关联的档案或新建的资料确实缺的时候提示；改过数量或单价时只提醒一次“数量或单价改过，正式金额和合计按新值重算”，同样的提醒合成一条。

- 客户订单文件在列表上写着到哪一步：待识别、等待识别、排队等待、AI 识别中、识别失败、已取消、待核对、已导入；助手说的状态和这里一样。
- 识别结果改错了点“撤回修改”，退回上一次修改；它只退识别结果，不撤销已导入的订单。
- 原件没写订单日期也能识别出来，标出“订单日期缺失”，补上才能导入。
- 已归档的识别文件不能导入，先在“更多 → 历史与归档”里恢复。
- 原件没写整单交期、每行都有交期时，整单交期先按最晚的一行填上，提示你核对。
- 读不出来的识别文件会单独标出数量，可在“更多 → 历史与归档”查看并用本机管理员账号永久删除。

**手工建：** “订单”右上角“新建”。从客户详情点“新建订单”客户已填好；从产品详情或产品列表勾选几种点“新建订单（N 种）”，产品已加好，客户要自己选（产品不属于某个客户）。有一行金额算不出来（单价没填）时合计显示“—”。

**单价：** 产品的参考单价留空是没定价，填 0 是 0 元：没定价的加进订单时单价空着要自己填。单价不能超过 1000000 元。

**预估成本：** 订单编辑窗“更多信息”里勾“录入预估成本”，按整张订单填各项成本（元，最多两位小数，每项不超过 1000000 元，“01”这种前面补零的写法不收）和估算依据。不录入的订单不算进经营概况的预估毛利。

**看进度：** 打开订单，顶部“下一步”写着接下来做什么，每一步右边就是按钮；下面列每个产品的待发、可用库存和生产情况。生产任务都做完了订单还是“生产中”时，黄色提示写明还差多少。

**状态：** 待确认、已确认、已取消由人改（待确认的不排生产、不送货）；生产中、待发货、部分发货、已发货由生产和送货自动更新。每个没发完的产品都做够订单数量才算待发货；同一张生产任务给几张订单做的，做够这几张的合计才算。发了一部分是“部分发货”，做好的那部分可以先发。

**几张订单一起办：** 订单列表勾选几张：
- **安排生产：** 同一种产品合成一张生产任务，数量 = 这几张没发的合计 − 成品可用库存，可以改。已有任务在做的、还待确认的不排，窗口里写原因。
- **安排送货：** 按交期先后用现有库存排满，一个客户一张待送货的送货单。
- **安排订料**（“更多”里）：和订单“下一步”里的“安排订料”是同一个窗口，几张订单时窗口上方多一个选择：“合成一张采购单”（按订单分行，订货单上同种纸板合成一行），或“每张订单一张”。同一张采购单只能是一家供应商。

**产品的附属品：** 大箱里套小箱这种，编辑小箱在“附属于”里选大箱。列表和订单里小箱挂在大箱下面，只是显示上归在一起，订单、价格、库存、生产都各算各的。点“不附属”取消。

**唛头和样稿：** 唛头是产品的参考资料，不识别，不产生订单、生产或库存。在产品详情的唛头一节上传（可以写一句说明），产品、订单和生产任务详情里都能点开预览。也可以把文件发给助手让它挂到产品下。

## 采购订货

1. **建采购单：** 订单确认后缺纸板时，“下一步”第一条是“安排订料”，点它打开新建采购单，已关联这张订单，每个要生产的产品预填一行纸板（材质、楞型取自产品）。尺寸、张数系统不推算，按开料自己填；单价按供应商报价填。每行都要有计价方式（按平方米或按张），新建行预填按平方米，照报价改；让助手建采购单没说按什么计价，它会先问。没选“库存里已有的纸板”的行，长和宽必填（按开料尺寸填，表单上标着“*”），高、尺寸单位、材质、楞型可以不填；选了库存里的纸板，尺寸跟着它走。以前订过料的产品带上次的长宽，标“参考上次”。也可以从供应商详情、原材料详情、原材料库存勾选几种后新建。一张采购单可以给几张订单订料，每种纸板写着“给订单 …”。
2. **发订货单：** 采购单列表勾选同一家供应商的几张（一张也行），点“导出订货单”。名称、规格、尺寸、材质、楞型、单价都一样的纸板合成一行写总数，系统里的采购单不合并。每行可以写到货安排（多少在哪天前到，可拆几段）。文件存好后这几张采购单变“待到货”。不导出的，在采购单“更多”里点“不导出，直接改成待到货”。
3. **订货单号** 按天编号（DG-日期-01、02……），删掉或初始化后也不回头重用。两个人几乎同时导出时，后一个会提示号被占用、请重新导出；同一组采购单先后导出了两份时，先完成的算数，另一份提示作废，不要发给供应商。预览不占号。

## 到货

1. **待到货：** 导出订货单后，到货页最上面的“待到货”里就有它，写着还差什么、最近的截止日期，过期没到的标红。到货安排以后可以在采购单详情里点“编辑到货安排”。
2. **登记到货：** 供应商送货来了，在待到货里（或采购单的“下一步”）点“登记到货”，按送货单填每行本次实到和其中不合格，点“登记到货”就直接入库。合格的没全部入库时，点这一行的“合格的没全部入库？”填实际入库。数量按下单先后分到各张采购单。分几次送就登记几次，没到齐的继续待到货。逾期没到的在今日页标红。
   - **AI 识别送货单：** 到货页点“AI 识别送货单”，核对时选这批货是哪份订货单（能对上的自动选好），多送、样品选“不挂采购单”；存下来是待入库，核对后入库。
   - **没有采购单的货**（多送、样品）：到货页“更多”里点“登记没有采购单的到货”。有采购单的货只能在“待到货”里登记。
3. **入哪个库存：** 不用选。采购明细关联了库存品的入那个；没关联的，和已有原材料规格一样的入已有的（已归档的自动恢复），没有才新建。
4. **验收：** 实收 = 合格 + 不合格，库存只按合格数增加。到货明细的单位只有“张”。
5. **弄错了：** 已入库的到货单照“改已生效的单据”那一节办：
   - **编辑：** 只改备注和到货时间。
   - **更正到货单**（详情“更多”里）：改数量、单价、库存品这些只有这一条路（本机管理员也一样），采购单详情的到货记录、AI 导入里已入库的到货单点“更正”进的也是这个窗口。某一行其实没到可以更正成 0；整张都没到时，撤销该到货单。替代单被删后，原单改标“已撤销”。货是退回给供应商的，用“采购退货”，不用更正。
   - **撤销到货：** 写一句原因，库存扣回，采购单的已到货改回，单据留着标“已撤销”。料已经领用掉、库存不够扣的撤销不了。
   - 有没撤销的采购退货时，要先撤销退货才能更正或撤销到货。
6. **退货给供应商：** 打开已确认的到货单点“采购退货”，按明细填退回数量和原因。扣库存，也从采购单的已到货里扣，供应商补货时还能再到货。纸板只能退整张。退错了在到货单的退货记录里“撤销退货”（要超级管理员模式），退回的数量加回库存。只读账号只能看。金额怎么算见“财务”里的“采购退货的钱”。

## 生产

1. **安排生产：** 只有一个“安排生产”窗口。在订单“下一步”点“安排生产”，或在“生产任务”页头点“安排生产”（按产品排，在窗口里“加一种要生产的产品”）。保存就是正式任务，排产板上显示待生产。计划日期默认今天；让助手安排生产、没说计划日期时也按今天填，卡片上看得到，要换日子直接跟它说。没有订单先备货：产品列表勾选几种点“安排生产（N 种）”，每种一张任务，不关联订单。还没登记完工的任务能编辑；已经登记过完工的不能改，少做就取消剩余任务，多做再安排一张。
2. **登记完工：** 只有一个“登记完工”窗口。在任务上点“登记完工”，填良品和废品，成品自动入这个产品的成品库存（一个产品只有一个，没有就新建，已归档的自动恢复）。几张任务共用一批纸板的，在同一个窗口勾选，先点“看领料怎么分”核对领料，再确认。
3. **打样、补做（不挂任务的完工）：** 在登记完工窗口的“不挂任务的完工”里选产品、填合格和报废，可以加几行，也可以和任务一起登记、共用一批纸板。
4. **批次备注：** 登记时可以写一句“批次备注”（这批用的什么料、质量怎样），显示在成品库存详情的“批次”里。
5. **先登记，稍后核对入库：** 还没清点时，在完工窗口“更多”里点“先登记，稍后核对入库”：存成待入库的完工单，库存不动；之后在“完工记录”里逐张“核对入库”。已经先登记的数量，再登记时从“还差”里扣掉，合格数不能超过还差的数。完工日期不能晚于今天。
6. **取消还没核对的完工：** 在完工记录详情点取消完工的操作：成品不入库、纸板不扣，记录保留标“已取消”，任务还差的数量加回来。
7. **已入库的完工登记错了：** 照“改已生效的单据”那一节办：只改机台操作、批次备注用“编辑”，合格、报废、领料错了用“更多 → 更正完工单”（要超级管理员模式），整张没发生就撤销该完工单。开工后的生产任务只有本机管理员能在“更多 → 编辑”里整张改；计划数不能改小到已登记的完工数以下（已入库加待核对入库，取消、撤销的不算），不动或改大照常能存。

## 送货

1. **安排送货：** 只有一个“安排送货”窗口。在订单右上角点“安排送货”，或在“送货”页的“可发货”里勾选；也可以从成品库存详情（只有一个客户在等时直接带出来，几个客户在等时先选给谁）或成品库存勾选几种（按客户自动分单）；在“送货”页页头点“安排送货”时先选“送给哪个客户”，带出这个客户在等的订单。每张送货单有“计划送货日期”，预填今天；收货联系人、联系方式、地址按客户档案预填，能改；删空了的，导出的送货单上印“未记录”，不拿客户档案的。“可发货”里勾了几张订单时，同一份库存按交期先后分，和按订单安排送货一样，不按勾选的先后。
2. **安排好是“待送货”：** 不扣库存，但这批货算已安排，可用量里扣掉；已经排在待送货单上的数量不会再排一遍。
3. **导出送货单就是出库：** 待送货单的主按钮是“导出送货单”，点“导出并出库”，文件存好后扣成品库存、算进订单已发，变“送货中”。不导出文件的，在“更多”里点“不导出直接出库”。出库算在出库那天（月底安排、月初装车的算月初那个月），送货单上印的是实际送货日期；模板里的“材质 / 配纸”“楞型”两列印产品的材质、楞型（已出库的和更正送货单时原样留下的行按出库时的印，待送货的按产品现在的印，没填的印空）。
4. **确认送达：** 客户收到后点“确认送达”，送达日期改成签收那天（不能早于出库日、不能晚于今天），只记一下，不再动库存。
5. **选不了的原因：** 窗口里会写出来。最常见的是订单明细写的规格和产品现在的不一样，提示里并排写出两边哪一项不一样，改对订单明细再排。比规格时空格、斜杠、逗号这类分隔符不算差别；横线、下划线可能是编号的一部分，算差别（“A-11”和“A1-1”不是同一规格）。
6. **超过订单数量：** 安排送货时某行超过订单还没发的数量，窗口里要填“超订单原因”，要超级管理员模式，也不能超过库存。已有的送货单在编辑窗的“超订单数量发货（特殊情况）”里勾选并写原因；没勾的，出库时超出订单剩余数量会拦下。
7. 送货一定要关联真实订单。
8. **发错了：** 已出库的送货单（送货中、已送达都算）照“改已生效的单据”那一节办：只改地址、联系人、备注用“编辑”，数量登记错了用“更多 → 更正送货单”，整张没发生就撤销该送货单。

## 改已生效的单据

已入库的到货单、已出库的送货单、已入库的完工单只有三条路，都在详情上：

- **编辑：** 只改不影响库存和金额的说明：到货单的到货时间、备注；送货单的收货地址、联系人、联系方式、实际送货时间、备注；完工单的机台操作、批次备注（成品批次块上的“写备注 / 编辑备注”打开的是同一个窗口）。库存和金额不变，不出新单。
- **更正**（“更多”里的“更正到货单 / 更正送货单 / 更正完工单”）：数量登记错了、某一行其实没有时用。原单保留、标“已更正”，另出一张新单号的替代单；详情顶上写“更正自 原单号”“已更正为 新单号”和原因。库存按差额追加流水，订单已发、采购已到货、任务已入库跟着改。不用重新给客户纸面单据。
  - **送货单：** 有编辑权限就能更正，客户已签收的也能；改每行数量、删行（至少留一行），数量变多超过订单剩余要超级管理员模式并写原因。出库日、送达记录照旧；没改的行沿用出库时的单价和税率（订单后来改了价也不变，窗口里会提一句）。
  - **完工单：** 要超级管理员模式；改合格、报废和整张领料（能加减行、换纸板）。发出一部分以后撤销不了，但能更正。
  - **本机管理员另能改：** 送货的出库日期、挂哪条订单明细、加一行；完工的完工日期、产品、生产任务。
  - 改好、写了原因，窗口自动算出“更正后的影响”（库存、订单已发或任务已入库、金额），点“提交更正”。打开窗口后单据或库存被别人改了，窗口里提示已按最新的重新预览，核对后再提交。
  - 已归档的先恢复才能更正；已经被更正过的，打开最新那张再改。
- **撤销：** 整张没发生时，从该单据详情的“更多”打开撤销操作，写原因；库存、订单已发、采购已到货、任务已入库都改回来，单据留着标“已撤销”。库存已经被后面的业务用掉、不够扣的撤销不了。
- 编辑、更正办完只关这个小窗口，详情留着。也可以跟助手说（例：“送货单 SH-… 实际只发了 550 只”“把这张送货单的地址改成……”），它出一张确认卡片，写明哪张单、每行原来和更正后多少、库存和订单已发（完工是任务已入库）怎么变，点确认才改；让助手更正完工单只有超级管理员账号能做，要先进超级管理员模式。

## 单据导出和模板

订货单、送货单都是固定版式，像印好的联单：每张纸铺满、明细行数固定，货少只填前几行。

- **改样式：** “设置 → 单据模板”选纸张（送货单默认针式 241×93 三等分，可选 241×140 二等分、A5 横向、A4；订货单默认 A4 竖版），改公司资料、联次、签字栏、条款和明细列。点“刷新预览”看每张能放几行；“恢复默认”把明细列和顺序恢复成默认。点“保存模板设置”才生效。
- **超过一张** 自动续页，合计金额只写在最后一张。一格放不下先缩小字（最小 7 磅），再加高；一整张纸都放不下时不生成文件，提示是哪行哪个字段太长。
- **Word 还是 Excel：** 针式打印用 Word（纸张尺寸准）；Excel 方便再改。
- **导出的文件留 180 天：** 期间能在助手聊天的文件卡片里再下载；过期了重新导出一份，单号和出库、订货结果都还在。

## 库存

- **能看：** 在库、已安排、可用、在途。可用量只是提示，真正的扣减在确认时校验。不能负库存。
- **流水：** 每一次库存变动的记录，库存数全靠流水算，流水不能删。单据生成的流水，点“去更正原单据”在原单据上改；手工出入库记错了，再做一笔反向的或盘点。被改过的流水，详情下面有修订记录。
- **手工出入库和盘点：** 库存品详情里点“出入库 / 盘点”，系统追加一笔流水，不直接改数字。本机管理员在数据管理里点库存品“更多 → 出入库 / 盘点”，打开的是同一个窗口。
- **同一种货只有一个库存品：** 成品先选产品，一个产品一个成品库存（已归档的也算），名称、规格跟着产品，自己只能改备注。原材料名称、规格说明、尺寸、材质、楞型都一样的就是同一种（不分大小写、全角半角，120cm 和 1200mm 算一样），不能建第二个，保存时会给“打开它”。质量不同的纸板用名称或规格说明区分。
- **用过以后不能改种类：** 有出入库或被单据用过的库存品，不能在原材料和成品之间改，用过的成品也不能换产品；要改就新建一个。
- **成品批次：** 成品库存详情的“批次”一节，每次完工入库一批，写着完工日期、入库多少、估计还剩多少、生产任务、订单、用料、批次备注。“估计还剩”是按流水推算的（同一订单的先扣，其余先做的先发），送货不用选批次。点“写备注”“编辑备注”能事后补批次备注（就是完工单的“编辑”），库存不变，也可以让助手改。原材料没有批次。
- **概览：** 原材料总面积只算尺寸和单位齐全的，算不进去的会写出几种。

## 财务

侧栏“财务”只有财务、出纳和管理员看得到，进去用顶部页签切换。**送货、到货、收付款都不用等财务：** 没有税率照常做，只有出正式报表和结账时才要求补齐。科目、报表行项目和税率还没请懂账的人复核，先当内部参考。

### 每月看什么

“财务概览”选月份，第一张表是两种盈亏，互不影响：

| | 收入 | 支出 |
|---|---|---|
| **理论** | 本月送货单金额 | 本月到货单金额 |
| **实际** | 本月收到的钱 | 本月付出的钱 |

补税率、拿优惠、收利息都不改理论盈亏；房租、工资、水电录了付款就算进实际支出。概览的“本月接单”、月度台账的“接单”不算待确认、已取消的订单，和今日页一样。点金额看每一笔；“本月实收来自哪个月的单子”看这个月收的是几月份的货款。

### 补税率

“月度台账 → 待补税率”：点开一张逐行填、勾选几张一起填，或“按单位整月补”。不开票的选“无税 / 不开票”。只改财务记录，不动送货单、到货单。金额本来就是 0 的（赠品、整批拒收）不用补。

### 账期、压货款和优惠

“应收应付 → 账期”按单位设：压几个月、每月几号付或压多少天；现结优惠（比例自己填，系统不内置）；分期、压款利息、保证金用到才设。利息只给建议、只算已经过去的逾期天数，确认后才入账；确认时选“算到哪天”，一个月可以确认几次，下次接着上次算到的那天算。

- 改账期只影响新单子；已有单子在“欠款明细”页头“更多”里点“按新账期重算到期日”。
- “没有账期”是到期日留空、不算逾期；“压 0 天”是当天到期。
- “欠款明细”的“按单位”看每家欠多少、预收款和还欠；“收付计划”看未来几个月；“到期提醒”看快到期和逾期的，今日页也会提醒。

### 收款和付款

- “资金发票 → 收付款 → 新建”，先存成待确认，确认时选核销哪些单子（只列收付款日及以前的）。核销金额含优惠：339 元的单子优惠 6.78 元，实收 332.22，核销填 339、优惠填 6.78。手填的优惠和约定的不一样时要写原因。
- 录错了点“撤销”，有核销的先撤销核销。
- 没有往来单位的（房租、水电）类型选“其他支出”。
- **承兑汇票：** “资金发票 → 承兑票据”登记，按到期先后冲这家的应收应付，冲不完的记预收预付；背书、退票在“变更状态”里。

### 记账和结账（给做账的人）

1. **启用：** “财务设置”选启用月份和纳税人身份（只看盈亏可以不启用）。应收应付预收预付的期初按单位逐行填。启用前已有库存的，原材料、库存商品的期初金额要和第一次算成本时填的一样（系统不校验）。启用后期初不能再改；再到“资金发票 → 资金账户”建账户。
2. **一个人做账：** 系统默认制单和审核要不同的人，只有一个人时在“财务设置 → 修改”关掉。
3. **制单：** “凭证账簿 → 业务单据”把送货、到货生成待记账凭证，再到“凭证”页提交、审核、记账。单据日期所在月份已经结账的（补录的、结账后才补税率的），凭证记在最早没结账月份的 1 号，摘要注明单据日期；到期日、分期和压款利息的起算日仍按单据日期；按送货确认收入时，这张单子的毛利也算在凭证所在的那个月。
4. **成本：** 第一次算成本要填启用前库存值多少钱，手工入库也要填金额，填 0 表示没有成本。冲销退回的库存按原成本自动冲回。补登到已算过成本月份的流水，计入下一个没算成本的月份。已入过账的到货被撤销或更正，在撤销那个月按原来的暂估把这批冲出库存，不用填；冲完数量是 0 的，到过票、还等红票冲的金额先留着，其余转进主营业务成本。没入过账就作废的到货不算成本；启用前的到货撤销后，仍要在“计算成本”窗口选对方科目。
5. **税率：** 结账前在“财务设置”填附加税率和所得税率，不用缴的填 0，系统不设默认值。
6. **结账：** “报表结账 → 结账”按清单走完；打开结账页会先把业务单据的变化同步进来（没同步成功页面上会写原因），撤销、更正、改过、删掉的单据还没处理完的，“业务单据”一步拦着，点它的“去处理”看全部要处理的单据；没有工资、固定资产的月份也要点一下“工资计提”“计提折旧”。12 月“结转损益”点两次（第二次是“结转年度利润”）。反结账后改了数，结账检查会写哪一步要“重做”：原凭证红字冲销、按现在的数重新生成。“报表结账 → 正式报表”和结账同一个口径：打开时先同步业务单据，还有没同步进财务的单据或没补完的资料时出不了正式报表，页面上写着还差几张。
7. **“有差异”的业务单据：** 盘点调整的差异，在“业务单据”点“核对无误”或等月末算成本一起处理，不卡结账。启用财务以前的单据后来又被改了的，结账检查的“启用前单据的变动”一步逐张列出（单号、日期、原因），核对后点“核对无误”，这一步只提醒、不拦结账。送货、到货已经入过账后又被撤销或更正的，详情的“改了什么”逐项写改前改后，点“红字冲销并重做”（单据已撤销的只叫“红字冲销”）；到货撤销或更正后做红字冲销，日期默认是撤销（更正）那天（那个月已结账的默认最早没结账月份的 1 号），更正带出来的原单和替代单一样；撤销或被更正替代的到货不能再关联发票（开票对比里也不列），到过票的先开红票再冲销，所以撤销那个月要等红票到了才能结账；冲销前已经收付过钱的，先在收付款单里撤销核销。只改备注、地址、确认送达这类不影响金额的，不出“有差异”。还没入过账的直接变“已更正”，不用处理。
   - **单据已删：** 送货、到货单被删除时，没入过账的（包括只挂了暂估往来的）自动变“已更正”；盘点流水、完工单被删直接“已更正”（库存数量和成本由月末成本计算按流水算）。入过账的标“单据已删”、拦结账，二选一：点“红字冲销”（只冲不重做）；或者原凭证记的收入、成本是真的（比如删单时保留了库存流水），在“更多 → 核对无误，保留凭证”，往来照常收付、毛利照算。没有还算数的凭证时没有“保留凭证”这一项；挂着收付款核销或发票的，先撤销核销或红冲发票再冲销。

**冲销以后怎么看：** 欠款明细的逐笔、对账单里，原来那笔标“已冲销”，下面挨着一笔负数“红字冲销”，两笔合起来两清，不再出现在到期提醒和核销选择里；按新内容重记的标“重记”。红字凭证还没记账时，账龄里那张单据还在，记账后才扣。“按单位”的还欠已扣掉没抵货款的预收款，和同一天对账单的期末一致；账龄只算已记账的、不含预收，两边可能暂时对不上。

### 凭证、发票和其他

- **凭证：** 已记账的不能改、不能删，错了只能红字冲销（凭证详情“更多”里；没记账的在同一处“作废”）。手工凭证里应收应付类科目要选单位。
- **费用、保证金、票据、资产处置、坏账、压款利息生成的凭证：** 不在凭证页作废或冲销，到各自详情的“更多”里办：还没记账的“撤回”，已记账的“红字冲销”。保证金的退回、转抵在保证金详情的“退回和转抵”里逐笔办。
- **红字发票：** 录入时选原蓝票。全额红冲自动冲原票凭证；部分红冲且原票已有凭证时要填对方科目。开错重开：先开整张红票冲完，再开正确的蓝票关联同一笔往来；只冲一部分的折让红票不能用来重开。
- **采购红字发票（退货、折让）：** 按比例冲减应付和库存成本。已经付过款的这笔显示“多付”：在欠款明细里点它，用“多付转抵”抵这家供应商的下一笔应付，或者让供应商退款；转错了在付款单的“核销记录”里点“撤销转抵”。
- **部分到票：** 一批货分几张票时，关联发票要填“对应暂估”。
- **采购退货的钱：** 还没到票的，退货时按这批到货的暂估单价冲减暂估，到票时只转回剩下的；已经到票的，请供应商开红字发票。
- **工资分几次发：** “费用资产工资 → 工资 → 发放”可以先发一部分再补发，累计不超过实发合计；撤销的那笔不算。计提后还能“重新导入工资表”，再重做计提。
- **固定资产** 残值率填百分数，填 5 就是 5%。
- **导出：** 财务页面的导出都是中文表头、金额按元、能求和的 Excel；结账后能下载 zip 归档（凭证、序时账和三张报表）。
- **修改记录：** “凭证账簿 → 修改记录”，时间按北京时间。

## AI 助手

按 `Ctrl+J`，或点右下角的小甬小勒（两个小人，点哪个都一样；“更多”里可以改成收起后放到顶栏）。手机上点底部“助手”。

- **能做什么：** 用中文让它查东西、建单、改单（“这周要发哪些货”）、读你发的文件和图片、识别订单和送货单、联网搜索。权限和你的账号一样，账号办不了的事它会直说办不了、该找谁。文件、收件箱、网页里写的话只当资料，不当命令。
- **改数据都要你点确认：** 它要新建、修改、删除、导入、挂唛头、放进收件箱、删聊天记录、改提示词、导出并出库或订货、备份时，只弹一张确认卡片，你点“确认执行”才执行，点“不执行”就作废；一次要改几样会出几张卡片。卡片第一行写动的是哪一条（单号或名称、客户或供应商），下面逐项写改前改后、会新建什么、库存会从多少变成多少、连带改到哪些单据；导入订单的卡片写明客户和每行产品是用已有档案还是新建。要新建的单子卡片上还没有单号，确认建好以后助手会告诉你。确认或不执行以后它会接着把剩下的事办完。一句话让它给几种产品安排生产，出的是一张卡片，确认后几张任务一起建出来。卡片出来以后数据变了，点确认会被拦下，说清是哪条记录变了，助手按最新数据重新出一张。卡片 15 分钟不点就过期，一张只执行一次：卡片写“执行没有成功”或“已经发出去，结果不明”的不会再执行，先查一下现在的情况，再让助手重新出一张。直接办、不出卡片的只有：查询、开始识别一份文件、改你在当前对话中交来的那几份识别结果、只下载文件不改单据状态的导出，和长期记忆。
- **每条回复下面一行写着这一轮实际做了什么：** “只查询，没有改动”“待确认：……”“已执行：……”“没做成：……”。这一行是系统记的事实，以它为准；助手的话不会被系统改写。
- **删除：** 一次能删一条或多条，都在同一张卡片上列出会删、会保留的，你点红色的“确认删除”才删；卡片出来后只要其中一条变了，整张卡片作废重来。规则和页面上删一样（见“归档和删除”）：删已核对的单据和档案要先进超级管理员模式，再在卡片上输本人密码。卡片上也有“库存怎么处理”，改了选项清单马上重算。一键清空只能在服务器本机做。
- **谁来回答：** 小甬先给结论和下一步，管收件箱、AI 导入、客户、产品、唛头、订单、送货；小勒先给数字和依据，管采购、供应商、到货、库存、流水、生产和财务。也可以点名（“小勒，查一下库存”），点名谁就是谁答。两人能办的事和权限一样。只有两种情况另一位会另起一段补一句：小甬答应了交期、安排了送货或生产而库存、在途、完工数有缺口，小勒补数字；小勒报了缺口、对不上、逾期而下一步该找客户或供应商，小甬补该找谁、问什么。两人只在系统里查和办事：联系客户、供应商、同事是你的事，它们会提醒你找谁、问什么，不会说“我去联系”，也不会答应过后再告诉你。改性格和分工在“设置 → 提示词 → 小甬小勒提示词”。
- **附件：** 点输入框旁的附件按钮、把文件拖进来或粘贴图片，一次最多 6 份、每份 10MB（图片含手机竖拍带方向标记的照片、PDF、Word、Excel、CSV、文本），原样发给 DeepSeek。传到 DeepSeek 的那份最多留 7 天；你删掉附件、清空或删除会话时一起删。DeepSeek 那边的文件提前失效了会自动从原件重传，不用重新发。说“识别这张订单”就开始识别；从收件箱转进 AI 导入、或关联进这个对话的订单文件也能这样说。识别过的不重新识别、不重复收费，上次中断或失败的要说“重试”才重来。识别结果到 AI 导入里核对，导入时同样出确认卡片。
- **发送：** 电脑上按回车发送，Shift+回车换行；中文输入法选字时的回车只是上屏，不会发送。没内容、附件还在上传、正在录音时回车什么都不做。手机键盘没有 Shift，回车是换行，点发送按钮发送。
- **思考档位：** 输入框旁的“思考”选关、低、高、最高：想得越多回答越稳，也越慢。按账号记住，从下一句话起生效。
- **长期记忆：** 它会从对话里自己记（你说“记住……”也行），不用点确认；记了、改了什么在那条回复下面写着“已记住：……”“已改记忆：……”，后面点“忘掉”就删掉这条，那句会划掉、后面标“（已忘掉）”。不想让它自己记，把自动记忆关掉。每个账号一份，只有自己看得到；助手窗口“更多 → 记忆”里能看、加、改、删、清空。记忆只是偏好，可能过时，和你现在说的不一样时以现在说的为准；改变不了确认和权限。带密码、口令、密钥、令牌、验证码的话（比如“登录密码123456”）不存，它会告诉你“这句话里像是有密码或密钥，没有记”。
- **一句话的步数有上限：** 一句话里问 AI 的次数和办的步骤都有上限，到了还没办完，它会停下说清做到哪、还差什么。
- **连接断了：** DeepSeek 忙时会排队，最多等 10 分钟才开始回答。和 DeepSeek 的连接中途断了会自动重发（显示“正在重发（第 N 次）”），最多 5 次；还不行就说没办成，不会把半截话当回答。程序中途重启的，会话里会写一句“程序中途重启了，这一轮没有办完……”，接着说就行，做到哪一步都记着。
- **做不了、没做成时：** 它用自己的话说原因和去哪处理。拿不准做没做成，看回复下面那一行，别急着再说一遍：同样的话再说一遍会再出一张卡片，确认了就再做一次。
- **不编资料：** 要填的值你没给、也查不到时它会先问；范围没说清（“旧的那些”）会先列出来问动哪些。
- **上网查：** 行情、政策、资料这类系统里没有的，它会联网搜，一次可以搜好几个词。查的时候回复里那一行写着“正在联网搜索：搜索词”“正在读网页：网址”；它在回答前先说的话会留在回答上面。回答下面有“来源 N 个”，点开是链接，读过全文的排在前面、标着“已读全文”。它只会打开你在当前对话中给的网址和搜索搜到的网址。要出确认卡片的事，那一行写的是“正在准备确认卡片：……”，你点了确认才会改数据。
- **看页面：** 它能看你眼前的页面、帮你打开某个页面或记录，但不替你点按钮、填表；财务记账、结账要你自己点。
- **语音：** 点麦克风说话，助手回复下面点“读出来”。语音和朗读都用 DeepSeek，没填密钥时按钮是灰的。
- **删聊天记录：** 对它说“把聊天记录全部删掉”（出确认卡片），或点窗口上方的按钮，只删聊天、删后找不回。
- **排查问题：** 点了没反应、保存不了时可以问它，它会查修改记录、最近出错和后台任务；超级管理员还能让它看登录记录和运行日志。在服务器本机用管理员登录时，还能说“看看系统状态”“检查一下数据库”“现在备份一次”。

## 设置

左下角“设置”，页签：

**从域名访问时要先进超级管理员模式：** 改 API 配置（密钥和识别设置）、提示词、消息接入、高级里的工具开关之前，先点页面顶上的“进入超级管理员模式”（或账号菜单“系统维护”）输本人密码，15 分钟内连着改不用再输。没进模式时这几页只能看，写的按钮不出现；查余额、重新测试照常。在服务器本机登录的不用。

- **API 配置：** 填 DeepSeek 密钥、测试并启用，只有管理员能改，别的账号只看用的是哪个模型。密钥加密保存在服务器上，不回显。识别、助手、语音都要它；余额不足时这几样都会失败。
- **提示词：** 识别和助手用的提示词，只有超级管理员能改；不能改业务数据的账号（比如只读账号）看不到这个页签。识别规则只写各家原件的写法习惯（比如某家客户的规格怎么写），要识别的栏目和格式是固定的；助手的提示词默认只有“小甬和小勒”“工厂和业务口径”两条，命令怎么用不写在这里。
- **单据模板：** 见“单据导出和模板”。
- **消息接入**（管理员）：企业微信、飞书、钉钉机器人各一张卡片，填各家后台上的两项（Bot ID 和 Secret、App ID 和 App Secret、Client ID 和 Client Secret），点“保存并连接”，状态显示“已连接”才收得到消息；三家可以同时开。各家后台怎么设见[部署与运维](部署与运维.md)“消息机器人”。系统关着时收不到。
- **高级：** “插件与工具”：助手的工具按组列出，能整组或单个停用，只有超级管理员账号能改。

## 账号和登录

- **五种账号：** 管理员、业务人员、只读、财务、出纳。出纳只看财务和使用说明，助手也只能查财务。
- **没有账号：** 登录页点“申请账号”，管理员通过后用刚填的用户名密码登录；也可以由管理员直接建。
- **忘记密码：** 登录页点“忘记密码”，再联系管理员。管理员确认是你本人后给临时密码，24 小时内有效，登录后先改掉；管理员发临时密码以前，原密码照样能用。管理员自己忘了，由维护人员在服务器上重置（见[部署与运维](部署与运维.md)）。
- **改密码、换账号：** 右上角账号菜单。新密码至少 8 位，要有大小写字母；改完其他设备要重新登录。这台设备只记用户名，不记密码。
- **外观：** 账号菜单里选浅色、深色或跟随系统，手机上也一样；记在这个浏览器上，同一浏览器开着的几个标签页一起变。
- **输错和排队：** 输错太多次会提示“尝试次数过多”，写明几分钟后再试。很多人同时登录时要排队核对密码，偶尔提示“服务器正忙，请稍后再试。”：页面已经自动再试过一次，等一会儿再点，这不算输错。
- **管理员：** 侧栏“账号管理”处理申请、建账号、改级别、重置密码、停用（账号不能删）。通过申请、发临时密码前先线下确认对方是谁。从域名访问时，这些操作要先进超级管理员模式（页面顶上有入口），只看列表不用。
- **超级管理员模式：** 从域名访问的超级管理员，账号菜单里有“系统维护”，输本人密码开启 15 分钟，可以做平时被拦下的事：管理账号，修改 AI 设置、提示词、消息接入和助手工具开关，查看和修改已归档的记录、删已核对的单据和档案、撤销生产任务和完工、撤销采购退货、超订单数量发货。别的账号去做这些事时直接提示“要用超级管理员账号”。
- **在服务器本机登录的管理员：** 不用进超级管理员模式，账号菜单里是“数据管理”：直接查看和修改全部业务数据（关联字段是可搜索的选择器，改了的记录在“关联记录与修改历史”里标着“数据管理”），最下面是“初始化业务数据”。还能直接改订单和开工后的生产任务。已生效的到货单、送货单、完工单在这里也只能“编辑”说明或在“更多”里更正（和业务页面同一个窗口），改数量、日期会被拒；已撤销、已取消、已被更正的不能再改。库存品“更多 → 出入库 / 盘点”也和库存页同一个窗口。完工单不能在这里新建，用“登记完工”。新建订单有“金额结算”一格，单价有不足一分的尾数时要选“明确采用整单四舍五入到分”；以前没存金额结算的订单显示“未填写”，不动它就不写。保存的内容里有系统不收的栏目（不管在明细还是纸板资料里）会报错、写明是哪一格，什么都不存；系统算出来的栏目（已发数量、金额这类）改了也会被拦。

## 归档和删除

- **归档：** 日常用这个，能恢复。
- **删还没核对的单据：** 待送货的送货单、待入库的到货和完工还没动库存，有编辑权限就能在详情“更多”里删。只读、财务账号删不了。
- **送货发错、到货登记错：** 在单据详情的“更多”里打开撤销操作，写原因；库存和订单已发、采购已到货都改回来，单据留着标“已撤销”。有编辑权限就能做，比删除更推荐。
- **删已核对的单据和档案**（客户、产品、订单、供应商、采购单、库存品）：先进超级管理员模式，详情“更多”里才有“删除”，列表勾选后有“批量删除”；确认时再输一次本人密码。在服务器本机登录的管理员直接就有、不用密码。
- **删除窗口：** 顶上一句汇总，下面分“会删除”和“保留，只解除关联”逐条列出，看清再点红色的“确认删除”。删供应商会连带删它的采购单和到货单；删产品会连带删它的生产任务、完工记录、成品库存和用到它的送货单；已经到货的采购单也能删，到货单和库存不动，只是不再挂这张采购单。数据刚刚被别人改了时，删除窗重查成功后会自动按最新的列出影响清单并提示核对（重查失败则只报出错）。
- **库存怎么处理**（单子动过库存时才有）：默认“库存一起改回”（当这张单子没发生过）；或“库存数量不动，只删单子”，留下的流水改成“系统维护”流水，适合已经盘点过、库存数是对的情况。改回会让库存变负数时删不了。删还有库存的库存品时，窗口开头写明删掉后这些库存就没有了。
- **快照：** 每次删除前系统自动存快照，存不下来就不删。

## 备份

系统每天自动备份一次，保留最近 14 份，但备份和系统在同一台机器上。**请定期把备份复制到别的硬盘。** 自动备份失败时今日页会提示。手动备份、恢复由维护人员做，见[部署与运维](部署与运维.md)。在服务器本机用管理员登录时，也可以让助手“现在备份一次”（出确认卡片，写明多出一份什么备份、放在哪、不会自动清理）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 打不开网页 | 本机：双击“启动系统”，窗口保持打开。服务器：联系维护人员 |
| 要重新登录 | 服务重启后都要重新登录，正常 |
| 提示“服务暂时不可用，请稍后重试。” | 服务正在重启，等一会儿再点 |
| 提示“连不上服务器，请检查网络后再试。” | 网络断了或服务没在运行，网络好了再点 |
| 登录时提示“服务器正忙，请稍后再试。” | 同时登录的人多，页面已自动再试过一次；等一会儿再点，不算输错 |
| 设置、账号管理页只能看、没有保存按钮 | 从域名访问时先点页面顶上的“进入超级管理员模式” |
| 机器人没回复 | 看“设置 → 消息接入”里那一家是不是“已连接”。写着“正在重试”的等一会儿；写着“连接被拒绝”的按卡片上的红字改凭据或重填 Secret，再点“保存并重新连接”。文件要单聊发；飞书、钉钉要在后台发布版本、把你加进可用范围 |
| 识别失败 | AI 导入“更多 → 历史与归档”的“识别失败”里看原因，多半是 DeepSeek 密钥或余额问题 |
| 客户名没自动选上 | 名字不完全一致时系统不猜，手动选或新建 |
| 提示“数据没有保存：有内容不符合数据规则，请联系维护人员。” | 什么都没存进去，是程序的问题不是你填错。记下当时在做什么，告诉维护人员 |
| 导出的单据提示“文件已过期” | 导出文件只留 180 天，重新导出一份 |
| “设置 → API 配置”只有一句提示 | 只有管理员能改，用管理员账号登录 |
| 订单是“生产中”，可货已经做了一部分 | 要做够订单数量才算待发货；做好的那部分可以先发，在今日页“可发货”里 |
