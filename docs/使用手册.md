# 使用手册

写给每天用系统的人。软件里的“使用说明”页是简版，这里更完整。

## 一张图看懂

```mermaid
flowchart LR
  A[客户发来文件] --> B[收件箱]
  B --> C[AI 导入核对]
  C --> D[订单]
  D --> E[采购纸板]
  E --> F[到货入库]
  F --> G[生产任务]
  G --> H[登记完工]
  H --> I[送货发货]
```

左侧导航就是这个顺序：今日、收件箱、AI 导入，然后是销售、采购、生产、仓储。

## 账号和登录

- **没有账号：** 登录页点“申请账号”，填用户名、密码和说明。管理员通过并选好级别后，用刚才的用户名和密码登录。也可以由管理员直接建好告诉你。
- **忘记密码：** 登录页点“忘记密码”，填用户名后联系管理员。管理员确认是你本人后给你一个临时密码，24 小时内有效，登录后必须先改掉。在此之前原密码不变，想起来了可以直接登录。
- **切换账号：** 右上角菜单点“切换账号”，或者退出后在登录页选。这台设备只记用户名，不记密码，切换时要输密码。公用电脑上可以点账号右边的 × 移除。
- **修改密码：** 右上角菜单点“修改密码”。新密码至少 8 位，要有大写和小写字母。改完其他设备要重新登录。
- **管理员：** 左下角“账号管理”处理待办申请、建账号、改级别、重置密码、停用账号。有待处理申请时右上角有红点。通过申请和发临时密码前，请先线下确认对方是谁，因为任何人都能填别人的名字。账号不能删除，只能停用。
- **管理员自己忘记密码：** 到服务器本机运行 `npm.cmd run reset-password -- "用户名"`。

## 手机上使用

手机浏览器打开系统地址就能用，不用装 App。系统部署到服务器之后，手机才能从外面访问；现在只能在运行系统的这台电脑上打开。

- **底部导航：** 今日、订单、助手、生产、仓库。其他页面点左上角菜单，收件箱的待处理数量也显示在那里。
- **仓库、生产：** 页面顶部切换库存、到货、送货、流水，或者生产任务、完工记录。
- **列表：** 手机上是一张张卡片，点卡片看详情。筛选默认收起，点“筛选”展开。
- **AI 助手：** 点底部的“助手”进入全屏对话，可以发照片和语音，点左上角返回。
- **排产：** 手机上默认看列表。排产板靠拖动改日期，要改计划日期建议在电脑上操作。

## 开始之前

- **地址：** `http://127.0.0.1:3001`，目前只能在运行系统的这台电脑上打开。
- **账号：** 分管理员、业务人员、只读、财务、出纳五种，详见下面的“账号和登录”。
- **第一次用：** 管理员先到 设置 → API 配置 连接 AI 服务（只有管理员能改），再录入常用的客户和产品（也可以在建订单时快捷新建）。

## 每天第一件事：看“今日”

今日页列出待处理的事，比如该发货的、逾期的、收件箱里没处理的。点一条就到对应单据。

## 收文件：收件箱

所有进来的内容都在这里，一条条处理。

- **企业微信机器人：** 在企业微信里**单聊**机器人，把文字、图片、文件发给它，它会回复“已收到”或失败原因。群里只收 @ 它的文字。
- **手动：** 点“上传文件”或“粘贴文字”。
- **处理文件：** 点转订单、转到货或转唛头，会进入 AI 导入。只有 PDF、Word、Excel、JPG、PNG 能转。
- **处理文字：** 点“新建订单”，原文显示在表单上方方便对照，保存后自动标记为已转单。
- **不需要的：** 点“忽略”，或标记“已处理”。

转单不会自动发给 AI，要你点“开始识别”才会。

**注意：** 机器人只收发给它的内容。客户发到员工企业微信的文件，要由员工转发给机器人。超过 20MB 的文件不保存，机器人会告知。

## 客户订单

**用文件建（推荐）：**

1. 在 AI 导入选“客户订单”，开始识别。
2. 对照左边的原件核对草稿，黄色提示的地方重点看。
3. 确认客户和产品。名字只差公司后缀的客户、名称和尺寸都对得上的产品会自动选上，选择自动保存。错别字、相近的、名称只是包含关系的（比如“纸箱1”和“纸箱10”）会列出候选让你选，没有对应的导入时新建。
4. 完整预览后正式导入。

**手工建：** 点“新建订单”，选客户、加产品、填数量和交期。

**看进度：** 点订单打开右侧面板，顶部的“下一步”会告诉你接下来做什么，下面能看到每行的待发、可用库存和生产情况。

**状态：** 草稿、已确认、已取消由人选；生产中、待发货、已发货由生产和送货单自动更新。每个没发完的产品都做够订单数量才算待发货，只做完一部分还是生产中。同一产品写了几行的合起来算；一张生产任务同时排给几张订单的，这几张订单要的总数做够了才算。生产任务的单位和订单不同（比如任务按箱、订单按只）时不换算，不算这张订单的生产量，订单详情里会提示。分批发货时，发了一部分就显示“部分发货”，全部发完才是“已发货”：比如一万个今天做五千发五千，今天是部分发货，今日页会提醒还差五千没排产，明天做完发完变成已发货。做好一批没发时，今日页的“可发货”里就有它，不用等全部做完。

## 唛头和样稿

客户发来的唛头不是订单，也不用生产，它是产品的参考资料。

1. 在 AI 导入选“唛头”并识别，也可以直接把文件发给助手。
2. 系统按料号、名称、尺寸对应产品。唯一对应上就自动把原文件挂到产品下，不用再点。唛头上的料号和产品档案的料号对不上时，即使名称一样也不会自动挂，要你确认。
3. 对不上或有多个候选时，选一下产品，点“挂到产品下”。不要的款勾“不挂”。挂错了到产品详情里移除。

之后在产品、订单和生产任务详情都能看到，点文件名预览原件，多页 PDF 能翻页。也可以在产品详情里直接上传。

## 采购和到货

1. **采购单：** 选供应商和原材料，可关联客户订单。可以导出订货单发给供应商。
2. **到货：** 在“到货”页登记。可以先建到货计划，货到后再确认；也可以用 AI 导入选“到货单”识别供应商送货单。
3. **验收：** 实收 = 合格 + 不合格。库存只按实际入库增加。可以分批到货。
4. **弄错了：** 在到货记录点更正，系统保留原记录并追加更正，不要新建重复单据。

## 生产

1. 在订单面板点“安排生产”，或到“生产任务”新建。排产板能看每天的任务。
2. 做完后在任务或“完工记录”登记良品和废品，成品自动入库，也可以整批领料完工。

## 送货

1. 在订单面板点“建送货单”，或用“可发货清单”勾选合并。
2. **确认发货时才扣成品库存。** 计划不影响库存。
3. 导出本批送货单（Word 或 Excel）。送货一定要关联真实订单。

## 库存和流水

- **库存：** 能看在库、已安排、可用、在途。可用量只是提示，真正的扣减在确认时校验。
- **流水：** 每一次库存变动的记录。不同单位不会换算相加。
- **盘点：** 在库存页操作，系统追加流水，不直接改数字。

## AI 助手

点右上角“AI助手”或按 `Ctrl+J`，也可以点右下角的小甬和小勒（Y 和 L 两个小人，点哪个都一样）。手机上从底部“助手”进入。

- **系统维护：** 可以对助手说“看看系统状态”“检查一下数据库”“现在备份一次”。恢复备份要先停机，运行 `npm run restore`。
- **删聊天记录：** 直接对助手说“把聊天记录全部删掉”，也可以点窗口上方的按钮。只删聊天，不动业务数据，删后找不回。必须是你本人明确说要删：“不要删”“怎么删”都不算，“能不能删”它会再问你一句。从产品上移除唛头也一样。
- **谁来回答：** 小甬管收件箱、AI 导入、客户、产品、唛头、订单、送货、今日总览和设置，开朗利索；小勒管采购、供应商、到货、库存、流水、生产、完工和财务，稳重较真。问到哪块，对应的人跳出来回答，也可以直接点名“小勒，查一下库存”。
- **能力一样：** 分工只决定谁出面，两个人能用的工具一样，权限都看你的账号。跨两边的事一个人就能办完，必要时另一位接一句。
- **改性格和分工：** 设置 → 提示词 → 全局助手提示词，里面有“小甬的性格”“小勒的性格”“分工和接力”等条目。
- **动作：** 平时自己玩，处理任务时负责的人干活，窗口收起时做完会击掌并冒气泡，点气泡打开聊天。拖到左右边缘时两人探出头和脸。

- 可以用中文让它查东西、建单、改单，比如“这周要发哪些货”。它的权限和你的账号一样。
- 可以把文件发给它读。文件里写的话不会被当作命令。
- 它说做完了，会以系统真实结果为准；重要操作还是建议在页面上看一眼。

## 财务

左侧“财务”分组，只有财务人员、出纳和管理员看得到。

**送货、到货、收款都不用等财务。** 没有税率照常做。只有出正式报表和结账时，系统才要求把缺的税率补上。

### 每月看什么

打开“财务概览”，选月份，第一张表就是两种盈亏：

| | 收入 | 支出 | 盈亏 |
|---|---|---|---|
| **理论** | 本月送货单金额 | 本月到货单金额 | 收入减支出 |
| **实际** | 本月收到的钱 | 本月付出的钱 | 收入减支出 |

两者互不影响。补税率、拿优惠、收利息都不改理论盈亏。房租、工资、水电不进理论盈亏；录了付款的话，算进实际支出。

点任一金额可以看到每一笔。“本月实收来自哪个月的单子”能看出这个月收的钱是几月份的货款。

### 补税率

打开“月度台账”，点“待补税率”。可以点开一张逐行填，也可以勾选几张一起填，或者“按单位整月补”。不开票的选“无税 / 不开票”。这里只改财务记录，不动送货单和到货单。

### 压货款和优惠

在“应收应付 → 账期设置”按单位设：

- **压货款：** 压几个月、每月几号付；或者压多少天。
- **现结优惠：** 比如当月结清优惠 2 个点。比例由你填，系统没有内置数字。
- **分期、压款利息、保证金：** 用到才设。利息只给建议，你确认后才入账。

改账期只影响新单子。已有单子要改到期日，用“往来单 → 按新账期重算到期日”。

“压货款”页签看每家压了多少，“收付计划”看未来几个月要收要付多少，“到期提醒”看快到期和逾期的，“今日”页也会提醒。

### 收款和付款

“资金发票 → 收付款 → 新建”，先保存成草稿，确认时选核销哪些单子。

核销金额含优惠：339 元的单子优惠 6.78 元，实收 332.22 元，核销填 339，优惠填 6.78。

录错了点“撤销”。有核销的先在下面撤销核销。

房租、水电这类没有往来单位的，类型选“其他支出”。

### 记账和结账（给做账的人）

1. **启用：** 先到“财务设置”选启用月份和纳税人身份，只想看盈亏可以不启用。启用前已有库存的，要把库存金额填进原材料（1403）、库存商品（1405）的期初，后面第一次算成本时填同样的金额，否则这两个科目的余额对不上。启用后期初不能再改。启用后到“资金发票 → 资金账户”建账户。
2. **一个人做账：** 系统默认制单和审核要不同的人。只有一个人时，到“财务设置 → 修改”关掉，由管理员操作。
3. **制单：** “凭证账簿 → 财务事件”把送货、到货生成凭证草稿，再到“凭证”页提交、审核、记账。
4. **报表：** “报表结账”。缺资料时会列出还差哪些单子。
5. **成本：** 第一次算成本（启用月）时，要填启用前已有库存值多少钱；手工入库也要填金额。没有这些金额算不出成本，也结不了账。填 0 表示没有成本。
6. **税率：** 结账前到“财务设置”填附加税率和所得税率，系统不设默认值。不用缴的填 0。
7. **结账：** “报表结账 → 结账”按清单走完。没有工资和固定资产的月份也要点一下“工资计提”“计提折旧”，算作已处理。

财务页面的“导出”都是可以直接看的 Excel：中文表头，金额按元，能继续求和。结账后可以下载一个 zip 归档，含凭证、序时账和三张报表。

已记账的凭证不能改、不能删，错了只能红字冲销。手工凭证里应收、应付这类科目要选客户或供应商。

**红字发票：** 录入时选对应的原蓝票，确认时不用关联往来单。全额红冲会自动冲掉原票凭证；部分红冲且原票已经生成凭证时，要填对方科目。红冲后原来占用的开票额度会释放，可以重新开票。

**12 月结账：** “结转损益”要点两次：第一次是月末损益，记账后按钮变成“结转年度利润”，再点一次。

报表行项目和税率还没请懂账的人复核，先当内部参考。

## 归档和删除

- **归档：** 日常用这个，可以恢复。
- **永久删除：** 只有本机管理员能做，会先显示影响范围，删除前系统自动存快照。

## 备份

系统每天自动备份一次，但备份在同一台电脑上。**请定期把 `backups` 文件夹复制到别的硬盘或 U 盘。** 详见[部署与运维](部署与运维.md)。

## 常见问题

| 现象 | 处理 |
|---|---|
| 打不开网页 | 双击 `启动系统.cmd`，窗口保持打开 |
| 要重新登录 | 服务重启后都要重新登录，正常 |
| 机器人没回复 | 看 设置 → 消息接入 是否“已连接”，软件要开着；文件要单聊发 |
| 识别失败 | 在 AI 导入的“更多”里看错误档案，可能是模型服务或额度问题 |
| 客户名没自动选上 | 名字不完全一致时系统不会猜，手动选或新建 |
| 尺寸单位提示待确认 | 系统不猜单位，确认后再选毫米或厘米 |
| 设置里的 API 配置只有一句提示 | 只有管理员能改 AI 设置，用管理员账号登录 |
| 订单显示“生产中”，可是货已经做了一部分 | 要做够订单数量才算“待发货”；做好的那部分可以先发，今日页“可安排送货”里能看到 |
