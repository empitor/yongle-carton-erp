# v0.5.2 发布说明

2026-10-28。软件、包及锁文件版本统一为0.5.2，Git标签v0.5.2；业务目录25，数据库迁移仍为11。本版在现有ERP和Agent架构内扩展，不新增第二套注册表、权限系统或业务库。

## AI 插件与工具管理

- 统一入口为“AI 设置 → AI 插件与工具管理”，聊天窗口插件按钮进入同一页面，移除左侧一级插件菜单；旧#ai-plugins及原设置链接兼容跳转。
- 插件包含工具，名称、简介、版本、实际工具数量、参数、权限、执行服务和当前可用状态从注册表动态读取，保留日志与状态查询。
- 插件关闭后所属工具不再向模型开放且拒绝执行；各工具独立开关保留，重新启用后按原设置恢复。沿用原tools.sqlite。
- 新插件可通过registerPlugin注册声明、Zod参数和执行器；模型回复解析同步读取实际注册表。

## ERP 页面控制与工作区

- page.observe/page.act/page.verify控制当前ERP标签页，优先原业务API；保留实际控件身份、快照失效、真实账号/会话/请求/标签页绑定及敏感信息排除。
- 支持概要、区域、当前记录、完整观察；默认概要，表格/控件/选项按需分页，连续操作回传变化内容和反馈。虚构大表格实测概要输出减少85.9%，无变化增量减少98.7%（JSON字符，不代表真实Token节省比例）。
- 页面交互与真实业务结果分开记录。需要核验的操作须事前绑定各自记录、完整预期和原版本，再逐步核验；跨任务、未执行、未绑定、版本不变或部分字段不符不能错误完成。
- 人工或聊天订单工作区通过list/attach原地关联，不复制或重复识别；明确导入指令沿原完整预览、身份、修订和ImportExecutionService逐份提交，多文件部分成功按文件反馈，成功文件不重放。
- 聊天窗口支持边缘和四角调整尺寸、拖动、最大化恢复及本机尺寸位置记忆。

## 执行预算、恢复与权限

- 服务端统一预算默认15次模型、40次工具、8次业务写入、20次页面交互、30分钟。环境或构造配置受验证，客户端和模型不能提额；写入上限8、超时上限30分钟。
- 只读、页面交互和业务写入分别计量；可能写入的页面操作保守预占写额度。预算耗尽保存真实进度，继续前核验原回执，保留无进展循环、连续失败、超时及未知结果防重放。
- 任务面板显示实际预算、工具输出字符数、Provider返回的真实Token及报告覆盖数；无真实用量时明确显示估算，工具输出估算采用字符数÷3。
- 展示与dispatch共用服务端最低权限判断，自定义写工具漏写/清空权限也不能降低business:edit要求；高级管理使用真实本机管理员能力证明。原业务服务的身份、版本、事务、审计、库存及幂等校验保留。
- 旧版无逐步目标绑定的页面成功状态恢复为待核验，不能直接跳过或猜测重放。

## 升级

1. 停止旧服务，离线备份完整data目录及独立API配置，保留SQLite WAL和工作区文件。
2. 更新至v0.5.2，使用Node.js 24.15或更高24.x版本，运行npm ci和npm run build。
3. 正常启动并刷新ERP网页。原业务、账号、工作区、提示词、工具设置和Provider存储路径保留，不用示例数据覆盖原数据。

从v0.5.1升级没有新增业务库迁移。历史v0.5.0、v0.5.0-fix及v0.5.1标签保留，不覆盖。

## 验收与边界

发布验证包括366项自动化测试、TypeScript类型检查、正式构建、启动脚本测试、干净Git克隆验证以及暂存区和历史凭据审计。测试使用独立临时虚构数据和可控Provider替身；未修改真实业务库，未调用收费模型。构建保留现有Zod注释及较大分块提示。

浏览器验证了统一管理入口、插件/工具启停恢复、页面填写与保存、独立业务核验、旧快照拒绝、敏感信息排除、分页和窗口调整。详细代码验收见[Agent与插件验收记录](Agent插件与页面控制验收-2026-10-28.md)。

本版只控制ERP自身DOM，未提供截图识别、像素鼠标、Windows桌面、跨域iframe或原生浏览器确认框控制。页面交互和数据库不能形成跨端原子事务，未知结果需先核验。无真实ID的新建记录优先使用原业务工具及回执；真实Token统计取决于Provider提供usage，未进行真实收费模型的自然语言成功率验收。

发布只包含源码、必要依赖包、公开测试夹具及许可证和经过整理的说明；真实数据库、账号/密钥、上传原件、备份、语音模型、运行日志和本机截图不上传。
