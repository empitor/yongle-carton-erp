# 文档目录

改代码的人和 AI 先读根目录的 `AGENTS.md`（硬规则，只放在开发机上，不随仓库公开）；文档写在哪、怎么写见它的“文档怎么维护”。

| 文档 | 管什么 |
|---|---|
| [使用手册](使用手册.md) | 给用软件的人：每个功能在哪、点什么、会发生什么。程序里的“使用说明”页和助手读的都是它 |
| [部署与运维](部署与运维.md) | 服务器部署、整包和补丁升级、备份恢复、日常维护和排查 |
| [架构说明](架构说明.md) | 模块、目录、数据怎么流、关键机制 |
| [数据模型](数据模型.md) | 表、归属、约束、派生关系 |
| [功能链路表](功能链路表.md) | 功能对应的页面、接口地址、助手工具 |
| [界面规范](界面规范.md) | 叫法词表、公共件、交互规则 |
| [路线图](路线图.md) | 只写还没做的：待办、待验证、已知问题、暂不做；做完就删 |
| [更新日志](CHANGELOG.md) | 只有一节：开发中叫“未发布”，做完还没发布的写在这里；发布时改成版本号和日期，内容就是发布说明；以前的版本看 Git 标签和 GitHub 发布 |
| `brand/` | 商标图片 |
