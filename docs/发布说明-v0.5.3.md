# 0.5.3：自主Agent与工程整理

日期：2026-10-28。软件版本统一为0.5.3；业务目录26，数据库迁移仍11。本版已发布 GitHub Release（v0.5.3），历史标签保持不动。

## Agent

- working、needs_input、completed、blocked结构化执行状态；问号不再触发停机，有可执行步骤时继续后台处理。
- 已确认业务参数、文件顺序与真实来源持久保存；独立目标新任务，原任务保留并可恢复。
- 默认连续调用与服务端资源配置，保留无进展、失败、超时、停止、检查点和幂等回执。
- 复用当前真实Actor与原业务服务；移除助手独有的重复密码、模式和不必要确认，保留真实权限、字段、库存及事务校验。
- 基础工具仍可组合；统一管理支持全量选择、批次及前序真实结果引用。
- 整批生产完工支持库存关联/必要档案准备、参数预检、正式领退料及成品入库；共享实际547张与独立型号取整548张分别处理，不猜物理切割布局。
- 本机ERP浏览器提供真实截图、坐标、键盘、滚动和当前聊天附件上传，保持账号/会话、来源和图像有效性保护。
- 保留新加入的受控业务初始化、工作区清理及识别元数据空值兼容，错误字段改为可读说明。项目文件清理本身不调用初始化功能。

## 工程整理

- 删除App中已被BusinessRecords/ListLayout替代的旧订单表格、分页、空状态/徽标和无效分页状态。
- 删除BusinessRecords废弃确认状态和空转发层、全局助手旧模块映射，以及69个编译器确认未使用的导入绑定。
- TypeScript启用未使用局部符号与参数检查；保留有效导出、兼容入口、动态Worker、插件接口和迁移。
- npm test补入启动脚本的13项验收；正式默认测试共405项。浏览器回归不再依赖本机既有dist，干净安装后也能直接测试。
- 原物理删除和业务初始化共用删除身份保留，避免清空后新记录复用保留审计/旧任务中的ID。
- 当前架构与历史演进分开；增加项目目录、保护数据及兼容清单，明确可公开文档白名单与生成目录忽略规则。

## 验证与升级

本轮使用独立虚构数据和模型替身验证，不修改真实业务库，不调用收费模型。执行全测试、类型检查、正式构建，并从干净Git克隆安装依赖及复验；隔离服务检查登录、主要业务入口、AI插件和管理入口。详细结果见[清理验收](项目清理与0.5.3验收-2026-10-28.md)。

更新前备份并停止服务，正常拉取、npm ci、npm run build后启动；不需要清空data或用户配置。新电脑需自行恢复数据与本地语音模型，API密钥按原DPAPI规则重新配置。

凭据、Windows原生窗口和其他网站仍不由Agent操作；视觉需要安装的Chrome/Edge及支持图片的模型。真实模型自然语言成功率、生产部署和物理排版仍是独立验收范围。
