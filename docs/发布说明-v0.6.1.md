# 0.6.1：可靠性修复与界面重构

日期：2026-11-05。软件版本0.6.1，业务目录34，数据库迁移13。历史标签保持原样。

本版修复全盘审计发现的基础问题，并重做界面。**升级后所有业务接口都要求登录，首次启动会执行迁移13，请先备份。**

## 可靠性

- 除健康检查和登录接口外，全部接口都要求登录。账号分管理员、业务人员、只读三级，支持改密、停用和命令行找回密码。
- 订单的生产中、待发货、已发货改为按明细逐行派生，冲销后自动回退；普通账号不能再手工设置这三个状态。
- 读取改为按主键或批量组装。3000张订单时，单条读取从约17秒降到1毫秒内，首页统计从约72秒降到1秒内。
- 新增完整备份和校验恢复、每日自动备份（保留14份）、物理删除和初始化前的自动快照。自动备份失败时今日页会提示。
- 管理员改写或删除库存流水时保留修订记录。

## 界面

- 新设计系统和导航，`Ctrl+K`全局搜索，今日页改为待办队列。
- 列表改为单行高密度，点行打开右侧面板，列表保持可见，方向键切换相邻记录。**编辑、归档、删除按钮从列表行移到了面板内。**
- 订单进度统一用履约链表达，只显示有事实依据的环节。
- 排产板可拖动改计划日期；客户和产品选择可搜索；收件箱改为文件、原件、草稿三栏，核对事项整理成疑点清单。
- 库存显示已安排、可用、在途。可用量只作提示，实际扣减仍在确认时校验。
- 送货新增可发货清单，可勾选同一客户的多行合并建单，共用一个成品档案时不会超出可用量。
- 订单、采购、流水改为服务端分页；不带页码的接口调用仍返回全部，AI工具不受影响。
- AI助手展开后默认停靠右侧并推开内容，`Ctrl+J`开关；可切回原来的浮动窗口，精灵仍是默认收起入口。聊天协议、工具和附件未改。
- 新增页面打印样式。清理旧样式约1400行，合并3个样式文件。

## 智能订单导入

- 人工和AI导入共用同一套客户、产品匹配比较。完全同名且唯一的客户可预选，同名歧义或仅相似时不自动合并。
- 顶部固定“保存客户与产品选择”，显示进度，失败时保留选择。

## 升级

1. 先备份：`npm.cmd run backup`。迁移前的备份是回退的唯一依据。
2. 停止旧版：在原服务窗口按Ctrl+C，或运行`npm.cmd stop`。
3. 拉取代码，执行`npm.cmd ci`、`npm.cmd run build`，再用`启动系统.cmd`或`npm.cmd start`启动。
4. 不清空数据库。程序自动执行迁移13：只增加读取索引和流水修订表，不改写业务数据。账号库会增加停用字段。

升级后的变化：

- 打开页面必须先登录。会话保存在内存中，服务重启后需要重新登录。
- `npm.cmd run restore`的参数改为备份目录，并须先停止服务。恢复前的`data/`会另存到同级目录。
- 这一版没有开放到公网的安全加固。部署到服务器前，需要另外配置HTTPS和反向代理。

## 已知限制

- 生产任务、完工记录、到货、送货列表和`Ctrl+K`搜索仍读取全量数据，数据量很大时会先变慢。
- 服务端分页是先算完整筛选结果再切片，减少的是传输和渲染量，不是数据库读取量。
- 在1440宽屏打开助手时，订单表金额之后的列要横向滚动。
- 页面打印只打当前页，最多50行。
- `Ctrl+J`也是Chrome打开下载页的快捷键，自动化测试无法确认实际窗口中页面能否抢先拦截。
