# 公共件

什么时候读：改界面时要用、要找或要加 `src/ui` 的公共件（提示、出错、读取、列表工具栏和表格、页头和“更多”、详情、编辑窗、弹窗、日期筛选、PDF、导出窗）。

都从 `src/ui/index.ts` 引（导出窗除外）。`tests/checks/ui-kit.test.ts` 查：菜单项、出错和“正在读取”提示、列表工具栏、列表行的点击和勾选、pdf.js 只在 `src/ui` 写。

| 位置 | 有什么 |
|---|---|
| `src/ui/Actions.tsx` | 全站一套“主 / 次 / 更多”的动作 `RecordAction`（按钮或链接；`download`、`external` 新窗口、`danger`、`hidden`、`emphasis`）。详情头部用 `ActionBar`；页头写进 `PageHeading` 的 `primary`、`secondary`、`more`（`moreLabel` 是“更多”的读屏名），财务各页的页签经 `src/finance/layout.tsx` 的 `HeadFn` 填页头；勾选条 `SelectionBar` 也用它；“更多”里自己拼的项用 `MenuItem` |
| `src/ui/Record.tsx` | `StatusChip`、`Facts`、`Section`、`Progress`（`text` 代替“已做 / 共 单位”）、`Hint` |
| `src/ui/DetailPanel.tsx` | 详情面板：`kicker` 类型、`title` 编号或名称、`status`、`subtitle`；上下条用 `stepper` |
| `src/ui/Editor.tsx` | `FormSection`、`FormField`（财务也用）、`FormGroup`、`EditorFooter`、明细行尾删除图标 `RowDelete`（`label` 即悬停提示） |
| `src/ui/Message.tsx` | 出错和说明 `FormMessage`（`close` 带“关闭提示”的叉，`action` 放右边一个按钮）；“正在读取…”小字 `Loading`（`what` 写读什么），嵌进别的件用 `loadingText` |
| `src/ui/ListToolbar.tsx` | 列表工具栏 `ListToolbar`（订单、档案、采购、库存、流水、生产任务、完工记录、到货、送货、收件箱、财务月度台账）：搜索、分段（带条数写进分段字）、关键下拉、筛选弹层（一个条件一个 `FilterRow`）。数据管理窗那一行另有条数、刷新、新建，只用 `ListToolbarFrame`、`ListToolbarKey`、`ListSearch` |
| `src/ui/ManagementDialog.tsx` | 弹窗外壳，`size`：`sm` 480、`md` 640、`lg` 880、`xl` 1120（辅助 hook 在 `dialog-hooks.ts`） |
| `src/ui/pdf.ts` | `openPdf` 打开、`drawPdfPage` 画一页（唛头按框宽、助手附件按缩放；翻页、关掉时取消）；pdf.js 只在这里、点了才加载 |
| `src/documents/ExportDialog.tsx` | 单据导出窗（送货单、订货单）：外壳 `DocumentExportDialog`（出错在最上面，预览原地换成纸面、底栏“返回导出”）、`TemplateSelect`（没选过是默认那套）、`FormatSelect`（Word、Excel）、`useExportFile` 正式导出并保存；取数和导出参数各写各的。单据上的抬头、信息格、条款都在 `shared/documents/document-fields.ts` 登记：`key` 存在模板的隐藏清单里，不能改；`label` 是印出来的叫法；`optionalOrder` 定设置页里勾选隐藏的顺序 |
| `src/ui/ListLayout.tsx` | `PageHeading`（标题、`meta` 统计；`children` 放月份这类条件）、`ListSummary`、`TableRegion`、`Pagination`、`EmptyState`、每页条数 `LIST_PAGE_SIZE` |
| `src/ui/DataTable.tsx` | 列表表格 `DataTable`：列定义 `col`、金额列 `mon`（选项 `num`、`wrap`、`priority`、`cellClass`、`title`、`render`），`onRow` 点行或回车开详情、`selected` 开着的行、`check` 勾选列、`empty` 空着时一句（`null` 时页面在表格外说）；财务、生产任务、完工记录、到货、送货、流水、收件箱、账号用它。表头另写的业务列表（订单、档案、采购、库存品、数据管理小表）用 `DataRow` 画行、`SelectAll`、`SelectRow` 勾选。窗口和详情里的明细表各自手写 `<table>` |
| `src/ui/` 其他件 | `SelectionBar` 勾选操作条、`FilterPopover` 筛选弹层、`DateFilter` 日期范围（列表和今日页统计日期共用）、`Segmented` 分段、`MoreMenu`、`ConfirmDialog` 和 `useConfirm`、`Combobox` 可搜索下拉（选项多的字段代替原生 select；下面放不下整张列表、上面放得下时往上开，判断在 `combobox-placement.ts`）、`PasswordField`、`Markdown`（使用说明页用，只认标题、段落、列表、表格、加粗、行内代码、链接）、`ErrorBoundary`（一页出错只换掉这一页）、`required-guide.ts` 必填引导、`SuperModeNotice`（没进超级管理员模式时页顶的提示和入口） |
| `src/ui/` 函数和 hook | `notify` 页面提示、`emit` / `listen` 模块间事件；`beijingTime`；金额（分）`yuan` 显示、`centsInput` 填进输入框、`toCents` 读输入；`sumByUnit` 按单位分别合计；`useLoad`、`useAction`、`useBusinessRevision`（业务数据变了重读）；`refreshOnReturn` 切回页面重新取（只在 App 装一次）；`useResettingPage` 筛选变了回第一页；`useSaveFile` 保存内存里的文件（不自己写 `a.download`）；`useIsPhone`、`isPhoneNow`、`prefersReducedMotion`；`useBackLayer` 安卓返回键登记 |
| 业务里共用的（不在 `src/ui`） | `src/recordkit/InfoBlocks.tsx`：详情里字段多的同类记录一条一块（`InfoBlocks`、`InfoBlock`，成品批次和客户厂区用，变体样式留在各自模块）；`src/editors/party-fields.tsx`：客户、供应商、产品编辑窗的底栏 `ArchiveFooter` 和联系方式 `ContactSection` |
| 样式 | 基础件样式和变量（`tokens.css`）在 `src/ui/`，各模块的在自己目录；样式放哪、先后相关的见 `docs/架构/前端约定.md`，变量相关的见 `docs/界面/样式和主题.md` |
