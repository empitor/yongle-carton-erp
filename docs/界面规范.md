# 界面规范

界面的细则：前端公共件、词表、按钮和布局、样式变量。硬规矩见 `AGENTS.md`“界面”，这里不复述；前端代码怎么组织见[前端约定](架构/前端约定.md)；操作说明见[使用手册](使用手册.md)。

## 叫法（词表）

- **建、改：** “新建××”“编辑××”（编辑说明、编辑备注、编辑到期日、编辑到货安排），不写“改××”；还没内容时写“写××”（写备注）。
- **单据名：** 送货单、到货单、完工单（页面叫“完工记录”），不说“完工登记”“生产登记”。指一张单据用 `shared/business/flow/physical-flow.ts` 的 `flowDocNames`，页面和列表名用 `flowNames`。
- **业务动作：** 确认订单、安排订料（生成采购单）、导出订货单（导出并标记已订货）、登记到货、登记没有采购单的到货（多送、样品）、核对入库（AI 导入到货面板的主按钮也叫它，核对窗的确定按钮叫“确认入库”）、安排生产、登记完工（没有任务的叫“不挂任务的完工”）、安排送货、导出送货单（导出并出库）、不导出直接出库、确认送达、采购退货、出入库 / 盘点。安排订料、安排生产、登记完工、安排送货、出入库 / 盘点各只有一个窗口。
- **撤回类：**

  | 叫法 | 用在 |
  |---|---|
  | 取消 | 还没生效的单据 |
  | 撤销 | 已生效的到货、送货、完工、生产任务、采购退货 |
  | 更正到货单 / 送货单 / 完工单 | 改已生效单据的数量等：撤销原单、出新单号的替代单，详情写“更正自 ××”“已更正为 ××” |
  | 编辑（已生效单据） | 只改说明：备注、时间、地址联系人、操作人 |
  | 红字冲销 | 财务凭证 |
  | 删除；归档 / 恢复 | — |
  | 撤回修改 | 只退回识别结果的上一次修改，不是业务的“撤销” |

- **档案状态：** 客户、产品、供应商只有“归档 / 恢复”，说“已归档”不说“已停用”；“停用”只用于账号、助手工具、提示词条目。采购单没导出订货单叫“待订货”。
- **待核对：** 识别文件说“待识别”“待核对”；生产任务没有待核对，安排即下达。
- **列表：** 搜索、筛选、清除筛选、清除选择；分段统一“待处理 / 全部 / 已归档”。
- **时间：** 只用 `src/ui/time.ts` 的 `beijingTime`：全写 2026/11/14 08:05:03，列表紧凑处 11/14 08:05。
- **名字一致：** 全站页面名、手机底部导航短名（`short`）和侧栏分组都从 `shared/core/pages.ts` 派生（财务各页内的页签由对应页面定义，页签取值在 `pages.ts` 登记）。状态叫法各一份：单据 `flowStatusText`（`shared/business/flow/physical-flow.ts`）、订单 `orderDisplayStatus`（`shared/core/domain.ts`）、采购单 `purchaseStatusLabel`（`shared/business/flow/labels.ts`）、状态颜色 `businessStatusTone`（`src/recordkit/record-meta.ts`）。
- **不露：** 内部编号、英文值、字段代码、开发口径。财务页可以用会计词，但一件事一个词。
- **库存：** 一种货叫“库存品”（“原材料库存品”“成品库存品”），仓库和页面叫“原材料库存”“成品库存”，不说“库存档案”“原材料档案”。删除时库存不动而留下的流水叫“系统维护”流水，不说“数据库维护”“手工调整”。流水按方向叫“入库流水”“出库流水”，两种都有才叫“出入库流水”。
- **其他固定叫法：** 没有采购单的到货明细写“无采购单”；能发的货叫“可发货”；面积单位“m²”；订货批次叫“订货单”；生产任务的量词“张任务”（和纸板的“张”放一起时不只写“N 张”）；领了没用完退回仓库叫“退料”（净耗用 = 领用 − 退料），采购退货里退给供应商的叫“退回”；推算的数带“估计”（如“估计还剩”），口径小字常显；详情“更多”里那一项和窗口都叫“关联记录与修改历史”。
- **栏目叫法：** 一个栏目全站一个叫法，只写在 `shared/core/field-names.ts`，页面、数据管理、修改历史、助手卡片、报错、识别结果表、导出列都从它取；带单位的写“单价（元）”“金额（元）”“税率（%）”，用 `fieldTitle` 取，不写“/ 元”“%”。改了叫法把旧说法加进 `tests/field-names.test.ts` 的名单。按单据叫的：

  | 单据 | 栏目 |
  |---|---|
  | 采购单 | 采购日期、订货数量（窄处“订货”） |
  | 到货单 | 到货日期、到货时间、实到数量（窄处“实到”） |
  | 完工单 | 完工日期、批次备注 |
  | 生产任务 | 登记日期、计划生产日期 |
  | 送货单 | 送货日期、计划送货日期（窄处“计划送货”）、收货地址、收货联系人 |
  | 订单明细 | 本单名称（明细上另起的名字）、分项交期 |

  别的：下单日期、预计到货日期（窄处“预计到货”）、客户采购单号、客户料号、材质 / 配纸、规格、长 / 宽 / 高、联系方式、币种、含税口径（下拉只有“含税”“未税”“未明确”）、金额结算、供应方、验收合格数量 / 拒收数量 / 入库数量（窄处“合格”“拒收”“入库”）、标注张数、标注面积（m²）、差异原因、供应商送货单号、送货单原件、关联订单、附属于、入库的成品库存、机台操作、合格数量、超订单原因。订单明细和纸板、库存品的“规格”是两个栏目，值不相通；导出单据里规格和尺寸拼成一列叫“规格及尺寸”；给供应商的订货单照供应商说法保留“下单日期”“预计交货日期”。例外：识别结果表的单价栏叫“单价（原币）”，照原件抄、可能是外币，旁边有币种一栏（`shared/import/order-draft.ts`）。
- **单价、金额：** 单价至少两位、最多四位小数、去尾零（2.7600 写 2.76），只用 `shared/core/precision.ts` 的 `plainPrice`，带计价方式的用 `shared/business/operations/display-text.ts` 的 `priceText`（按面积写“元/m²”）；还没定价写 `UNPRICED_TEXT`“单价待定”（订货单打印和预览也用）。金额两位小数加千分位。计价方式只有“按平方米”“按张”，不说“计价依据”。订单“金额结算”两项“精确到分，不自动舍入”“明确采用整单四舍五入到分”只写在 `shared/core/domain.ts` 的 `roundingPolicyLabels`，没存的显示“未填写”。
- **财务：** 叫法都在 `shared/finance/labels.ts`。没有到期日叫“没有账期”；收付款类型只用短名（收客户款、付供应商款、其他收入、其他支出、内部转账）；保证金、优惠叫“收到保证金”“付出保证金”“收到优惠”“给出优惠”，不说“押金”；没单号的记录写“叫法 月-日 金额”。财务事件页的按钮叫“核对无误”，送货、到货“有差异”的叫“红字冲销并重做”。被冲销的原往来标“已冲销”（中性色），冲销那笔标“红字冲销”；红色只给“红字”标签、“红字冲销”状态和负数金额。
- **删除：** 影响清单、库存说明、“库存怎么处理”两个选项的叫法只在 `shared/business/lifecycle/deletion-words.ts`，排版在 `src/recordkit/deletion-impact.ts`，删除窗口和助手卡片共用。删除窗口的标题和主按钮写明连带删几张什么单据；删完的提示说清删了哪条、连带几条。
- **报错和提示：**
  - 校验没过按界面叫法说哪一格，中文冒号、整句（“客户：请选择客户；明细第1项的产品：请选择产品”），只经 `shared/core/user-errors.ts` 的 `userError`。
  - 网络断开：“连不上服务器，请检查网络后再试。”；服务器正忙：“服务器正忙，请稍后再试。”（`shared/core/server-busy.ts`，页面先自动再试一次）；先预览再确认被拒：“预览以后数据已变化，请重新预览。”，核对窗、更正窗原地换成最新的，不弹第二个窗。
  - 不是超级管理员账号：“要用超级管理员账号，当前账号没有这个权限”，不叫人去“系统维护”；超级管理员没进模式的才提示去账号菜单“系统维护”。模式横幅和“系统维护”窗口同一句，只在 `src/admin/MaintenancePanel.tsx` 的 `superModeScope`；没进模式时要改共用设置的页面顶上放 `SuperModeNotice`（说明一行，“进入超级管理员模式”按钮另起一行），写按钮不出现。

## 按钮和入口

- **主按钮：** 区域指页头、详情头部、窗口底栏、选择条。主按钮随状态变，没有下一步就不放，不拿“编辑”“新建库存品”凑数。唯一例外：产品的勾选条和详情里“安排生产”“新建订单”并列实心（`RecordAction.emphasis`，只用在这里）。
- **位置：** 页头和窗口底栏在最右；详情头部在最左（主、次，然后“更多”）。
- **次要和“更多”：** 次要最多一两个。“更多”上面是低频动作和管理类（归档 / 恢复、关联记录与修改历史、更正××单），分隔线下面是红色危险项（取消、撤销、删除），危险项只出现在“更多”和确认窗。`ActionBar`、`PageHeading` 自动把多的主操作降为次要，多的次要（详情两个、页头一个）和危险项挪进“更多”。
- **主入口：** 所在对象详情或所在页面页头的主按钮。别的入口只留能带内容进去的（从选中的记录开单、选择条批量操作、待办行的动作）。
- 不放刷新按钮（数据自动刷新）；没权限的操作、走不通的链接不显示；不为少按钮去掉功能，拿不准的收进“更多”。
- **改了按钮文字或结构：** 同时改 `scripts/ui-check/flow-*.mjs` 和断言文字的测试，并查 `shared/assistant/ui-capabilities.ts`、`shared/assistant/assistant-navigation.ts`、`server/assistant/` 有没有用旧文字。

## 列表

- **页头：** 标题、一行统计（只在这里出现一次）、右侧从左到右“更多”、最多一个次要、一个主按钮。按钮文字不带变量（月份写在期间框和确认窗标题里）。
- **工具栏一行：** 搜索 + 一个分段 + 最多一个关键下拉 + 筛选弹层（其余条件收进去，按钮上显示生效个数）。排序点表头。
- **说明：** `ListSummary` 的 `hint` 是口径说明，收起；`note` 是不看就会把数读错的说明，常显。
- **金额合计算不出来**（有一行没单价）显示“—”加一句次要说明，不显示 0.00、不只算能算的几行。
- **默认视图**显示要处理的，不默认“当日”空列表；日期条只留在排产板这种日程页。
- **列优先级：** 表格区域变窄（详情面板、助手停靠、窗口窄）时按优先级收列，规则在 `src/ui/list-layout-5.css`“列表的列优先级”。单号或名称、状态、金额这类关键列不收；收掉的列要能在详情里看到。宽屏定死宽度的列在 `@container list-table (max-width: 899px)` 里放开。
- **行里不放按钮**，点行开详情。例外：待办列表（今日、待到货、可发货）每行一个动作，直接开对应窗口，办完回原处。
- **勾选后**用 `SelectionBar`：固定在底部，“已选 N 项”、一个正向主操作、最多一个次要、“更多”（批量归档、批量删除）、“清除选择”。归档能恢复，不用红色。
- **空状态：** 一句为什么空 + 一个能解决的动作。

## 详情

- 一张单只有一个详情，不做“面板 + 弹窗”两层；列表面板、归档页、从别的详情点开的窗口用同一份。窗口里的到货单“采购退货”只显示、不出“撤销退货”，“到货记录”也不出“更正到货单”（一个窗口只交互一次）。
- **头部：** 类型、编号或名称、`StatusChip`（待办 `neutral`、进行中 `accent`、完成 `success`、取消 `warning`、撤销或作废 `danger`，都要有底色）、一行关键上下文（送货单写“客户 · N 种产品”）；操作用 `ActionBar`。
- **正文顺序：** 提示（`Hint`）→ 进度（只出现一次）→ 明细（数字右对齐，补充信息写 `<small>`）→ 基本信息（`Facts`）→ 关联单据（都能点开）→ 历史。“下一步”只写一句为什么，不放按钮。
- 单据能互相跳：订单 ↔ 生产任务 ↔ 完工 ↔ 送货，采购单 ↔ 到货。
- 一节里多条同类、字段又多的记录（如成品批次），一条一块浅底圆角块上下排，不用多列表格。
- 空值写“—”；单号、日期、“现存 1,050 只”这类短内容 `nowrap`；撤销、更正后原日期照常显示，后面写“ · 已撤销”“ · 已更正”。“经办人”有确认人写确认人，没有写登记人。
- 修改历史每条一个中性色小标签写来源：页面、助手、数据管理、系统（服务器按 `shared/core/audit-sources.ts` 的 `auditSourceNames` 给 `sourceLabel`）。

## 编辑窗和确认窗

- 外壳 `ManagementDialog`；手机上 `sm`、`md` 变底部弹层，`lg`、`xl` 全屏。所有窗口都有底栏。
- **关窗口：** 手机样式下点窗口背后的暗处就关，和点 × 同一个关闭（提交中不关；按下和抬起都在暗处才算，`src/ui/backdrop-close.ts`）；电脑上居中的窗口点暗处不关。用 `ManagementDialog` 就自带，不自己画暗层。
- 只摊开必填和常用字段，低频的收进折叠的“更多信息”；节标题用大白话（“生产什么”“什么时候做”）。
- 状态不在编辑窗里手选，用底栏按钮表达（保存 / 保存并确认）。默认值不伪装成真值（单价留空，不填 0）；说明最多一句 `hint`，改不了的字段在 `hint` 写原因。
- **字段：** `FormField` 的 `label` 简短，必填 `required`，错误 `error`；数量和单位一起用 `.form-inline`；明细字段少用 `.line-table`、多用 `.line-card`。表格行里输入框的读屏名用列名加行号（“第 1 行单价”）。点底部按钮有报错时，`required-guide.ts` 标红空着的必填项、滚到第一个并聚焦。
- **底栏：** `EditorFooter`，左边一句说明，右边“取消”+ 主按钮，最多再加一个次要，低频的放底栏“更多”。到货、完工、送货的取消确认窗里退出按钮写“不取消”。主按钮写这一步的结果（保存订单、安排送货、确认删除）；危险确认红色实心（`danger-solid`）；会动库存或连带删单据的删除窗口默认焦点在“取消”。
- 不用原生 `confirm`，用 `ConfirmDialog`，异步流程用 `useConfirm()`。撤销、取消的确认窗不列关联记录，后果在顶上说明里讲清。
- 从单个对象进来的窗口只显示这个对象，要多选时给“再加一张”。
- 叠在页面上、有自己关闭按钮的一层（窗口、详情面板、侧边菜单、浮层、菜单）用 `useBackLayer` 登记关闭函数，安卓返回键才能一层层关（见[外壳和网页](架构/外壳和网页.md)“安卓 App 通道”）；`ManagementDialog`、`DetailPanel`、`FilterPopover`、`MoreMenu` 已登记。`tests/back-layers-registered.test.ts` 守着。
- **办完和没办成：** 办完关窗，结果用 `notify('…')` 页面提示；不保存后再弹详情，能一步做完的不拆两步。没办成的错误显示在窗口里（`FormMessage`）；窗口已要关或是从别处弹出的，用 `notify(原因, 'error')`，不能“点了没反应”。只是提醒接下来会怎样、要人做什么的用 `notify(文字, 'info')`：颜色和停留时长同办成，图标是 i、不带对勾。

## 助手确认卡片

- **标题：** 写要做的事、用本词表的叫法（核对入库、不导出直接出库、撤销送货、盘点调整），不用“已……”，不写事务、回滚这类开发口径。删除卡片写“删除 + 叫法 + 单号或名称”，库存品写“删除原材料库存 …”“删除成品库存 …”。
- **按钮：** 删除、清空红色实心，写“确认删除”“确认清空”，其他写“确认执行”；旁边“不执行”作废卡片。执行过的卡片只在标题下写一次“已执行”，不再放按钮；执行回执写“已执行：方案标题”，不露工具名。执行没成、结果不明写“执行没有成功 · 这张卡片不会再执行”“已经发出去，结果不明 · 先查一下再决定”。
- **内容：** 第一行动的是哪条，下面逐项改前 → 改后、库存前后，由服务器写好（`server/assistant/tools/card-summary.ts`），页面原样列出，不在前端猜。小字按服务器给的标记写要不要密码、超级管理员模式、是否只能在服务器本机，不写“二次确认”“高风险操作”；密码框标签和页面删除窗口一样。
- **每条回复下面一行**写这一轮实际做了什么：“只查询，没有改动”“待确认：…”“已执行：…”“没做成：…”（`src/assistant/plan-card.ts` 的 `factLines`）；没做成只写哪一步，原因由助手说。“已执行”里的长期记忆每条后面一个“忘掉”（`src/assistant/AssistantExecuted.tsx`），别的不放按钮。
- 方案被别处改过、确认被拒时，同一个核对区换成服务器上最新的一版，不弹新窗口。说法集中在 `src/assistant/plan-card.ts`。

## 页签、手机、质感

- 两到四项的切换用分段控件（`.record-view-tabs`），页内页签全站一套样式。超过四项：手机上改下拉或横向滑动，电脑上折成两行，不截掉最后一项。
- **多窄算手机：** 窗口宽 700 及以下是手机版式，701 起是电脑版式（平板、窄窗口也是，页面要在 701 宽排得下）。样式写 `@media (max-width: 700px)`（反过来 `min-width: 701px`），代码里判断手机用 `src/ui/phone.ts`。701～899 不另立断点；700 以下再收一档（如 480）、900 以上多一栏可以有。`npm run lint:css` 守着。
- **手机（390 宽）：**
  - 列表是紧凑行：第一列做标题，其余“字段名 值”小字，两三行高（`src/mobile/MobileNav.tsx` 自动处理）；空格子由脚本标 `m-hide`，长字段（地址、备注、加工要求）在 td 上标 `m-long`；不按列序号隐藏。
  - 组合输入、表格式输入不溢出，没有竖排文字和横向滚动。一套导航：底部栏 + 页内一排切换。筛选默认收起。
  - 顶栏（搜索、新建、账号）往下滚跟手收起、内容淡出，往回滚跟手露出，停在半路松手吸附（`src/mobile/topbar-collapse.ts`，只动位移和透明度），所以别的东西不要贴着顶栏下沿定位。弹层开着时页面提示条挪到顶上、让出一个标题栏高，不压住弹层的标题栏和底栏。
- **悬浮的小甬小勒不挡内容：** 电脑上真的压住详情面板，或贴在屏幕右边压住表格、按钮时，才缩到边上只露一条（贴左边的不缩），鼠标移上或聚焦时探出（`src/assistant/floating-assistant.ts` 的 `yieldPeek`、`yieldReveal`）。助手入口按“收起方式”二选一（悬浮小人或顶栏按钮）。
- **质感：** 精致版式层统一（AGENTS.md“界面”）：不框套框；图标按钮平时透明；输入框是要填的空格（浅色比纸白一档、一圈细线），聚焦变白有光圈；禁用的输入框更浅的底、虚线边（`src/ui/buttons-4.css`“禁用的输入框”）；弹窗背后变暗、缩放淡入；动画跟随系统“减少动态效果”关闭。键盘能操作，焦点可见。

## 颜色和字体

- **换主题只改 `src/ui/tokens.css`：** 浅色、深色各一块变量（`:root[data-ui='refined']` 和它的 `[data-theme='dark']`），页面样式只引用变量，不按深浅另写规则。浏览器地址栏颜色（`theme-color`）由 `src/ui/theme.ts` 读 `--page-bg` 设，也跟着走。
- **浅色“米纸留白”：** 整个面是一张米色的纸（`--page-bg`），卡片是纸上用细线框出的一栏（`--surface` 加 `--card-shadow` 那圈线），不靠白底和阴影浮起来；只有弹出的菜单、窗口有阴影。白色只留给“正在用”的地方：要填的格子（`--field-bg`、`--input-bg`）、选中的行、分段和页签选中的那一格、侧栏当前页、弹出的菜单。墨水蓝（`--teal`）只给主按钮、链接和选中行左边那条。表格的表头压深一档（`--surface-muted`）、下面一条实线（`--rule-head`）。
- **深色“墨纸留光”：** 同一张纸到了晚上：纸是带一点暖的墨色，字是米色；明暗次序和浅色一样（侧栏 < 页面底 < 卡片 < 要填的格子 < 正在用的），浅色里“白的”地方在深色里是“亮一档的”。主按钮是提亮的蓝底配深色字；“提示”往青里偏、AI 紫更紫，和主色的蓝分开。公共样式两套共用，深色只是深色块里的另一组值。
- **选中：** 列表选中的行（右边详情开着的那一行）全站只有 `src/ui/list-layout-5.css` 一处，底色 `--selected-bg`、第一格左边一条主色，冻结的最后一格跟着换；别处“当前选中的是这一个”（收件箱和 AI 导入的文件行、使用说明目录当前项、数据管理勾上的行、财务的选项卡片、附件预览的当前页、排产板的“今天”那一列）也用 `--selected-bg`；分段控件和页内切换、财务和设置的页签选中的那一格用 `--input-bg` 加 `--segment-shadow`；侧栏当前页 `--sidebar-selected`。`--accent-soft` 只给蓝标签、“下一步”、角标这一类，以及“指着的那一项”（搜索面板和下拉里鼠标或键盘指着的、“更多”菜单的鼠标停着）和按下的开关，不当“选中”用。
- **字体：** 正文思源黑体（`--font-sans`）；页面标题、卡片和窗口标题、侧栏抬头、登录页公司名用思源宋体（`--font-serif`）；点了会展开的那一行（“最近 12 个月”“对应成品库存 · 2”这类折叠标题）是开关不是标题，用黑体，人一眼分得出哪个能点。表格格子、详情的字段值、详情标题下那一行、列表统计、订单明细和合计、经营概况的数、今日页的单号是“数据”，里面的数字和字母用宋体、汉字仍是黑体（`--font-num`，表格、字段值在 `tokens.css` 一处定，格子不用逐个标）；今日页“交期 11-13”“逾期 10 天”这种短语整句宋体，免得一句里忽粗忽细；列表里的数字加半档字重。等宽字体 `--font-mono`，单据样张 `--paper-font`（照纸面，不跟主题）。网页字体来自 `@fontsource-variable/noto-sans-sc`、`@fontsource-variable/noto-serif-sc`（`src/main.tsx` 引入，按字切成小片、同源发、用到哪片下哪片），后面跟系统字体做后备；换字体改这两个包和 `tokens.css` 里的字体变量。“·”“×”在思源里是全角，交给系统字体的半角（`tokens.css` 的 `ERP Marks`）。深浅两套字体一样。
- **对比度：** 文字不低于 4.5:1（`npm run test:ui -- a11y` 查）；提示字只靠 `--placeholder` 定深浅，不加透明度。

## 样式变量

- 颜色、字号、圆角、层级（`z-index`）只写 `src/ui/tokens.css` 里的变量，色值只许出现在这一份。`npm run lint:css`（stylelint，规则在 `stylelint.config.mjs`，也在 `npm run check` 里）拦：十六进制和英文名颜色、`rgb()` `hsl()` 这类颜色函数；`font-size`、各种 `radius`、`z-index` 不是变量的值（`0`、`none`、`auto`、`inherit` 这类关键字除外）；700 以外的手机断点（见“页签、手机、质感”）。用变量调出来的（`color-mix(… var(--x) …)`）不算写死。
- 字号六档 `--text-xs/sm/md/lg/xl/2xl`（12/13/14/16/20/24）；圆角 `--r-control` 8、`--r-panel` 12、`--r-pill` 胶囊、`--r-inner` 6、`--r-small` 4、`--r-circle` 圆（`tests/ui-kit.test.ts` 查变量只有这几档）；层级按用途起名（`--z-topbar`、`--z-overlay`、`--z-toast` 等，从低到高列在一处）。单据样张（`--paper-*`，照纸面、不跟主题变）、打印（`--print-*`）、小甬小勒（`--yl-*`，紫色只给 `--yl-star`）各有一组。新值先在 `tokens.css` 起名，跟主题变的写进浅色、深色两块（深色要的一起写），不跟主题的写在后面那个不分深浅的 `:root`。组件里的 SVG 颜色也用类名引变量（如小甬小勒的 `yl-white`、`yl-pupil`），不写色值。
- 间距八档 `--space-3xs` 到 `--space-2xl`（2/4/6/8/12/16/20/24，负值写法 `calc(-1 * var(--space-…))`），在档上的已改用变量；间距还不归 stylelint 管，不在档上的怎么归档、何时进检查见[路线图](路线图.md)。
