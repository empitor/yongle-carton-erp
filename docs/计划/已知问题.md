# 已知问题

什么时候读：看还剩什么没做：1.0 之后还没修的已知问题。

每件只写是什么、在哪，修好就删；技术债和暂不做的相关的见 `docs/计划/技术债.md`，不影响对错的小改进相关的见 `docs/计划/小改进.md`。

**会算错数的（先修）**

- 本机管理员在已送过货的明细上原地换产品，送货单和 `flow_refs` 不动、已发数记到新产品头上，订单进度和仓库台账的“已发”对不上实物（`server/orders/order-edit-cascade.ts`）；数量改得比已发少也照存。怎么改要用户定。

**还慢的地方**

- 今日页 `buildToday` 读全部没归档的订单、生产任务、采购单。
- 有些列表接口不分页。
- 到货页另读全部 `/purchases`（`src/warehouse/useWarehouseData.ts`）。
- 台账日历计数在 JS 里数（4 万张约 40 毫秒），改 SQL 分组。
- 每日清理同步收回空闲页，请求要等（100MB 约 0.67 秒）。
- 本机管理员改订单后全库重算（`server/orders/service.ts` 的 `recomputeAfterMaintenance`）。
- 按采购单查到货可加 `flow_refs(purchase_id, document_id)` 组合索引。
- `production.plan` 读全部库存品。
- `server/assistant/tools/records-lifecycle.ts` 的 `buildDelete` 逐条调 `recordRow`，改批量读。

**范围很小的风险：业务和数据**

- 采购单新建行、数据管理模板预填“按平方米”，原材料默认名“瓦楞纸板”，是猜测（`src/operations/purchase-seed.ts`、`shared/business/overview/data-management-templates.ts`），待定。
- 送货页“可发货”的待发数没扣待送货单上的数。
- 改已算成本月份的流水数量，成本不自动调（会提示重做）。
- 订单编辑窗开着时数据变了，冲掉正在填的（`src/records/RecordEditors.tsx` 的 `key` 带版本号）。
- 同一条收件在两个标签页同时新建订单会建两张（`server/inbox/service.ts`），同一标签页也有很短的空当（`src/import/InboxOrderDialog.tsx`）。
- 收件箱改状态先校验正文后查权限；收件箱和建出的订单之间没有来源链接；订单编辑窗新建不带防重复请求号。
- 厂区改了资料，已安排的待送货单不跟着变（不再保存就出库印旧地址）：建议自动跟着变，等用户定。
- 升级后外键校验不过只报“数据关联校验失败”，不说哪张表哪行（`server/core/schema/upgrade.ts`）。
- 配置库被拒时已多建一个空业务库：要先核完配置库再开业务库。
- `import:restore` 权限（`server/accounts/account-db.ts` 的 `levelGrant`）没人检查：删掉或真查。
- 首个管理员核对密码排不上队时账号已建好，要再登一次。
- 同一产品在原客户名下有两张以上订单都选错了客户的，每张都被“别的订单也用过”拦下，改不了（只能先改掉别的订单或新建产品）。
- 升级第 25 步不挂超出厂区录入上限的待送货单（按 JS 字符串长度，带表情、NUL 的比程序严，`server/core/schema/steps.ts` 的 `v25Fits`）：再保存仍按默认厂区重取，手填的会被换掉。本机已跑过旧第 25 步、升到 25 版的开发和测试实例也不会再补挂。

**范围很小的风险：财务**

- 已结账月份的单据没补扫前，那月起的正式报表和快照出不来；大批单据要几次请求补完。
- 完工单冲销时分摊的制造费用留在 `400101`。
- 按送货确认收入时，销售蓝票不生成凭证、不查是否超开。
- 开票确认收入时部分红冲让应收暂时偏少；毛利的收入和成本可能和总账不同月。
- 未到票退货冲了暂估，后到票再撤销退货，暂估不恢复。
- 已结账月份物理删盘点流水或完工单后，算成本报期初对不上（`server/finance/costing/costing-compute.ts`）。
- 单价为 0 的有效到货算成本被拦，补不了。
- 概览“需要处理”把缺价格、缺数量合成一个数（`server/finance/reports/monthly.ts` 的 `missingPrice`）。
- 一条坏记录让整个列表或页面 500（`StoredDataError`）：改成跳过并记出错记录。
- 没启用财务时开账簿报“账簿期间必须在财务启用之后。”。
- 未提交的红字凭证详情仍显示“编辑”。
- 期末明细和防重复重放的输出悄悄去掉多出的键。
- 每个财务请求查两次会话。
- 财务上传和原件下载没有走 HTTP 的测试。
- 单张补税率的金额框预填七位小数（如“5475.0000000”，`src/finance/flow/ResolveTax.tsx`）：那是算钱用的精确金额，改显示要先定改法。
- 补税率表的口径认不出（如“口径：含税价”）时空着，下面不写原话。

**范围很小的风险：助手、开发工具、界面**

- 助手执行的初始化外层回滚时，删掉的识别工作区文件回不来。
- 按批导入时前一份刚建的产品没尺寸，后一份同名的被拦下问。
- 撤销采购退货的卡片有一行“有改动但列不出明细”。
- `src/assistant/composer-keys.ts` 只按 `isComposing` 认选字，要在 Mac Safari 实测拼音。
- `scripts/schema-dump.ts` 导出第 20 版快照那步预期报错，改成跳过。
- `scripts/linux/verify-package.mjs` 停在导出预览（`rowsPerPage`）、没检查在跑：修好，在发布检查里真跑。
- 临时目录不清理（两天近 30 GB）：`scripts/ui-check/lib.mjs` 的 `openChrome`、预览和流程实例、`scripts/ui-check/server.mts`（只在 `SIGINT` 时清）：改成用完就删。
- 安卓返回键：同一次渲染挂上父子两层时先关父层；全屏助手下的窗口按登记先后关。
- Codex 下钩子回不了“先问”：停本机正式实例、反斜杠写法的真实模型脚本、命令行改检查配置、浏览器批量和脚本连 3001、`git -C . push` 都不问（`.codex/rules/ask-before.rules` 只认前缀）；Claude Code 的 `permissions.ask` 也认不出 `git -C . push`。
- 钩子（`.claude/hooks/`）拦不到：管道删除（`Get-ChildItem | Remove-Item`）、变量拼的路径（`$HOME`、`$PWD`）、命令替换算出的路径、两层以上的 `$( )`、`npx -p 包名`、`\\?\` 前缀、Glob 列文件名、正式实例地址的别的写法、带选项的 `systemctl`；Antigravity 的 `Cwd` 没有实测样本，文件工具的 `TargetFile`、`SearchDirectory` 没查。
- 钩子多拦的：子目录下的 `git clean -fdx`、`tar -C <根目录>`、`node -e` 读锁定文件写别处、`cd src && ls data`、`Get-ChildItem -Filter data`、`Join-Path $t 'data\erp.sqlite'`，浏览器参数里写了 `localhost:3001` 也先问。

**还没修的小问题**
