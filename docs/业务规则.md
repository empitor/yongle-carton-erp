# 业务规则

什么时候读：改业务代码（server/、shared/、src/）之前读，每条都是审查标准。

每条先写规矩，再写写代码时最容易漏的地方。库里怎么存（千分数量、万分之一元单价、分）相关的见 `docs/架构/数据库约定.md`；写入的版本校验、防重复、事务、审计各只有一种做法，相关的见 `docs/架构/服务端写法.md`。

## 不猜

- 未知的客户、产品、税率、价格、日期不得猜测。不默认含税。
- 留意这几种悄悄猜的写法：默认税率、默认今天、拿 0 或 1 冒充数量和单价、把没定价当 0 元。

## 数量单位

- 产品和成品只有“只”（“个”就是“只”，没写也是“只”），原材料只有“张”（`shared/core/units.ts`）。别的单位一律拒收，提示人先换算；系统不换算、不相加。
- 统一走 `shared/core/units.ts`，判断和校验里不直接写“张”“只”。采购明细、到货明细的单位没有数据库约束、靠保存服务保证，新的写入路径不能绕过保存服务。

## 单价和金额

- **金额：** 不用浮点相乘。留意 `parseFloat`、`Number(x) *`、金额和数量直接相乘。
- **单价：** 最多四位小数，用 `shared/core/precision.ts`；上限是同一份的 `MAX_PRICE_YUAN`。
- **精确价和“分”两头都给：** 按 `server/sales/record-fields.ts` 的 `chosenExact` 取，对不上又分不清改的是哪一头就拒收。补丁改价先过 `shared/core/precision.ts` 的 `priceEdit` 判断补丁的意思，再交给保存。

## 日期

- 业务日期用 `shared/core/domain.ts` 的 `today()`（按业务时区），不能用 `toISOString().slice(0, 10)`（北京时间早上 8 点前会变成前一天）；操作时间戳可以用 ISO。
- 送达、到货、签收这类该由人确认的业务日期不悄悄默认今天，至少预填让人看见、能改。
- 日期校验用共享的 `dateSchema`，不只用正则；还要和单据自身的日期合理（比如送达不早于出库）。

## 库存

- 余额只由 `stock_movements` 流水派生，不能负库存。管理员改写流水必须留修订记录。
- 同一种货只有一个库存品：成品一定关联产品、一个产品一个成品库存；原材料按查重键（`rawStockKey`）不重复，归档的也算。

相关的见 `docs/功能/库存.md`。

## 产品归属客户

同客户内查重（允许未指派客户的旧档案并存）；订单、导入与单据不能跨客户混选；已开过订单的产品不可变更归属客户，唯一例外是订单换客户时只在这张订单里下过单的产品跟着改归新客户。相关的见 `docs/功能/客户产品订单.md`。

## 写入

- 复用现有业务服务，保留登录权限、版本校验、事务、幂等和审计。删除和初始化前调用 `snapshotBeforeDestructive`。
- 版本校验（`version` / `expectedVersion`）、审计（`business_audit`）都要在。
- 幂等可以带 `requestId`，也可以“已经办过就直接返回”，但要放在版本校验之前；同样的请求重复提交却报错，算问题。
- 批量操作逐条把失败原因交给人或写进结果时用 `failureMessage`（`server/core/http/errors.ts`），不把数据库约束的英文原文带给用户。

## 读取

单条按主键，列表批量组装，禁止全量加载后再 `find`。

## 派生的状态要重算

- 订单的生产中、待发货、已发货由有效单据派生，不手工设置。
- 改了派生状态依赖的输入（订单明细的产品、数量，生产任务，送货、完工单据），要触发重算（`FlowService.refreshOrderProgress`），否则状态要等下一张单据才变。

## 新字段在所有改写路径都保留

单据内容的结构是严格的（`shared/business/flow/flow-document.ts`），新字段没登记写入就报错。还要查说明编辑（`updateDocumentInfo`）、三种更正、数据管理保存、识别导入这些改写路径，都把新的系统字段（如 `shippedAt`、`deliveredAt`）原样带上，没被中间哪一层的结构剥掉。

## 财务

- **已记账凭证不可改、不可删，** 只能红字冲销。
- **财务不卡业务：** 缺税率时送货、到货、收付款全部照常，理论金额先进账，事后在月度台账补。只有生成正式报表和结账才拦，并提示补完。卡点越少越好。

相关的见 `docs/功能/财务取数和补扫.md`、`docs/功能/财务记账和结账.md`。
