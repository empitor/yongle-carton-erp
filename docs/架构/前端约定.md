# 前端约定

前端代码怎么写：请求、取数、单据窗口、显示用的统一函数、刷新、样式。界面长什么样、词表、公共件清单见[界面规范](../界面规范.md)；请求怎么发见[架构说明](../架构说明.md)“一次请求怎么走”，接口表见[服务端通用做法](服务端写法.md)；和两个外壳的约定见[外壳和网页](外壳和网页.md)。

- **请求和取数：** 组件和 hook 只调本模块 `*-api.ts` 里的函数，不写地址；页面里的类型取接口表里的（`RecordsApi['GET /orders']['response']`、`Listed<Order>`），不写 `<any>`；别的模块的数据走 `src/ui/slots.tsx` 的服务接口。读一份数据用 `src/ui` 的 `useLoad`，点一下执行用 `useAction`，业务数据变了用 `useBusinessRevision` 重读，不手写 `setBusy…finally`；effect 只想在某时刻跑、又要读最新值时用 React 的 `useEffectEvent`，不靠省略依赖。档案（客户、产品、供应商、采购单、库存品等）只经 `src/recordkit/catalog-api.ts` 的 `readCatalog` 读，按需缓存用 `useCatalog.ts`。
- **单据的更正和编辑窗：** 三种单据的更正共用 `src/flow/CorrectionDialog.tsx`（防抖核验和行状态在 `useCorrection.ts`），完工和更正完工共用 `MaterialInputs.tsx`；说明编辑只有 `DocumentInfoDialog.tsx`。被 409 拒时读回最新单据、留住人填的行、重新预览（`correction-recover.ts`），不弹第二个窗。详情顶上的“更正自 / 已更正为”是 `CorrectionNote.tsx`；单据链接只用 `shared/core/pages.ts` 的 `flowDocHref`。
- **单据详情只有一份：** `src/flow/FlowDocView.tsx`（面板和窗口同一正文；到货单、送货单按明细 → 基本信息 → 流水排，经办人只有 `handler` 一种写法）。到货页、送货页（在用和已归档）、归档页、从订单和采购单点开的单据窗口、核对窗都用它。到货单、送货单点开时由 `flow-api.ts` 的 `readFlowRecord` 按编号读这一张的台账记录（`GET /flow/daily` 带 `doc`）；核对窗还没核对，不列验收入库和流水。到货单的“采购退货”（窗口里只显示、不能撤销；窗口里的“到货记录”也不出“更正到货单”）和“到货记录”也在 `FlowDocView` 里，财务段插槽排最后。
- **共用件：** 详情、编辑窗、弹窗、出错提示、页头和“更多”、列表工具栏、列表表格、PDF 预览、提示、时间、日期筛选都在 `src/ui/`（导出窗在 `src/documents/ExportDialog.tsx`），从 `src/ui/index.ts` 引，不在模块里另抄；`tests/ui-kit.test.ts` 查别处不手写。清单和写法只在[界面规范](../界面规范.md)“公共件”。
- **时间：** 一律按北京时间显示，只经 `src/ui/time.ts` 的 `beijingTime`；时区只在 `shared/core/domain.ts` 的 `BUSINESS_TIME_ZONE`。
- **列表变窄：** th 和 td 标 `col-low`（区域窄于 900px 收）或 `col-mid`（窄于 660px 收），规则在 `src/ui/list-layout-5.css`；用 `DataTable` 的在列定义里写 `priority`（`src/ui/DataTable.tsx`）。手机卡片的空格子由 `src/mobile/MobileNav.tsx` 标 `m-hide`，长字段手写 `m-long`。
- **显示统一的函数只用一份：**

| 显示什么 | 用哪个 |
|---|---|
| 单价 | `shared/core/precision.ts` 的 `plainPrice`；带计价方式的 `shared/business/display-text.ts` 的 `priceText` |
| 以分存的金额 | `shared/core/display-amount.ts` 的 `centsText` |
| 单据状态、单据名、单据有效、状态筛选 | `shared/business/physical-flow.ts` 的 `flowStatusText`、`flowNames`（页面、列表用，完工叫“完工记录”）、`flowDocNames`（指一张单据，“完工单”）、`activeDoc`、`matchesFlowStatus` |
| 栏目叫法，哪个栏目指向哪张表 | 栏目登记表 `shared/core/field-names.ts`（`fieldLabel`、`fieldName`、`fieldTitle`、`fieldShort`、`fieldTables`；按记录种类和明细一层另起的叫法也在这里）。编辑窗、详情、列名、数据管理、修改历史、助手卡片、报错、识别结果表、导出列都用；退掉的旧叫法由 `tests/field-names.test.ts` 拦 |
| 选项的叫法（跟选项的值写在一起） | 尺寸单位 `dimensionUnitNames`、计价方式 `priceBasisNames`、币种 `currencyNames`、种类 `stockKindNames`、数据管理的单据状态 `storedFlowStatusName`；修改历史和数据管理下拉共用 `history-fields.ts` 的 `codeNames` |
| 档案和单据名 | `shared/business/labels.ts` |
| 修改历史 | `shared/business/record-history.ts`（词表在 `history-fields.ts`，新审计动作在 `historyActionNames` 登记中文名） |
| 判断和校验里的单位 | `shared/core/units.ts` 的 `RAW_UNIT`、`FINISHED_UNIT`，不直接写“张”“只” |
| 页面编号、名称、分组、地址和查询参数 | 页面地址册子 `shared/core/pages.ts`（`pages`、`pageTitle`、`pageShortTitle`、`pagesInGroup`、`pageHref`、`pageParams`、`flowDocHref`、`isPageHref`、`pageIdOf`）；代码里 `#页面`、`#页面?参数` 字面只许出现在这一份，由 `tests/page-hrefs.test.ts` 守 |

- **别人改的数据怎么刷新：** 服务器不推送，靠页面自己重新取：导航数字每 15 秒取一次（`src/app-shell.ts` 的 `useNavCounts`）；从别的窗口切回来时发一次 `erp-business-changed`，导航数字和眼前列表都重取，5 秒内不重复（`src/ui/return-refresh.ts`）；本页办完事也发同一个事件（识别文件归档、删除、恢复后别的页面跟着刷新）。
- **主题：** 跟随系统时系统切深浅立即跟着变；别的标签页改了外观这边也立刻变，账号菜单的选项一起更新（都在 `src/ui/theme.ts`，全站只监听这一处）。
- **样式：**
  - 和组件放同一个模块目录，每份不超过 500 行。一条选择器只用本模块和它能用的模块的类名，前端业务里只用本层和下层的（`tests/css-modules.test.ts`；跨模块的例外只在 `src/cross-module.css`）。“类名有人用”只认 `className`、`classList` 和字符串字面量里出现过的词（共用代码的词表也算），类名归写出它的模块；没人写出的类名就是没人用的规则，要删。收紧这个认法时新报出来、还没定的登记在测试的 `pendingRules`，只许减少。
  - 删样式、搬样式前后用[样式比对](检查和测试.md#几组手动跑的比对和验证脚本)确认页面没变。
  - 颜色、字号、圆角、层级只写 `src/ui/tokens.css` 的变量（`npm run lint:css` 守）；间距八档（`--space-3xs` 到 `--space-2xl`）已进 `tokens.css`、在档上的已替换，不在档上的处理完再进 stylelint（见[路线图](../路线图.md)“界面这条线剩下的五步”）。
  - 全部只在 `src/main.tsx` 引入，顺序就是优先级：按模块从低到高，最前面是两个网页字体包（`@fontsource-variable/noto-sans-sc`、`noto-serif-sc`，开发依赖，按字切片的 woff2 构建进 `dist`、同源发，出处和许可见 `THIRD_PARTY_NOTICES.md`），然后是 `ui/tokens.css`。换主题只改 `tokens.css`（见[界面规范](../界面规范.md)“颜色和字体”）。带“// 排在……之后”注释的是设计如此的先后：模块要压过基础件的同级写法，精致版式的基础件（按钮悬停、详情卡片、表格、分段控件，`ui/*-2`、`-3`、`-4` 这类）要压过模块的，同一主题拆成前后两份，手机和打印的 `@media` 覆盖。`tests/css-order.test.ts` 守着这些先后、每份只引入一次。
